Monitoring, alerts and notifications

The server checks every device once a minute. An alert opens while its condition holds and closes by itself when it is gone; you are told by email, in a chat channel or through a webhook.

Alert rules

Set the rules in the policies of the customers, sites and devices (every customer has its policy Default). Alert emails, the email server and chat channels are under Settings → Monitoring and alerts.

RuleOpens when
CPU loadthe load stays above the limit for the chosen minutes
Memory usememory use stays above the limit for the chosen minutes
Disk spacea disk is fuller than the percentage, or (on disks larger than twice this) has less free space than the given GB
Device offlinethe agent has not connected for longer than the given minutes
Restart pendinga restart is pending and the computer has been up longer than the given days
Microsoft Defender offthe antivirus or its real-time protection is off (optional)
Firewall offa Windows Firewall profile is off (optional)
Service stoppeda service from your list (service names, not display names) is set to start automatically but is not running

Alerts are a Warning or Critical (critical: offline devices, stopped services, Defender off, and disks with less than 1 GB free or 98 % used). Alerts lists the open ones (and, if you want, the resolved ones); a technician can acknowledge an alert so others see that someone is on it. The number of open alerts is shown in the menu.

Alert emails

  1. Enter the email server (SMTP): host, port, connection security (STARTTLS or TLS; a password is never sent over an unencrypted connection), user, password and sender. The password is stored encrypted.
  2. Add the recipients, one address per line, and choose whether an email also goes out when an alert is resolved.
  3. Click Send a test email.

Slack, Microsoft Teams and webhooks

Under Chat and webhooks add up to 20 channels:

  • Slack — an incoming webhook URL of the channel.
  • Microsoft Teams — a channel workflow When a Teams webhook request is received, and its URL.
  • Webhook — any HTTPS URL that accepts a JSON POST (ticket system, automation). With a secret, every request carries X-ControlZit-Signature: sha256=<HMAC of the body>, so the receiver can check it came from your server.

For each channel choose all alerts or only critical ones, and whether resolved alerts are sent too. Send test sends a test message. Channel addresses are stored encrypted.

Live values

The device page shows the current CPU load, memory and disks, and the automatic services that are not running.
