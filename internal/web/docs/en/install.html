Installing the server

Choose one of four ways. The ready-made VM image is the fastest; the install script suits an existing Linux server.

WayBest forNeeds
1. VM image (OVA, qcow2, VHDX)import, start, sign in, in a few minutesVMware, Proxmox / KVM or Hyper-V
2. Appliance ISOa new VM or a physical server, unattendedinternet access during the installation
3. Install scriptan existing Debian, Ubuntu, AlmaLinux or Rocky Linux serverroot and internet access
4. Packages by handyour own PostgreSQL, configuration management, offline serversthe deb or rpm package of a release

All files are on the release page. Give the server 2 vCPU, 2–4 GB RAM and a 16 GB or larger disk.

1. VM image

  1. Import the image:
    • VMware ESXi / Workstation, VirtualBox: deploy controlzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: create a VM without a disk (2 vCPU, 2–4 GB RAM, VirtIO network), copy controlzit-appliance.qcow2 to the node and run qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm; attach the disk as SCSI and make it the boot disk.
    • Hyper-V: unzip controlzit-appliance-vhdx.zip and create a generation 1 VM with the VHDX as its disk.
  2. Start the VM. The disk grows to the size of the virtual disk by itself. The screen of the VM shows the address of the console and the setup token.
  3. Open https://<address>:8443. The browser warns once about the self-signed certificate (replace it later under Settings → Certificate). Enter the setup token and create the first administrator.

The appliance gets its address by DHCP. To set a fixed address, the server name or the time zone, sign in on the VM's own screen as czadmin (first password controlzit, which must be changed): a setup menu opens. The time zone and the network can also be changed later in the console.

2. Appliance ISO

  1. Boot a VM or a server from controlzit-appliance.iso. After 5 seconds the installation starts by itself: it erases the first disk, installs Debian, PostgreSQL and ControlZit and needs internet access (10–20 minutes).
  2. After the restart the screen shows the console address and the setup token, as with the VM image.

3. Install script

On an existing Linux server, as root:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

The script installs PostgreSQL, downloads the newest release, checks its signature, creates a database with a random password and starts the service. Options (after sh -s --): --version X, --db postgres://… for an existing database, --no-auto-updates to leave the automatic security updates of the operating system off. Running it again updates ControlZit and keeps the data.

4. Packages by hand

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Then put the database address into /etc/controlzit/server.env (CONTROLZIT_DB=postgres://…) and start the service with systemctl enable --now controlzit-server.

First sign-in

  • The setup token is in /var/lib/controlzit/setup-token.txt and in the server log (journalctl -u controlzit-server). It works once.
  • Every account needs an authenticator app (TOTP) and gets 10 recovery codes. Keep them safe.
  • The console accepts connections only from private networks by default. If you lock yourself out, run controlzit-server --reset-allowlist on the server (on the appliance: setup menu, item 5).

Where things are

PathWhat
/etc/controlzit/server.envconfiguration: database, ports, update source (readable by root and the service only)
/var/lib/controlzitdata directory: certificates, secret key, agent installers (downloads), logs
/var/lib/controlzit/logs/server.logserver log; also in journalctl -u controlzit-server
/var/log/controlzit-helperlog of the root helper (updates, time zone, network)

Back up the database together with /var/lib/controlzit: the secret key there decrypts the stored passwords and the certificates identify the server to its agents.
