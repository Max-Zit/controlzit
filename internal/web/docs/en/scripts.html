Scripts and scheduled jobs

Run PowerShell, cmd, bash or sh on one device, on many devices at once or on a schedule. Scripts run as SYSTEM (Windows) or root (Linux), without a window.

On one device

On a device page, open Scripts, choose the shell, write the script (or load one from the library) and set a time limit (5–1500 seconds). The page waits for the result and shows the exit code and the output (the first 1 MB). Earlier runs stay in the list; Edit and run again opens a run as a new script.

Script library

Save scripts you use often under Scripts → Script library, with a name and a description. From there you run a script on selected devices, on all devices of some customers, or on all devices.

Jobs

Running a library script on several devices creates a job. The job page shows every device with its state (waiting, running, succeeded, failed, expired) and its output. Exit code 0 counts as success. Devices that are offline run the script when they connect, within 24 hours; after that they count as expired.

Schedules

A script in the library can run on a schedule: on chosen days of the week at a time (server time), on single devices, on all devices of some customers or on all devices (also new ones). A schedule can be paused and resumed. Devices that are offline at that time run the script when they connect, within 24 hours.

What is logged

The script and the start of its output are written to the audit log with your name. Read-only users cannot run scripts.

Scripts have full rights on the computers. Keep the library tidy, give technicians only the customers they need, and test a script on one device before you run it on many.
