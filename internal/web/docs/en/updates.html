Windows updates and software

ControlZit shows which updates are missing on every computer and installs them by hand or on your schedule. Programs are installed and updated with winget.

The overview

Updates lists the devices with missing updates (security updates counted separately), devices waiting for a restart, the last installation and the last search. Agents search for missing updates a few minutes after they start and then twice a day; Search now starts a search at once.

On a device

The Updates tab of a device lists the missing updates with their category and severity and the recently installed ones. Select updates and click Install selected; the installation runs as a task under Activity, which shows the result when it is done. If a restart is needed, the device says so, and you can restart it from its page.

Defender definitions (Security Intelligence Update) come out several times a day, each with a new update ID. When you install one, the agent searches again first and installs the definition version Windows Update offers at that moment.

Automatic installation

The Windows Update part of a policy (for example the customer's policy Default) chooses what the server installs by itself:

  • Off — updates are installed only from the console.
  • Security and critical updates, Defender definitions.
  • All updates except feature upgrades — new Windows versions are never installed automatically.

Choose the days and the hour (server time), or In the maintenance window. Devices that are online then install once that day; offline devices wait for the next scheduled day.

Update ring: with a delay of, for example, 7 days, a device installs an update only 7 days after the server first saw it. Give the test computers a policy with 0 days and the others one with 7 days, and problems show on the test computers first. Defender definitions never wait.

Restart when an update needs it: never automatically; automatically 5 minutes after the installation, with a notice; or Ask the user: the ControlZit icon asks the signed-in user to restart, again every 4 hours, and after the deadline (the days the user may postpone) the server restarts the computer with a 10-minute notice, in the maintenance window if the device has one. The device's Policy tab shows a pending restart and its deadline.

So that updates do not arrive at random times, the agent switches off the automatic installation of Windows Update by policy. When the agent is removed, the earlier settings come back.

Linux

On Linux the agent reads the available package updates through apt (Debian, Ubuntu; security updates from the -security suites) or dnf (RHEL family; security updates from the update information) and installs selected packages. The automatic installation applies to Linux devices too; there, "security updates" are the packages from the security sources.

Programs (winget)

The Programs tab of a Windows device has three parts. Updates available lists the programs winget can update; Update all updates them, or update single programs. Installed lists every program in the Windows list of installed programs, for the computer and for signed-in users, with a filter by name or publisher. Uninstall removes a program silently: Windows Installer (MSI) packages with msiexec /x, Inno Setup and NSIS uninstallers with their silent switch, or the program's own silent command. The result is reported only when the program is really gone; programs without a silent uninstaller are marked and have to be removed on the computer or with a script. Install a program searches the winget community repository (for example 7-Zip or Chrome) and installs it silently for all users. Installing and updating needs winget (App Installer), which comes with current Windows 10 and 11.

Chocolatey can be added as a second public source under Software → Public sources. Install a program then has a source choice (winget or Chocolatey), and Updates available also lists the programs installed through Chocolatey that have a newer version. The Chocolatey client is installed on a device through winget the first time it is needed. Chocolatey packages are maintained by its community and usually download the program from the vendor's site.

Software library

Under Software administrators upload their own installers: a Windows Installer package (.msi) or a setup program (.exe), up to 2 GB, with a name, a version, the arguments for a silent installation and the exit codes that mean success (default 0, 1641 and 3010; the last two mean that a restart completes the installation). For an MSI the agent runs msiexec /i with a log, and the default arguments are /qn /norestart; an EXE needs its own silent switch, for example /S (NSIS), /VERYSILENT /NORESTART (Inno Setup) or /quiet.

Install on devices chooses customers, sites or single Windows devices and starts a job, like a library script: online devices install at once, offline ones when they connect within 24 hours. The agent downloads the installer from the server's agent port and checks it against the SHA-256 in the signed command before it runs it as SYSTEM. The job page shows the result of every device; the log of a Windows Installer package is kept with the result. Technicians install packages on the devices of their customers, also from Install a program on a device's Programs tab.
