Server settings and updates

Administrators find the server's settings under Settings: network and ports, the certificate, time zone, updates of the server and the agents, and the diagnostics for support.

Network and access

Under Settings → Network and access:

  • Console — listen address and port (default :8443) and the allowed networks: one IP address or network per line (CIDR). Connections from other addresses are closed before TLS; the server itself (127.0.0.1) is always allowed. Saving refuses a list that would lock out your own address.
  • Agent endpoint — listen address and port (default :8444, must differ from the console), the networks agents may come from (empty = all) and the public agent address put into installers and enrollment codes.
  • New ports take effect after Restart now (restarts the ControlZit service; agents reconnect by themselves).

If you lock yourself out, run controlzit-server --reset-allowlist on the server (appliance: setup menu, item 5).

Network of the server (appliance)

On the ControlZit appliance the server's own network is set here too: DHCP or a fixed address with network size (e.g. 192.168.1.20/24), gateway, one to three DNS servers and the server name. If the gateway does not answer with the new settings, the previous ones come back by themselves after 30 seconds. On other installations the operating system manages the network.

Time zone

Schedules (updates, scripts, reports) and the times in the console use the server's time zone. Choose it from the list and click Set; the console restarts and is back in a few seconds. Without the root helper (see below), set it on the server: timedatectl set-timezone Europe/Berlin.

Certificate (HTTPS)

Under Settings → Certificate choose the certificate browsers see when they open the console. Agents use their own port and certificate, so changing it never disconnects them.

  • The console's own certificate (self-signed) — works at once; browsers warn about it.
  • Let's Encrypt — a free certificate, renewed automatically 30 days before it expires. Enter the console's public DNS name and an email address, and choose the check:
    • port 80 — the name points to this server and port 80 is reachable from the internet; the server answers on port 80 and redirects browsers to HTTPS;
    • Cloudflare DNS — for servers that are not reachable from the internet; needs a Cloudflare API token with Zone:DNS:Edit for the zone.
  • Upload a certificate from your certificate authority or company CA: the certificate (PEM, with the intermediate certificates) and the private key. The key is stored only on this server.

Updates of the server

Settings → ControlZit updates shows the running version and the newest release. Install updates the server: only releases signed with the ControlZit release key are installed; before installing, the server backs up its database and program, and if the new version does not start it goes back to the old one by itself. The console is away for a minute or two. Optionally new versions are installed automatically in a chosen hour.

Updates, the time zone and the network need the root helper that comes with the Linux packages and the appliance. Without it (e.g. the plain program), update with install.sh or the package of the release.

Diagnostics

Settings → Diagnostics shows where ControlZit writes its logs, the newest lines of the server log (filter by level or text), the root helper's log and the versions. Download diagnostics (ZIP) creates a file for support with the logs, the versions and settings summary, the devices, the alerts and the audit log. Passwords, tokens, enrollment codes and keys are removed from everything shown and from the file; scripts and their output are not included.

Custom fields

Under Settings → Custom fields administrators add their own fields for devices and customers — text, number or date — for example an asset number, the end of the warranty or a contract. Technicians fill them in on the device and customer pages; the API returns the device fields with each device and sets them with PUT /api/v1/devices/{id}/fields.
