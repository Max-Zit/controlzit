Agents installieren

Der Agent ist ein kleiner Dienst auf jedem verwalteten Computer. Er verbindet sich ausgehend mit dem Agent-Port des Servers, meldet Inventar und Messwerte und führt die signierten Befehle der Konsole aus.

Bevor Sie beginnen

  • Agents müssen den Server auf dem Agent-Port erreichen (standardmäßig TCP 8444). Für Computer außerhalb Ihres Netzes öffnen Sie diesen Port in der Firewall und setzen die öffentliche Agent-Adresse unter Einstellungen → Netzwerk und Zugriff (zum Beispiel https://rmm.example.com:8444). Der Konsolen-Port bleibt geschlossen.
  • Wenn Sie die Konsole auf dem Server selbst (localhost) geöffnet haben und keine öffentliche Agent-Adresse gesetzt ist, warnt die Standortseite: Agents würden versuchen, sich mit der Loopback-Adresse des Servers zu verbinden.

Registrierungscodes

Agents treten einem Standort eines Kunden mit einem Registrierungscode bei. Öffnen Sie den Standort unter Kunden und klicken Sie auf Registrierungscode erstellen. Sie wählen, wie lange er gilt (1–365 Tage) und wie viele Computer ihn verwenden dürfen. Der Code (RZ1-…) enthält die Serveradresse und den Fingerabdruck des Serverzertifikats, das Installationsprogramm braucht also nichts weiter. Er wird nur einmal angezeigt; widerrufen Sie ihn, wenn er nicht mehr gebraucht wird.

Windows

Laden Sie das MSI auf der Standortseite herunter (Agent herunterladen (MSI, 64-Bit)) und doppelklicken Sie es und fügen den Code ein, oder installieren Sie es still, zum Beispiel per Gruppenrichtlinie, Intune oder Skript:

msiexec /i rmmzit-agent-x64.msi /qn ENROLLCODE="RZ1-…"

Der Agent läuft als Windows-Dienst RMMZit Agent. Ein kleines Symbol neben der Uhr zeigt, ob er verbunden ist (grün), und öffnet ein Fenster mit dem Server und wer den Computer verwaltet.

Das Symbol, sein Fenster und die Neustartfrage verwenden die Anzeigesprache des Windows des Benutzers (eine der 14 Sprachen der Konsole, sonst Englisch).

Ohne MSI (PowerShell als Administrator):

.\rmmzit-agent.exe enroll --code "RZ1-…"
.\rmmzit-agent.exe install

Linux

Laden Sie den Linux-Agent auf der Standortseite herunter (x86-64 oder ARM64 für Raspberry Pi und ARM-Server), kopieren Sie ihn auf den Rechner und führen Sie ihn als root aus:

chmod +x rmmzit-agent-linux-amd64
sudo ./rmmzit-agent-linux-amd64 install --code "RZ1-…"

Er kopiert sich nach /usr/local/bin/rmmzit-agent, registriert sich und startet den systemd-Dienst rmmzit-agent.

Agent-Updates

Der Server bringt die Agent-Installationsprogramme seiner eigenen Version mit. Unter Einstellungen → Agent-Updates sehen Sie, welche Agents veraltet sind, aktualisieren alle auf einmal oder lassen veraltete Agents sich beim Verbinden selbst aktualisieren. Ein einzelner Agent wird auf seiner Geräteseite aktualisiert. Der Agent lädt das Installationsprogramm über seine eigene verschlüsselte Verbindung und installiert es nur, wenn es zum SHA-256 im signierten Update-Befehl passt. Dort können Sie auch ein anderes Installationsprogramm hochladen (ein MSI oder einen Linux-Agent).

Windows Update auf verwalteten Computern

Der Agent schaltet die automatische Installation von Windows Update per Richtlinie ab, sodass Updates nur von RMMZit kommen, von Hand oder nach Ihrem Zeitplan (siehe Windows-Updates). Die vorherigen Einstellungen werden gespeichert und kehren zurück, wenn der Agent entfernt wird.

Einen Agent entfernen

Löschen Sie das Gerät auf seiner Seite (Gerät entfernen). Ist es online, deinstalliert sich der Agent innerhalb von Sekunden und Windows Update erhält seine eigenen Einstellungen zurück. Ein Offline-Computer kann sich nicht mehr verbinden; deinstallieren Sie den Agent dort von Hand (Windows: Apps → RMMZit Agent → Deinstallieren; Linux: sudo rmmzit-agent uninstall).

Viele Computer: Gruppenrichtlinie und Intune

Erstellen Sie einen Registrierungscode mit genug Verwendungen für alle Computer; die Standortseite zeigt dann, mit diesem Code ausgefüllt:

  • Gruppenrichtlinie: ein PowerShell-Startskript. Legen Sie das MSI auf eine Freigabe, die die Computerkonten (Domänencomputer) lesen dürfen, geben Sie den Pfad ein, kopieren Sie das Skript und fügen Sie es unter Computerkonfiguration → Richtlinien → Windows-Einstellungen → Skripts → Starten → PowerShell-Skripts hinzu. Computer mit dem Agenten (Dienst RMMZitAgent) überspringen es; das Installationsprotokoll ist %windir%\Temp\rmmzit-agent-install.log.
  • Microsoft Intune: Fügen Sie den Agenten als Windows-App (Win32) hinzu: Packen Sie das MSI mit Microsofts IntuneWinAppUtil und verwenden Sie die Installations- und Deinstallationsbefehle, das Installationsverhalten System und die Erkennungsregel (Datei C:\Program Files\RMMZit Agent\rmmzit-agent.exe) von der Standortseite. Nicht als Branchen-MSI hinzufügen: Der Agent aktualisiert sich selbst, und Intune würde wieder die alte Version installieren.
