Server installieren

Wählen Sie einen von vier Wegen. Das fertige VM-Image ist am schnellsten; das Installationsskript passt zu einem vorhandenen Linux-Server.

WegAm besten fürBraucht
1. VM-Image (OVA, qcow2, VHDX)importieren, starten, anmelden, in wenigen MinutenVMware, Proxmox / KVM oder Hyper-V
2. Appliance-ISOeine neue VM oder ein physischer Server, unbeaufsichtigtInternetzugang während der Installation
3. Installationsskriptein vorhandener Debian-, Ubuntu-, AlmaLinux- oder Rocky-Linux-Serverroot und Internetzugang
4. Pakete von Handeigenes PostgreSQL, Konfigurationsverwaltung, Server ohne Internetdas deb- oder rpm-Paket einer Version

Alle Dateien liegen auf der Versionsseite. Geben Sie dem Server 2 vCPU, 2–4 GB RAM und eine Festplatte ab 16 GB.

1. VM-Image

  1. Image importieren:
    • VMware ESXi / Workstation, VirtualBox: controlzit-appliance.ova bereitstellen (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: eine VM ohne Festplatte anlegen (2 vCPU, 2–4 GB RAM, VirtIO-Netzwerk), controlzit-appliance.qcow2 auf den Knoten kopieren und qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm ausführen; die Festplatte als SCSI anhängen und zur Bootplatte machen.
    • Hyper-V: controlzit-appliance-vhdx.zip entpacken und eine VM der Generation 1 mit der VHDX als Festplatte anlegen.
  2. VM starten. Die Festplatte wächst von selbst auf die Größe der virtuellen Festplatte. Der Bildschirm der VM zeigt die Adresse der Konsole und das Einrichtungstoken.
  3. https://<Adresse>:8443 öffnen. Der Browser warnt einmal vor dem selbstsignierten Zertifikat (später unter Einstellungen → Zertifikat ersetzen). Einrichtungstoken eingeben und den ersten Administrator anlegen.

Die Appliance bezieht ihre Adresse per DHCP. Für eine feste Adresse, den Servernamen oder die Zeitzone melden Sie sich am Bildschirm der VM als czadmin an (erstes Passwort controlzit, muss geändert werden): Ein Einrichtungsmenü öffnet sich. Zeitzone und Netzwerk lassen sich später auch in der Konsole ändern.

2. Appliance-ISO

  1. Eine VM oder einen Server von controlzit-appliance.iso starten. Nach 5 Sekunden beginnt die Installation von selbst: Sie löscht die erste Festplatte, installiert Debian, PostgreSQL und ControlZit und braucht Internetzugang (10–20 Minuten).
  2. Nach dem Neustart zeigt der Bildschirm die Konsolenadresse und das Einrichtungstoken, wie beim VM-Image.

3. Installationsskript

Auf einem vorhandenen Linux-Server als root:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

Das Skript installiert PostgreSQL, lädt die neueste Version, prüft ihre Signatur, legt eine Datenbank mit Zufallspasswort an und startet den Dienst. Optionen (nach sh -s --): --version X, --db postgres://… für eine vorhandene Datenbank, --no-auto-updates, um die automatischen Sicherheitsupdates des Betriebssystems ausgeschaltet zu lassen. Ein erneuter Lauf aktualisiert ControlZit und behält die Daten.

4. Pakete von Hand

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Tragen Sie dann die Datenbankadresse in /etc/controlzit/server.env ein (CONTROLZIT_DB=postgres://…) und starten Sie den Dienst mit systemctl enable --now controlzit-server.

Erste Anmeldung

  • Das Einrichtungstoken steht in /var/lib/controlzit/setup-token.txt und im Serverprotokoll (journalctl -u controlzit-server). Es gilt einmal.
  • Jedes Konto braucht eine Authenticator-App (TOTP) und erhält 10 Wiederherstellungscodes. Bewahren Sie sie sicher auf.
  • Die Konsole nimmt standardmäßig nur Verbindungen aus privaten Netzen an. Wenn Sie sich aussperren, führen Sie controlzit-server --reset-allowlist auf dem Server aus (Appliance: Einrichtungsmenü, Punkt 5).

Wo was liegt

PfadWas
/etc/controlzit/server.envKonfiguration: Datenbank, Ports, Update-Quelle (nur für root und den Dienst lesbar)
/var/lib/controlzitDatenverzeichnis: Zertifikate, geheimer Schlüssel, Agent-Installationsprogramme (downloads), Protokolle
/var/lib/controlzit/logs/server.logServerprotokoll; auch in journalctl -u controlzit-server
/var/log/controlzit-helperProtokoll des Root-Helfers (Updates, Zeitzone, Netzwerk)

Sichern Sie die Datenbank zusammen mit /var/lib/controlzit: Der geheime Schlüssel dort entschlüsselt die gespeicherten Passwörter, und die Zertifikate weisen den Server gegenüber seinen Agents aus.
