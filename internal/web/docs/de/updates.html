Windows-Updates und Software

ControlZit zeigt, welche Updates auf jedem Computer fehlen, und installiert sie von Hand oder nach Ihrem Zeitplan. Programme werden mit winget installiert und aktualisiert.

Die Übersicht

Updates listet die Geräte mit fehlenden Updates (Sicherheitsupdates getrennt gezählt), Geräte, die auf einen Neustart warten, die letzte Installation und die letzte Suche. Agents suchen einige Minuten nach dem Start und dann zweimal täglich nach fehlenden Updates; Jetzt suchen startet sofort eine Suche.

Auf einem Gerät

Die Registerkarte Updates eines Geräts listet die fehlenden Updates mit Kategorie und Schweregrad sowie die kürzlich installierten. Wählen Sie Updates aus und klicken Sie auf Auswahl installieren; die Seite zeigt das Ergebnis, wenn es fertig ist. Ist ein Neustart nötig, zeigt das Gerät es an, und Sie können es von seiner Seite neu starten.

Automatische Installation

Unter Einstellungen → Windows-Updates wählen Sie, was der Server selbst installiert:

  • Aus — Updates werden nur über die Konsole installiert.
  • Sicherheits- und kritische Updates, Defender-Definitionen.
  • Alle Updates außer Funktionsupdates — neue Windows-Versionen werden nie automatisch installiert.

Wählen Sie die Tage und die Stunde (Serverzeit). Geräte, die in dieser Stunde online sind, installieren einmal an diesem Tag; Offline-Geräte warten auf den nächsten geplanten Tag. Optional startet der Computer selbst neu, wenn ein Update es erfordert, 5 Minuten nach einem Hinweis an den angemeldeten Benutzer.

Damit Updates nicht zu beliebigen Zeiten kommen, schaltet der Agent die automatische Installation von Windows Update per Richtlinie ab. Wird der Agent entfernt, kehren die früheren Einstellungen zurück.

Linux

Unter Linux liest der Agent die verfügbaren Paketupdates über apt (Debian, Ubuntu; Sicherheitsupdates aus den -security-Quellen) oder dnf (RHEL-Familie; Sicherheitsupdates aus den Update-Informationen) und installiert ausgewählte Pakete. Die automatische Installation gilt auch für Linux-Geräte; dort sind „Sicherheitsupdates“ die Pakete aus den Sicherheitsquellen.

Programme (winget)

Die Registerkarte Programme eines Windows-Geräts listet die installierten Programme, die winget kennt, und die verfügbaren Updates. Alle aktualisieren aktualisiert sie; einzelne Programme lassen sich aktualisieren oder deinstallieren. Programm installieren durchsucht das winget-Community-Repository (zum Beispiel 7-Zip oder Chrome) und installiert still für alle Benutzer. Das Gerät braucht winget (App Installer), das mit aktuellen Windows 10 und 11 kommt.
