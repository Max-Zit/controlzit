Windows-Updates und Software

ControlZit zeigt, welche Updates auf jedem Computer fehlen, und installiert sie von Hand oder nach Ihrem Zeitplan. Programme werden mit winget installiert und aktualisiert.

Die Übersicht

Updates listet die Geräte mit fehlenden Updates (Sicherheitsupdates getrennt gezählt), Geräte, die auf einen Neustart warten, die letzte Installation und die letzte Suche. Agents suchen einige Minuten nach dem Start und dann zweimal täglich nach fehlenden Updates; Jetzt suchen startet sofort eine Suche.

Auf einem Gerät

Die Registerkarte Updates eines Geräts listet die fehlenden Updates mit Kategorie und Schweregrad sowie die kürzlich installierten. Wählen Sie Updates aus und klicken Sie auf Auswahl installieren; die Installation läuft als Aufgabe unter Aktivität, die das Ergebnis zeigt, wenn sie fertig ist. Ist ein Neustart nötig, zeigt das Gerät es an, und Sie können es von seiner Seite neu starten.

Defender-Definitionen (Security Intelligence Update) erscheinen mehrmals täglich, jede mit einer neuen Update-ID. Wenn Sie eine installieren, sucht der Agent zuerst erneut und installiert die Definitionsversion, die Windows Update in diesem Moment anbietet.

Automatische Installation

Der Teil Windows Update einer Richtlinie (zum Beispiel der Richtlinie Default des Kunden) bestimmt, was der Server selbst installiert:

  • Aus — Updates werden nur über die Konsole installiert.
  • Sicherheits- und kritische Updates, Defender-Definitionen.
  • Alle Updates außer Funktionsupdates — neue Windows-Versionen werden nie automatisch installiert.

Wählen Sie die Tage und die Stunde (Serverzeit) oder Im Wartungsfenster. Geräte, die dann online sind, installieren einmal an diesem Tag; Geräte, die offline sind, warten auf den nächsten geplanten Tag.

Update-Ring: Mit einer Verzögerung von zum Beispiel 7 Tagen installiert ein Gerät ein Update erst 7 Tage, nachdem der Server es zuerst gesehen hat. Geben Sie den Testcomputern eine Richtlinie mit 0 Tagen und den anderen eine mit 7 Tagen, dann zeigen sich Probleme zuerst auf den Testcomputern. Defender-Definitionen warten nie.

Neustart, wenn ein Update ihn braucht: nie automatisch; automatisch 5 Minuten nach der Installation mit Hinweis; oder Benutzer fragen: Das ControlZit-Symbol bittet den angemeldeten Benutzer um einen Neustart, erneut alle 4 Stunden, und nach der Frist (die Tage, die der Benutzer verschieben darf) startet der Server den Computer mit 10 Minuten Vorwarnung neu, im Wartungsfenster, wenn das Gerät eines hat. Der Reiter Richtlinie des Geräts zeigt einen ausstehenden Neustart und seine Frist.

Damit Updates nicht zu beliebigen Zeiten kommen, schaltet der Agent die automatische Installation von Windows Update per Richtlinie ab. Wird der Agent entfernt, kehren die früheren Einstellungen zurück.

Linux

Unter Linux liest der Agent die verfügbaren Paketupdates über apt (Debian, Ubuntu; Sicherheitsupdates aus den -security-Quellen) oder dnf (RHEL-Familie; Sicherheitsupdates aus den Update-Informationen) und installiert ausgewählte Pakete. Die automatische Installation gilt auch für Linux-Geräte; dort sind „Sicherheitsupdates“ die Pakete aus den Sicherheitsquellen.

Programme (winget)

Die Registerkarte Programme eines Windows-Geräts hat drei Teile. Updates verfügbar listet die Programme, die winget aktualisieren kann; Alle aktualisieren aktualisiert sie, oder Sie aktualisieren einzelne Programme. Installiert listet jedes Programm aus der Windows-Liste der installierten Programme, für den Computer und für angemeldete Benutzer, mit einem Filter nach Name oder Herausgeber. Deinstallieren entfernt ein Programm still: Windows-Installer-Pakete (MSI) mit msiexec /x, Inno-Setup- und NSIS-Deinstallationsprogramme mit ihrem Schalter für die stille Ausführung oder mit dem eigenen stillen Befehl des Programms. Das Ergebnis wird erst gemeldet, wenn das Programm wirklich entfernt ist; Programme ohne stilles Deinstallationsprogramm sind gekennzeichnet und müssen am Computer oder mit einem Skript entfernt werden. Programm installieren durchsucht das winget-Community-Repository (zum Beispiel 7-Zip oder Chrome) und installiert still für alle Benutzer. Installieren und Aktualisieren braucht winget (App Installer), das mit aktuellem Windows 10 und 11 kommt.

Chocolatey kann unter Software → Öffentliche Quellen als zweite öffentliche Quelle hinzugefügt werden. Programm installieren bietet dann eine Quellenauswahl (winget oder Chocolatey), und Updates verfügbar listet auch die über Chocolatey installierten Programme mit einer neueren Version. Der Chocolatey-Client wird über winget auf einem Gerät installiert, wenn er dort zum ersten Mal gebraucht wird. Chocolatey-Pakete werden von der Community gepflegt und laden das Programm meist von der Website des Herstellers.

Softwarebibliothek

Unter Software laden Administratoren eigene Installationsprogramme hoch: ein Windows-Installer-Paket (.msi) oder ein Setup-Programm (.exe), bis 2 GB, mit Name, Version, den Argumenten für eine stille Installation und den Exit-Codes, die Erfolg bedeuten (Standard 0, 1641 und 3010; die letzten beiden bedeuten, dass ein Neustart die Installation abschließt). Bei einem MSI führt der Agent msiexec /i mit Protokoll aus, die Standardargumente sind /qn /norestart; ein EXE braucht seinen eigenen Schalter, zum Beispiel /S (NSIS), /VERYSILENT /NORESTART (Inno Setup) oder /quiet.

Auf Geräten installieren wählt Kunden, Standorte oder einzelne Windows-Geräte und startet einen Auftrag wie bei einem Bibliotheksskript: Online-Geräte installieren sofort, Offline-Geräte, wenn sie sich innerhalb von 24 Stunden verbinden. Der Agent lädt das Installationsprogramm vom Agent-Port des Servers und prüft es gegen den SHA-256 im signierten Befehl, bevor er es als SYSTEM ausführt. Die Auftragsseite zeigt das Ergebnis jedes Geräts; das Protokoll eines Windows-Installer-Pakets wird mit dem Ergebnis gespeichert. Techniker installieren Pakete auf den Geräten ihrer Kunden, auch über Programm installieren auf der Registerkarte Programme eines Geräts.

Schwachstellen

Unter Schwachstellen schaltet ein Administrator die Prüfung der installierten Programme ein. Alle 6 Stunden gleicht der Server sie mit öffentlichen Schwachstellendatenbanken ab: NVD für verbreitete Windows-Programme (Browser, PDF-Reader, Packprogramme, Fernzugriffs- und Entwicklungswerkzeuge und andere) und OSV für die Pakete von Debian und Ubuntu. Gesendet werden nur Programmnamen und Versionen, nie Gerätedaten. Ein optionaler kostenloser NVD-API-Schlüssel macht die erste Prüfung schneller.

Die Seite listet die betroffenen Programme und Versionen mit der Zahl der Schwachstellen nach Schweregrad und den Geräten; der Reiter Schwachstellen eines Geräts listet jede mit einem Link zu ihrer Beschreibung. Ein Update des Programms behebt sie. Mit Alarm, wenn ein Programm eine kritische Schwachstelle hat in den Alarmregeln einer Richtlinie öffnen kritische (CVSS 9 oder mehr) einen Alarm. Windows selbst decken die Windows-Updates ab, nicht diese Prüfung.

Schwachstellen von Debian- und Ubuntu-Paketen, für die es im Release des Geräts noch keine Korrektur gibt, sind ausgeblendet, bis Sie sie anzeigen; jeder Fund zeigt die Version, die ihn behebt.
