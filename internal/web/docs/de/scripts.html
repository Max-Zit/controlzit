Skripte und geplante Aufträge

Führen Sie PowerShell, cmd, bash oder sh auf einem Gerät, auf vielen Geräten gleichzeitig oder nach Zeitplan aus. Skripte laufen als SYSTEM (Windows) oder root (Linux), ohne Fenster.

Auf einem Gerät

Öffnen Sie auf einer Geräteseite Skripte, wählen Sie die Shell, schreiben Sie das Skript (oder laden Sie eines aus der Bibliothek) und setzen Sie ein Zeitlimit (5–1500 Sekunden). Die Seite zeigt Exitcode und Ausgabe (das erste 1 MB), wenn das Skript in wenigen Sekunden endet; ein längeres Skript läuft unter Aktivität weiter, wo es auch angehalten werden kann. Frühere Läufe bleiben in der Liste; Bearbeiten und erneut ausführen öffnet einen Lauf als neues Skript.

Skriptbibliothek

Speichern Sie häufig verwendete Skripte unter Skripte → Skriptbibliothek mit Name und Beschreibung. Von dort führen Sie ein Skript auf ausgewählten Geräten, auf allen Geräten einiger Kunden oder auf allen Geräten aus.

Aufträge

Ein Bibliotheksskript auf mehreren Geräten auszuführen erzeugt einen Auftrag. Die Auftragsseite zeigt jedes Gerät mit seinem Status (wartend, läuft, erfolgreich, fehlgeschlagen, abgelaufen) und seiner Ausgabe. Exitcode 0 gilt als Erfolg. Offline-Geräte führen das Skript beim Verbinden aus, innerhalb von 24 Stunden; danach gelten sie als abgelaufen.

Zeitpläne

Ein Skript der Bibliothek kann nach Zeitplan laufen: an gewählten Wochentagen zu einer Uhrzeit (Serverzeit), auf einzelnen Geräten, auf allen Geräten einiger Kunden oder auf allen Geräten (auch neuen). Ein Zeitplan kann pausiert und fortgesetzt werden. Geräte, die zu diesem Zeitpunkt offline sind, führen das Skript beim Verbinden aus, innerhalb von 24 Stunden.

Was protokolliert wird

Das Skript und der Anfang seiner Ausgabe werden mit Ihrem Namen im Prüfprotokoll vermerkt. Nur-Lesen-Benutzer können keine Skripte ausführen.

Skripte haben volle Rechte auf den Computern. Halten Sie die Bibliothek ordentlich, geben Sie Technikern nur die Kunden, die sie brauchen, und testen Sie ein Skript auf einem Gerät, bevor Sie es auf vielen ausführen.
