Primi passi

ControlZit è uno strumento di monitoraggio e gestione remota (RMM) self-hosted. Da una console web sul tuo server controlli e gestisci i computer Windows e Linux dei tuoi clienti: inventario, monitoraggio e avvisi, desktop remoto, terminale, file, script, aggiornamenti di Windows, software e report.

Come funziona

  • Il server gira su una macchina Linux (di solito una piccola VM) con PostgreSQL. Ha due porte: la console (interfaccia web e API, TCP 8443) e l'endpoint degli agent (TCP 8444).
  • Gli agent girano come servizio su ogni computer gestito. Si connettono in uscita alla porta degli agent; i computer non hanno bisogno di porte aperte. Un agent si fida del server tramite l'impronta del suo certificato, che fissa alla registrazione.
  • Ogni comando a un agent è firmato dal server e verificato dall'agent, e ogni azione è scritta nel log di audit a prova di manomissione.

La console controlla ogni computer gestito. Rendila raggiungibile solo dalle tue reti (impostazione predefinita) e apri solo la porta degli agent dove servono. Vedi Sicurezza.

Primi passi

  1. Installa il server: importa l'immagine VM pronta, avvia l'ISO dell'appliance o esegui lo script di installazione su un server Linux. Vedi Installare il server.
  2. Crea il primo amministratore con il token di configurazione mostrato dal server e configura l'accesso a due fattori con un'app di autenticazione.
  3. Controlla l'indirizzo degli agent in Impostazioni → Rete e accesso: gli agent devono raggiungere il server tramite l'indirizzo pubblico degli agent o il nome host della console.
  4. Aggiungi un cliente e una sede in Clienti, poi crea un codice di registrazione nella sede.
  5. Installa l'agent sui computer di quella sede con il codice. Vedi Installare gli agent.
  6. Configura gli avvisi in Impostazioni → Monitoraggio e avvisi e, se vuoi, l'installazione automatica degli aggiornamenti di Windows.
  7. Aggiungi i tuoi tecnici in Utenti, oppure collega Active Directory / LDAP o il Single Sign-On. Vedi Utenti, ruoli e accesso.

Requisiti

  • Server: 2 vCPU, 2–4 GB di RAM, disco da 16 GB; Debian 12+, Ubuntu 22.04+, AlmaLinux o Rocky Linux 9+ (o l'appliance pronta).
  • Agent Windows: Windows 10 / 11, Windows Server 2016 e successivi, 64 bit.
  • Agent Linux: distribuzioni con systemd, x86-64 o ARM64 (Raspberry Pi e server ARM). Aggiornamenti tramite apt o dnf.
  • Browser: Chrome, Edge, Firefox o Safari recente.
