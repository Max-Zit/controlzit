Installare gli agent

L'agent è un piccolo servizio su ogni computer gestito. Si connette in uscita alla porta degli agent del server, invia inventario e metriche ed esegue i comandi firmati della console.

Prima di iniziare

  • Gli agent devono raggiungere il server sulla porta degli agent (TCP 8444 per impostazione predefinita). Per i computer fuori dalla tua rete, apri questa porta sul firewall e imposta l'indirizzo pubblico degli agent in Impostazioni → Rete e accesso (ad esempio https://rmm.example.com:8444). La porta della console resta chiusa.
  • Se hai aperto la console sul server stesso (localhost) e non è impostato un indirizzo pubblico degli agent, la pagina della sede ti avvisa: gli agent tenterebbero di connettersi all'indirizzo di loopback del server.

Codici di registrazione

Gli agent entrano in una sede di un cliente con un codice di registrazione. Apri la sede in Clienti e fai clic su Crea codice di registrazione. Scegli quanto dura (1–365 giorni) e quanti computer possono usarlo. Il codice (CZ1-…) contiene l'indirizzo del server e l'impronta del suo certificato, quindi l'installer non ha bisogno d'altro. Viene mostrato una sola volta; revocalo quando non serve più.

Windows

Scarica l'MSI dalla pagina della sede (Scarica l'agent (MSI, 64 bit)) e fai doppio clic e incolla il codice, oppure installalo in modo silenzioso, ad esempio con Criteri di gruppo, Intune o uno script:

msiexec /i controlzit-agent-x64.msi /qn ENROLLCODE="CZ1-…"

L'agent gira come servizio Windows ControlZit Agent. Una piccola icona accanto all'orologio mostra se è connesso (verde) e apre una finestra con il server e chi gestisce il computer.

L'icona, la sua finestra e la domanda di riavvio usano la lingua di visualizzazione di Windows dell'utente (una delle 14 lingue della console, altrimenti l'inglese).

Senza l'MSI (PowerShell come amministratore):

.\controlzit-agent.exe enroll --code "CZ1-…"
.\controlzit-agent.exe install

Linux

Scarica l'agent Linux dalla pagina della sede (x86-64, o ARM64 per Raspberry Pi e server ARM), copialo sulla macchina ed eseguilo come root:

chmod +x controlzit-agent-linux-amd64
sudo ./controlzit-agent-linux-amd64 install --code "CZ1-…"

Si copia in /usr/local/bin/controlzit-agent, si registra e avvia il servizio systemd controlzit-agent.

Aggiornamenti degli agent

Il server contiene gli installer degli agent della sua versione. In Impostazioni → Aggiornamenti degli agent vedi quali agent sono obsoleti, li aggiorni tutti insieme o lasci che gli agent obsoleti si aggiornino da soli quando si connettono. Un singolo agent si aggiorna dalla pagina del dispositivo. L'agent scarica l'installer tramite la propria connessione cifrata e lo installa solo se corrisponde allo SHA-256 del comando di aggiornamento firmato. Lì puoi anche caricare un altro installer (un MSI o un agent Linux).

Windows Update sui computer gestiti

L'agent disattiva tramite criterio l'installazione automatica di Windows Update, così gli aggiornamenti arrivano solo da ControlZit, a mano o secondo la tua pianificazione (vedi Aggiornamenti di Windows). Le impostazioni precedenti vengono salvate e tornano quando l'agent viene rimosso.

Rimuovere un agent

Elimina il dispositivo dalla sua pagina (Rimuovi dispositivo). Se è online, l'agent si disinstalla in pochi secondi e Windows Update recupera le proprie impostazioni. Un computer offline non può più connettersi; disinstalla lì l'agent a mano (Windows: App → ControlZit Agent → Disinstalla; Linux: sudo controlzit-agent uninstall).

Molti computer: Criteri di gruppo e Intune

Crea un codice di registrazione con abbastanza utilizzi per tutti i computer; la pagina della sede mostra allora, compilati con quel codice:

  • Criteri di gruppo: uno script di avvio PowerShell. Metti l'MSI in una condivisione che gli account computer (Computer del dominio) possono leggere, inserisci il percorso, copia lo script e aggiungilo in Configurazione computer → Criteri → Impostazioni di Windows → Script → Avvio → Script di PowerShell. I computer che hanno l'agente (servizio ControlZitAgent) lo saltano; il log di installazione è %windir%\Temp\controlzit-agent-install.log.
  • Microsoft Intune: aggiungi l'agente come app Windows (Win32): crea il pacchetto dell'MSI con IntuneWinAppUtil di Microsoft e usa i comandi di installazione e disinstallazione, il comportamento di installazione Sistema e la regola di rilevamento (file C:\Program Files\ControlZit Agent\controlzit-agent.exe) della pagina della sede. Non aggiungerlo come MSI line-of-business: l'agente si aggiorna da solo e Intune reinstallerebbe la versione vecchia.
