Desktop remoto, terminale e file

Aiuta gli utenti e ripara i computer dal browser: nessun software dalla tua parte, nessuna porta aperta dalla loro. Tutto passa per la connessione cifrata dell'agent e viene scritto nel log di audit.

Desktop remoto

Apri un dispositivo e fai clic su Desktop remoto (o aprilo in una finestra separata). Vedi lo schermo e lo controlli con mouse e tastiera.

  • Tastiera: fai clic sullo schermo per digitare; i tasti vanno al computer remoto con il suo layout di tastiera. Invia Ctrl+Alt+Canc e Invia testo (digita un testo, ad esempio una password lunga) sono nella barra degli strumenti. A schermo intero anche scorciatoie come Ctrl+W o il tasto Windows vanno al computer remoto; tieni premuto Esc per uscire dallo schermo intero.
  • Qualità: Veloce, Bilanciata o Nitida, a seconda della connessione.
  • Monitor: scegli un monitor o tutti.
  • Le schermate di accesso e UAC sono visibili e utilizzabili, quindi puoi accedere e confermare le richieste di amministratore.

Appunti e file

Sui computer Windows il testo copiato va in entrambe le direzioni con Ctrl+C e Ctrl+V. I file copiati nel tuo Esplora file si incollano sul computer remoto con Ctrl+V. I file copiati sul computer remoto vengono offerti come download (Scarica i file copiati), perché un browser non può mettere file nei tuoi appunti. Lo scambio degli appunti si può disattivare in Impostazioni → Desktop remoto.

Avviso sullo schermo remoto

Per impostazione predefinita la persona al computer vede in cima allo schermo una barra con il tuo nome mentre sei connesso. Tu non vedi la barra nell'immagine. Si può disattivare in Impostazioni → Desktop remoto; ogni sessione viene comunque scritta nel log di audit.

Linux

Il desktop remoto funziona sui desktop Linux con X11 (Xorg). Wayland non consente a un servizio in background di vedere o controllare lo schermo: accedi lì con una sessione X11 o usa il terminale. Senza desktop grafico, usa il terminale.

Terminale (Linux, Windows)

Terminale apre una shell root del dispositivo nel browser. Fai clic all'interno per digitare; copia selezionando il testo, incolla con Ctrl+Maiusc+V o Invia testo. L'inizio e la fine della sessione vengono scritti nel log di audit. Su Windows usa gli Script.

Su Windows (agenti 0.12 e successivi, Windows 10 1809 / Server 2019 e successivi) il terminale è Windows PowerShell eseguito come SYSTEM su una pseudoconsole. Uscendo dalla pagina terminano la shell e tutti i programmi che ha avviato.

File

File esplora le unità del computer senza collegarsi allo schermo. Carica file (fino a 4 GB), scarica file, scarica una cartella o una selezione come ZIP, crea cartelle, rinomina ed elimina. L'agent esegue ogni operazione sui file come SYSTEM (Windows) o root (Linux); ognuna viene scritta nel log di audit con il tuo nome.

Processi e servizi

Processi elenca i programmi in esecuzione con memoria, thread e sessione e termina un processo. Servizi elenca i servizi (servizi Windows o unità systemd) e li avvia, arresta o riavvia. L'agent ControlZit si protegge da solo: non può essere arrestato o terminato dalla console.

Editor del registro (Windows)

La scheda Registry di un dispositivo Windows sfoglia il registro: apri una chiave dal suo percorso (per esempio HKLM\SOFTWARE\Vendor) o naviga dalle radici HKLM, HKU, HKCR e HKCC. I valori si possono aggiungere, modificare ed eliminare (REG_SZ, REG_EXPAND_SZ, REG_DWORD, REG_QWORD, REG_MULTI_SZ; numeri in decimale o in esadecimale 0x); i valori binari sono mostrati in esadecimale. Le chiavi si possono creare ed eliminare con tutto il contenuto; le radici, le chiavi subito sotto e i rami propri del sistema sono protetti. Ogni modifica viene scritta nel registro di controllo con il valore sostituito. I registri degli utenti sono sotto HKU (per SID); HKCU sarebbe quello di SYSTEM. Agenti 0.12 e successivi.

Attività pianificate (Windows)

La scheda Scheduled tasks elenca le attività dell'Utilità di pianificazione con stato, ultima esecuzione e risultato, prossima esecuzione, account e comando. Le attività di Windows (sotto \Microsoft\) sono nascoste finché non le includi. Un'attività si può avviare, terminare, attivare, disattivare ed eliminare; ogni azione viene registrata. Agenti 0.12 e successivi.
