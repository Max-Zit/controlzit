Impostazioni e aggiornamenti del server

Gli amministratori trovano le impostazioni del server in Impostazioni: rete e porte, certificato, fuso orario, aggiornamenti di server e agent e la diagnostica per l'assistenza.

Rete e accesso

In Impostazioni → Rete e accesso:

  • Console — indirizzo e porta di ascolto (predefinita :8443) e le reti consentite: un indirizzo IP o una rete per riga (CIDR). Le connessioni da altri indirizzi vengono chiuse prima di TLS; il server stesso (127.0.0.1) è sempre consentito. Il salvataggio rifiuta un elenco che escluderebbe il tuo indirizzo.
  • Endpoint degli agent — indirizzo e porta di ascolto (predefinita :8444, diversa dalla console), le reti da cui possono arrivare gli agent (vuoto = tutte) e l'indirizzo pubblico degli agent inserito negli installer e nei codici di registrazione.
  • Le nuove porte valgono dopo Riavvia ora (riavvia il servizio ControlZit; gli agent si riconnettono da soli).

Se resti chiuso fuori, esegui controlzit-server --reset-allowlist sul server (appliance: menu di configurazione, voce 5).

Rete del server (appliance)

Sull'appliance ControlZit qui si imposta anche la rete del server stesso: DHCP o un indirizzo fisso con dimensione della rete (ad es. 192.168.1.20/24), gateway, da uno a tre server DNS e nome del server. Se il gateway non risponde con le nuove impostazioni, quelle precedenti tornano da sole dopo 30 secondi. Sulle altre installazioni la rete è gestita dal sistema operativo.

Fuso orario

Le pianificazioni (aggiornamenti, script, report) e gli orari nella console usano il fuso orario del server. Sceglilo dall'elenco e fai clic su Imposta; la console si riavvia e torna in pochi secondi. Senza l'helper root (vedi sotto), impostalo sul server: timedatectl set-timezone Europe/Rome.

Certificato (HTTPS)

In Impostazioni → Certificato scegli il certificato che i browser vedono aprendo la console. Gli agent usano una porta e un certificato propri, quindi cambiarlo non li disconnette mai.

  • Il certificato proprio della console (autofirmato) — funziona subito; i browser avvisano.
  • Let's Encrypt — un certificato gratuito, rinnovato automaticamente 30 giorni prima della scadenza. Inserisci il nome DNS pubblico della console e un indirizzo email e scegli la verifica:
    • porta 80 — il nome punta a questo server e la porta 80 è raggiungibile da Internet; il server risponde sulla porta 80 e reindirizza i browser a HTTPS;
    • DNS Cloudflare — per server non raggiungibili da Internet; richiede un token API di Cloudflare con Zone:DNS:Edit per la zona.
  • Carica un certificato dalla tua autorità di certificazione o CA aziendale: il certificato (PEM, con gli intermedi) e la chiave privata. La chiave viene salvata solo su questo server.

Aggiornamenti del server

Impostazioni → Aggiornamenti di ControlZit mostra la versione in esecuzione e l'ultima release. Installa aggiorna il server: vengono installate solo release firmate con la chiave di release di ControlZit; prima dell'installazione il server salva database e programma, e se la nuova versione non si avvia torna da solo a quella vecchia. La console non è disponibile per un paio di minuti. Facoltativamente le nuove versioni si installano automaticamente in un'ora scelta.

Aggiornamenti, fuso orario e rete richiedono l'helper root incluso nei pacchetti Linux e nell'appliance. Senza di esso (ad es. il programma da solo) aggiorna con install.sh o con il pacchetto della release.

Diagnostica

Impostazioni → Diagnostica mostra dove ControlZit scrive i suoi log, le righe più recenti del log del server (filtro per livello o testo), il log dell'helper root e le versioni. Scarica la diagnostica (ZIP) crea un file per l'assistenza con i log, le versioni e un riepilogo delle impostazioni, i dispositivi, gli avvisi e il log di audit. Password, token, codici di registrazione e chiavi vengono rimossi da tutto ciò che è mostrato e dal file; gli script e il loro output non sono inclusi.
