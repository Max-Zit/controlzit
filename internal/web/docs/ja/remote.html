リモートデスクトップ、ターミナル、ファイル

ブラウザーからユーザーを支援し、コンピューターを修理できます。こちら側にソフトウェアは不要で、相手側でポートを開く必要もありません。すべてエージェントの暗号化接続を経由し、監査ログに記録されます。

リモートデスクトップ

デバイスを開いてリモートデスクトップをクリックします（別ウィンドウでも開けます）。画面が表示され、マウスとキーボードで操作できます。

  • キーボード: 画面をクリックすると入力できます。キーはリモートコンピューター自身のキーボード配列で送られます。Ctrl+Alt+Del を送信とテキストを送信（長いパスワードなどのテキストを入力）はツールバーにあります。全画面では Ctrl+W や Windows キーなどのショートカットもリモートコンピューターに送られます。全画面を終了するには Esc を長押しします。
  • 画質: 接続に応じて高速、バランス、高画質を選びます。
  • モニター: 1 台またはすべてのモニターを選べます。
  • サインイン画面と UAC 画面も表示・操作できるため、サインインや管理者確認ができます。

クリップボードとファイル

Windows コンピューターでは、コピーしたテキストを Ctrl+C と Ctrl+V で双方向にやり取りできます。エクスプローラーでコピーしたファイルは、リモートコンピューターで Ctrl+V で貼り付けられます。リモートコンピューターでコピーしたファイルはダウンロードとして提供されます（コピーしたファイルをダウンロード）。ブラウザーはファイルをあなたのクリップボードに置けないためです。クリップボードのやり取りは設定 → リモートデスクトップでオフにできます。

リモート画面の通知

既定では、接続中はコンピューターの前の人に、画面上部にあなたの名前を表示するバーが見えます。このバーはあなたの画像には映りません。設定 → リモートデスクトップでオフにできますが、どちらの場合もすべてのセッションは監査ログに記録されます。

Linux

リモートデスクトップは X11（Xorg）の Linux デスクトップで動作します。Wayland はバックグラウンドサービスが画面を表示・操作することを許可しないため、X11 セッションでサインインするかターミナルを使用してください。グラフィカルデスクトップがない場合はターミナルを使用します。

ターミナル（Linux）

ターミナルはデバイスの root シェルをブラウザーで開きます。クリックすると入力できます。テキストを選択するとコピー、Ctrl+Shift+V またはテキストを送信で貼り付けます。セッションの開始と終了は監査ログに記録されます。Windows ではスクリプトを使用してください。

ファイル

ファイルでは、画面に接続せずにコンピューターのドライブを参照できます。ファイルのアップロード（最大 4 GB）、ダウンロード、フォルダーや選択項目の ZIP ダウンロード、フォルダー作成、名前の変更、削除ができます。ファイル操作はすべてエージェントが SYSTEM（Windows）または root（Linux）として実行し、あなたの名前で監査ログに記録されます。

プロセスとサービス

プロセスは実行中のプログラムをメモリ、スレッド、セッションとともに一覧表示し、プロセスを終了します。サービスはサービス（Windows サービスまたは systemd ユニット）を一覧表示し、開始、停止、再起動します。ControlZit エージェントは自身を保護しており、コンソールから停止・終了することはできません。
