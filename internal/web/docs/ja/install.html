サーバーのインストール

4 つの方法から選べます。既製の VM イメージが最も速く、インストールスクリプトは既存の Linux サーバーに適しています。

方法適した用途必要なもの
1. VM イメージ（OVA、qcow2、VHDX）数分でインポート、起動、サインインVMware、Proxmox / KVM、Hyper-V
2. アプライアンス ISO新しい VM や物理サーバーへの無人インストールインストール中のインターネット接続
3. インストールスクリプト既存の Debian、Ubuntu、AlmaLinux、Rocky Linux サーバーroot とインターネット接続
4. パッケージを手動で独自の PostgreSQL、構成管理、オフラインのサーバーリリースの deb または rpm パッケージ

すべてのファイルはリリースページにあります。サーバーには 2 vCPU、2～4 GB RAM、16 GB 以上のディスクを割り当ててください。

1. VM イメージ

  1. イメージをインポートします:
    • VMware ESXi / Workstation、VirtualBox: controlzit-appliance.ova をデプロイします（Create / Register VM → Deploy a virtual machine from an OVF or OVA file）。
    • Proxmox VE: ディスクなしの VM（2 vCPU、2～4 GB RAM、VirtIO ネットワーク）を作成し、controlzit-appliance.qcow2 をノードにコピーして qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm を実行します。ディスクを SCSI として接続し、起動ディスクにします。
    • Hyper-V: controlzit-appliance-vhdx.zip を展開し、その VHDX をディスクとする第 1 世代の VM を作成します。
  2. VM を起動します。ディスクは仮想ディスクのサイズまで自動で拡張されます。VM の画面にコンソールのアドレスとセットアップトークンが表示されます。
  3. https://<アドレス>:8443 を開きます。ブラウザーが自己署名証明書について一度警告します（後で設定 → 証明書で置き換えてください）。トークンを入力し、最初の管理者を作成します。

アプライアンスは DHCP でアドレスを取得します。固定アドレス、サーバー名、タイムゾーンを設定するには、VM の画面で czadmin（初期パスワード controlzit、変更が必要）としてサインインすると、セットアップメニューが開きます。タイムゾーンとネットワークは後でコンソールからも変更できます。

2. アプライアンス ISO

  1. VM またはサーバーを controlzit-appliance.iso から起動します。5 秒後にインストールが自動で始まり、最初のディスクを消去して Debian、PostgreSQL、ControlZit をインストールします。インターネット接続が必要です（10～20 分）。
  2. 再起動後、VM イメージと同様に画面にコンソールのアドレスとセットアップトークンが表示されます。

3. インストールスクリプト

既存の Linux サーバーで root として実行します:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

スクリプトは PostgreSQL をインストールし、最新リリースをダウンロードして署名を検証し、ランダムなパスワードでデータベースを作成してサービスを開始します。オプション（sh -s -- の後）: --version X、既存のデータベース用の --db postgres://…、OS の自動セキュリティ更新をオフのままにする --no-auto-updates。再実行すると ControlZit を更新し、データは保持されます。

4. パッケージを手動で

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

次にデータベースのアドレスを /etc/controlzit/server.env（CONTROLZIT_DB=postgres://…）に書き、systemctl enable --now controlzit-server でサービスを開始します。

最初のサインイン

  • セットアップトークンは /var/lib/controlzit/setup-token.txt とサーバーログ（journalctl -u controlzit-server）にあります。使えるのは 1 回だけです。
  • すべてのアカウントに認証アプリ（TOTP）が必要で、10 個の回復コードが発行されます。安全に保管してください。
  • 既定ではコンソールはプライベートネットワークからの接続のみ受け付けます。締め出された場合は、サーバーで controlzit-server --reset-allowlist を実行します（アプライアンス: セットアップメニューの項目 5）。

ファイルの場所

パス内容
/etc/controlzit/server.env構成: データベース、ポート、更新元（root とサービスのみ読み取り可能）
/var/lib/controlzitデータディレクトリ: 証明書、秘密鍵、エージェントのインストーラー（downloads）、ログ
/var/lib/controlzit/logs/server.logサーバーログ。journalctl -u controlzit-server にも記録
/var/log/controlzit-helperroot ヘルパーのログ（更新、タイムゾーン、ネットワーク）

データベースは /var/lib/controlzit と一緒にバックアップしてください。そこにある秘密鍵が保存済みパスワードを復号し、証明書がエージェントに対してサーバーを識別します。
