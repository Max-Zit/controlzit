トラブルシューティングと FAQ

よくある質問と、最初に確認すべきこと。サポートに問い合わせるときは、設定 → 診断で診断情報をダウンロードしてください。

コンソールにアクセスできない

  • アドレスが許可されたネットワークに含まれていない可能性があります。接続は TLS の前に切断されるため、ブラウザーには接続エラーが表示されます。サーバーで rmmzit-server --reset-allowlist を実行して（アプライアンス: セットアップメニューの項目 5）、すべてのプライベートネットワークを再び許可します。
  • ポートを変更した後は、新しいポートでコンソールを開きます。
  • サーバーのサービスを確認します: systemctl status rmmzit-server と journalctl -u rmmzit-server。

サインインの問題

  • コードが間違っている — 電話の時刻が正しい必要があります（自動設定の時刻）。
  • 電話を紛失した — 回復コードでサインインします。他の管理者が 2 段階サインインをリセットできます。
  • 失敗回数が多すぎる — アドレスが一定時間ブロックされます。管理者は設定 → サインインとセキュリティでブロックを解除できます。サーバー自身からのサインインはブロックされません。
  • LDAP / シングルサインオン — LDAP ページのテストを使い、プロバイダーが送るグループを確認します。詳細はサーバーログにあります。

エージェントが接続しない

  • コンピューターからエージェントのポートに到達できますか? Windows では Test-NetConnection rmm.example.com -Port 8444。
  • エージェント用の公開アドレスは正しいですか? コンソールを localhost で開いていたときに作成したコードは、エージェントを誤ったサーバーに向けます。アドレスを設定して新しいコードを作成してください。
  • コードはまだ有効で、使い切っていませんか?
  • エージェントのログ: Windows は C:\ProgramData\RMMZit Agent\agent.log、Linux は /var/lib/rmmzit-agent/agent.log と journalctl -u rmmzit-agent。接続中のデバイスなら、コンソールのファイルから開けます。Windows では時計の横のアイコンが接続状態を示します。

リモートデスクトップに何も表示されない

  • Wayland の Linux は表示できません。X11（Xorg）セッションでサインインするか、ターミナルを使用してください。
  • デスクトップのない Linux: ターミナルを使用してください。
  • クリップボード経由のファイルコピーには、Windows コンピューターにサインイン中のユーザーが必要です。

Windows 更新がインストールされない

  • デバイスのポリシー タブで自動インストールを確認します: Windows Update を設定しているポリシー、曜日、時刻、モード。その時間帯にデバイスがオンラインである必要があります。
  • デバイスの更新タブに、前回の検索とそのエラー（ある場合）が表示されます。

アラートメールが届かない

設定 → 監視とアラートのテストメールを送信を使ってください。メッセージにサーバーの応答が表示されます。パスワードは STARTTLS または TLS でのみ送信されます。

FAQ

RMMZit にクラウドサービスは必要ですか?

いいえ。すべてお使いのサーバーで動作し、MaxZit には何も送信されません。サーバーは新しいリリースの確認のために GitHub にアクセスするだけです。

RMMZit をバックアップするには?

設定 → コンソールのバックアップで、サーバーは毎日データベース、秘密鍵、証明書をバックアップします。必要に応じて暗号化し、SFTP サーバーにコピーできます。サーバーの外にもコピーを保管してください。秘密鍵がないと保存されたパスワードを復号できず、エージェントは新しいサーバーを信頼しません。

サーバーを新しいマシンに移行できますか?

はい。新しいマシンに RMMZit をインストールし、そこでコンソールのバックアップを復元します(rmmzit-server -restore ファイル、アプライアンスではセットアップメニューの項目 7)。同じアドレスを使うか、エージェント用の公開アドレスを変更して古い名前を新しいマシンに向けてください。バックアップにはサーバーの証明書が含まれるため、エージェントはそのまま動作します。

macOS 用のエージェントはありますか?

まだありません。Windows と Linux（x86-64、ARM64）に対応しています。
