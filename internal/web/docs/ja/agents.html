エージェントのインストール

エージェントは管理対象の各コンピューターで動く小さなサービスです。サーバーのエージェントポートへ送信接続し、インベントリと計測値を報告し、コンソールからの署名付きコマンドを実行します。

始める前に

  • エージェントはエージェントポート（既定は TCP 8444）でサーバーに到達できる必要があります。社外のコンピューター向けには、ファイアウォールでこのポートを開き、設定 → ネットワークとアクセスでエージェント用の公開アドレス（例: https://rmm.example.com:8444）を設定します。コンソールのポートは閉じたままです。
  • サーバー上（localhost）でコンソールを開いていて公開アドレスが未設定の場合、拠点ページに警告が表示されます。エージェントがサーバーのループバックアドレスに接続しようとしてしまうためです。

登録コード

エージェントは登録コードで顧客の拠点に参加します。顧客で拠点を開き、登録コードを作成をクリックします。有効期間（1～365 日）と使用できるコンピューターの台数を選びます。コード（CZ1-…）にはサーバーのアドレスと証明書のフィンガープリントが含まれるため、インストーラーには他の情報は不要です。表示は一度だけです。不要になったら取り消してください。

Windows

拠点ページで MSI をダウンロード（エージェントをダウンロード（MSI、64 ビット））し、ダブルクリックしてコードを貼り付けるか、グループポリシー、Intune、スクリプトなどでサイレントインストールします:

msiexec /i controlzit-agent-x64.msi /qn ENROLLCODE="CZ1-…"

エージェントは Windows サービス ControlZit Agent として動作します。時計の横の小さなアイコンが接続状態（緑）を示し、サーバーとコンピューターの管理者を表示するウィンドウを開きます。

アイコン、そのウィンドウ、再起動の確認は、ユーザーの Windows の表示言語を使います (コンソールの 14 言語のいずれか。それ以外は英語)。

MSI を使わない場合（管理者として PowerShell）:

.\controlzit-agent.exe enroll --code "CZ1-…"
.\controlzit-agent.exe install

Linux

拠点ページで Linux エージェント（x86-64、または Raspberry Pi と ARM サーバー向けの ARM64）をダウンロードし、マシンにコピーして root として実行します:

chmod +x controlzit-agent-linux-amd64
sudo ./controlzit-agent-linux-amd64 install --code "CZ1-…"

自身を /usr/local/bin/controlzit-agent にコピーし、登録して systemd サービス controlzit-agent を開始します。

エージェントの更新

サーバーは自身と同じバージョンのエージェントインストーラーを保持しています。設定 → エージェントの更新で古いエージェントを確認し、すべてを一度に更新するか、古いエージェントが接続時に自動更新されるようにできます。個別のエージェントはデバイスページで更新します。エージェントは自身の暗号化接続でインストーラーをダウンロードし、署名付き更新コマンドの SHA-256 と一致する場合にのみインストールします。ここで別のインストーラー（MSI または Linux エージェント）をアップロードすることもできます。

管理対象コンピューターの Windows Update

エージェントはポリシーで Windows Update の自動インストールをオフにし、更新が ControlZit からのみ（手動またはスケジュールで）届くようにします（Windows 更新を参照）。以前の設定は保存され、エージェントを削除すると元に戻ります。

エージェントの削除

デバイスのページで削除します（デバイスを削除）。オンラインの場合、エージェントは数秒で自身をアンインストールし、Windows Update は元の設定に戻ります。オフラインのコンピューターは今後接続できないため、そこで手動でアンインストールしてください（Windows: アプリ → ControlZit Agent → アンインストール、Linux: sudo controlzit-agent uninstall）。
