エージェントのインストール

エージェントは管理対象の各コンピューターで動く小さなサービスです。サーバーのエージェントポートへ送信接続し、インベントリと計測値を報告し、コンソールからの署名付きコマンドを実行します。

始める前に

  • エージェントはエージェントポート（既定は TCP 8444）でサーバーに到達できる必要があります。社外のコンピューター向けには、ファイアウォールでこのポートを開き、設定 → ネットワークとアクセスでエージェント用の公開アドレス（例: https://rmm.example.com:8444）を設定します。コンソールのポートは閉じたままです。
  • サーバー上（localhost）でコンソールを開いていて公開アドレスが未設定の場合、拠点ページに警告が表示されます。エージェントがサーバーのループバックアドレスに接続しようとしてしまうためです。

登録コード

エージェントは登録コードで顧客の拠点に参加します。顧客で拠点を開き、登録コードを作成をクリックします。有効期間（1～365 日）と使用できるコンピューターの台数を選びます。コード（RZ1-…）にはサーバーのアドレスと証明書のフィンガープリントが含まれるため、インストーラーには他の情報は不要です。表示は一度だけです。不要になったら取り消してください。

Windows

拠点ページで MSI をダウンロード（エージェントをダウンロード（MSI、64 ビット））し、ダブルクリックしてコードを貼り付けるか、グループポリシー、Intune、スクリプトなどでサイレントインストールします:

msiexec /i rmmzit-agent-x64.msi /qn ENROLLCODE="RZ1-…"

エージェントは Windows サービス RMMZit Agent として動作します。時計の横の小さなアイコンが接続状態（緑）を示し、サーバーとコンピューターの管理者を表示するウィンドウを開きます。

アイコン、そのウィンドウ、再起動の確認は、ユーザーの Windows の表示言語を使います (コンソールの 14 言語のいずれか。それ以外は英語)。

MSI を使わない場合（管理者として PowerShell）:

.\rmmzit-agent.exe enroll --code "RZ1-…"
.\rmmzit-agent.exe install

Linux

拠点ページで Linux エージェント（x86-64、または Raspberry Pi と ARM サーバー向けの ARM64）をダウンロードし、マシンにコピーして root として実行します:

chmod +x rmmzit-agent-linux-amd64
sudo ./rmmzit-agent-linux-amd64 install --code "RZ1-…"

自身を /usr/local/bin/rmmzit-agent にコピーし、登録して systemd サービス rmmzit-agent を開始します。

エージェントの更新

サーバーは自身と同じバージョンのエージェントインストーラーを保持しています。設定 → エージェントの更新で古いエージェントを確認し、すべてを一度に更新するか、古いエージェントが接続時に自動更新されるようにできます。個別のエージェントはデバイスページで更新します。エージェントは自身の暗号化接続でインストーラーをダウンロードし、署名付き更新コマンドの SHA-256 と一致する場合にのみインストールします。ここで別のインストーラー（MSI または Linux エージェント）をアップロードすることもできます。

管理対象コンピューターの Windows Update

エージェントはポリシーで Windows Update の自動インストールをオフにし、更新が RMMZit からのみ（手動またはスケジュールで）届くようにします（Windows 更新を参照）。以前の設定は保存され、エージェントを削除すると元に戻ります。

エージェントの削除

デバイスのページで削除します（デバイスを削除）。オンラインの場合、エージェントは数秒で自身をアンインストールし、Windows Update は元の設定に戻ります。オフラインのコンピューターは今後接続できないため、そこで手動でアンインストールしてください（Windows: アプリ → RMMZit Agent → アンインストール、Linux: sudo rmmzit-agent uninstall）。

多数のコンピューター: グループ ポリシーと Intune

すべてのコンピューター分の使用回数を持つ登録コードを作成すると、サイト ページにそのコードを埋め込んだ次の内容が表示されます。

  • グループ ポリシー: PowerShell のスタートアップ スクリプト。コンピューター アカウント (Domain Computers) が読み取れる共有に MSI を置き、そのパスを入力してスクリプトをコピーし、コンピューターの構成 → ポリシー → Windows の設定 → スクリプト → スタートアップ → PowerShell スクリプト に追加します。エージェント (サービス RMMZitAgent) があるコンピューターではスキップされます。インストール ログは %windir%\Temp\rmmzit-agent-install.log です。
  • Microsoft Intune: エージェントを Windows アプリ (Win32) として追加します。Microsoft の IntuneWinAppUtil で MSI をパッケージ化し、サイト ページのインストール/アンインストール コマンド、インストールの動作システム、検出規則 (ファイル C:\Program Files\RMMZit Agent\rmmzit-agent.exe) を使用します。基幹業務 (LOB) MSI として追加しないでください。エージェントは自動更新されるため、Intune が古いバージョンを再インストールしてしまいます。
