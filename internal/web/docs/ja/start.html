はじめに

ControlZit は自社サーバーで運用するリモート監視・管理（RMM）ツールです。自分のサーバー上の 1 つの Web コンソールから、顧客の Windows / Linux コンピューターを監視・管理できます。インベントリ、監視とアラート、リモートデスクトップ、ターミナル、ファイル、スクリプト、Windows 更新、ソフトウェア、レポートに対応します。

ControlZit でできること

分野内容
インベントリ各デバイスのハードウェア、OS、ディスク、ネットワーク、セキュリティ状態（ウイルス対策、ファイアウォール、BitLocker）、インストール済みソフトウェア。デバイス
監視とアラートCPU、メモリ、ディスク容量、オフラインのデバイス、停止したサービス、Defender とファイアウォール。メール、Slack、Microsoft Teams、Webhook でアラートを通知。監視
リモートアクセスブラウザーでのリモートデスクトップ（Windows、X11 の Linux）とクリップボード・ファイルコピー、Linux の root ターミナル、ファイルマネージャー、プロセス、サービス、再起動とシャットダウン。リモートアクセス
スクリプトスクリプトライブラリから PowerShell、cmd、bash、sh を 1 台、複数台同時、またはスケジュールで実行。スクリプト
更新とソフトウェア不足している Windows 更新と Linux パッケージを手動またはスケジュールでインストール、winget によるプログラム管理。更新
レポート顧客ごとのレポート（デバイス、更新、アラート、技術者の作業）。印刷するか、毎週・毎月メールで送信。レポート

しくみ

  • サーバーは PostgreSQL を備えた Linux マシン（通常は小さな VM）で動作します。ポートは 2 つあります。コンソール（Web 画面と API、TCP 8443）とエージェントのエンドポイント（TCP 8444）です。
  • エージェントは管理対象の各コンピューターでサービスとして動作し、エージェントポートへ送信接続します。コンピューター側で開くポートは不要です。エージェントは登録時に固定したサーバー証明書のフィンガープリントでサーバーを信頼します。
  • エージェントへの各コマンドはサーバーが署名し、エージェントが検証します。すべての操作は改ざん防止の監査ログに記録されます。

コンソールはすべての管理対象コンピューターを制御します。自社ネットワークからのみアクセスできるようにし（既定）、エージェントのポートは必要な場所だけで開いてください。セキュリティを参照してください。

最初の手順

  1. サーバーをインストール — 既製の VM イメージをインポートするか、アプライアンス ISO を起動するか、Linux サーバーでインストールスクリプトを実行します。サーバーのインストールを参照してください。
  2. 最初の管理者を作成 — サーバーに表示されるセットアップトークンを使い、認証アプリで 2 段階サインインを設定します。
  3. エージェント用アドレスを確認 — 設定 → ネットワークとアクセスで確認します。エージェントは公開アドレスまたはコンソールのホスト名でサーバーに到達できる必要があります。
  4. 顧客と拠点を追加 — 顧客で追加し、拠点で登録コードを作成します。
  5. エージェントをインストール — そのコードで拠点のコンピューターにインストールします。エージェントのインストールを参照してください。
  6. アラートを設定 — 設定 → 監視とアラートで設定し、必要なら Windows 更新の自動インストールも設定します。
  7. 技術者を追加 — ユーザーで追加するか、Active Directory / LDAP やシングルサインオンを接続します。ユーザー、ロール、サインインを参照してください。

要件

  • サーバー: 2 vCPU、2～4 GB RAM、16 GB ディスク。Debian 12 以降、Ubuntu 22.04 以降、AlmaLinux または Rocky Linux 9 以降（または既製のアプライアンス）。
  • Windows エージェント: Windows 10 / 11、Windows Server 2016 以降（64 ビット）。
  • Linux エージェント: systemd を使うディストリビューション、x86-64 または ARM64（Raspberry Pi と ARM サーバー）。更新は apt または dnf。
  • ブラウザー: 最新の Chrome、Edge、Firefox、Safari。
