Instalace serveru

Vyberte jeden ze čtyř způsobů. Hotový obraz VM je nejrychlejší; instalační skript se hodí pro existující linuxový server.

ZpůsobNejlepší proPotřebuje
1. Obraz VM (OVA, qcow2, VHDX)import, spuštění, přihlášení za pár minutVMware, Proxmox / KVM nebo Hyper-V
2. ISO appliancenovou VM nebo fyzický server, bez obsluhypřístup k internetu během instalace
3. Instalační skriptexistující server Debian, Ubuntu, AlmaLinux nebo Rocky Linuxroot a přístup k internetu
4. Balíčky ručněvlastní PostgreSQL, správu konfigurace, servery bez internetubalíček deb nebo rpm daného vydání

Všechny soubory jsou na stránce vydání. Dejte serveru 2 vCPU, 2–4 GB RAM a disk alespoň 16 GB.

1. Obraz VM

  1. Importujte obraz:
    • VMware ESXi / Workstation, VirtualBox: nasaďte controlzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: vytvořte VM bez disku (2 vCPU, 2–4 GB RAM, síť VirtIO), zkopírujte controlzit-appliance.qcow2 na uzel a spusťte qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm; připojte disk jako SCSI a nastavte jej jako spouštěcí.
    • Hyper-V: rozbalte controlzit-appliance-vhdx.zip a vytvořte VM 1. generace s VHDX jako diskem.
  2. Spusťte VM. Disk se sám zvětší na velikost virtuálního disku. Obrazovka VM ukazuje adresu konzole a instalační token.
  3. Otevřete https://<adresa>:8443. Prohlížeč jednou varuje před certifikátem podepsaným sám sebou (později jej nahraďte v Nastavení → Certifikát). Zadejte token a vytvořte prvního správce.

Appliance získá adresu přes DHCP. Pro pevnou adresu, název serveru nebo časové pásmo se přihlaste na obrazovce VM jako czadmin (první heslo controlzit, je nutné jej změnit): otevře se nabídka nastavení. Časové pásmo a síť lze později změnit i v konzoli.

2. ISO appliance

  1. Spusťte VM nebo server z controlzit-appliance.iso. Po 5 sekundách začne instalace sama: smaže první disk, nainstaluje Debian, PostgreSQL a ControlZit a potřebuje přístup k internetu (10–20 minut).
  2. Po restartu obrazovka ukazuje adresu konzole a instalační token, stejně jako u obrazu VM.

3. Instalační skript

Na existujícím linuxovém serveru jako root:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

Skript nainstaluje PostgreSQL, stáhne nejnovější vydání, ověří jeho podpis, vytvoří databázi s náhodným heslem a spustí službu. Volby (za sh -s --): --version X, --db postgres://… pro existující databázi, --no-auto-updates, aby automatické bezpečnostní aktualizace systému zůstaly vypnuté. Opětovné spuštění aktualizuje ControlZit a zachová data.

4. Balíčky ručně

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Pak zapište adresu databáze do /etc/controlzit/server.env (CONTROLZIT_DB=postgres://…) a spusťte službu příkazem systemctl enable --now controlzit-server.

První přihlášení

  • Instalační token je v /var/lib/controlzit/setup-token.txt a v protokolu serveru (journalctl -u controlzit-server). Platí jednou.
  • Každý účet potřebuje ověřovací aplikaci (TOTP) a dostane 10 záložních kódů. Uschovejte je bezpečně.
  • Konzole ve výchozím stavu přijímá spojení jen z privátních sítí. Pokud se zablokujete, spusťte na serveru controlzit-server --reset-allowlist (appliance: nabídka nastavení, položka 5).

Kde co je

CestaCo
/etc/controlzit/server.envkonfigurace: databáze, porty, zdroj aktualizací (čitelné jen pro root a službu)
/var/lib/controlzitdatový adresář: certifikáty, tajný klíč, instalátory agentů (downloads), protokoly
/var/lib/controlzit/logs/server.logprotokol serveru; také v journalctl -u controlzit-server
/var/log/controlzit-helperprotokol root pomocníka (aktualizace, časové pásmo, síť)

Zálohujte databázi spolu s /var/lib/controlzit: tajný klíč odtud dešifruje uložená hesla a certifikáty identifikují server vůči jeho agentům.
