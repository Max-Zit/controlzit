Instalace serveru

Vyberte jeden z pěti způsobů. Hotový obraz VM je nejrychlejší; instalační skript se hodí pro existující linuxový server, Docker pro existující hostitele Docker.

Všechny soubory jsou na stránce vydání. Dejte serveru 2 vCPU, 2–4 GB RAM a disk alespoň 16 GB.

1. Obraz VM

  1. Importujte obraz:
    • VMware ESXi / Workstation, VirtualBox: nasaďte rmmzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: vytvořte VM bez disku (2 vCPU, 2–4 GB RAM, síť VirtIO), zkopírujte rmmzit-appliance.qcow2 na uzel a spusťte qm importdisk <vmid> rmmzit-appliance.qcow2 local-lvm; připojte disk jako SCSI a nastavte jej jako spouštěcí.
    • Hyper-V: rozbalte rmmzit-appliance-vhdx.zip a vytvořte VM 1. generace s VHDX jako diskem.
  2. Spusťte VM. Disk se sám zvětší na velikost virtuálního disku. Obrazovka VM ukazuje adresu konzole a instalační token.
  3. Otevřete https://<adresa>:8443. Prohlížeč jednou varuje před certifikátem podepsaným sám sebou (později jej nahraďte v Nastavení → Certifikát). Zadejte token a vytvořte prvního správce.

Appliance získá adresu přes DHCP. Pro pevnou adresu, název serveru nebo časové pásmo se přihlaste na obrazovce VM jako rzadmin (první heslo rmmzit, je nutné jej změnit): otevře se nabídka nastavení. Časové pásmo a síť lze později změnit i v konzoli.

2. ISO appliance

  1. Spusťte VM nebo server z rmmzit-appliance.iso. Po 5 sekundách začne instalace sama: smaže první disk, nainstaluje Debian, PostgreSQL a RMMZit a potřebuje přístup k internetu (10–20 minut).
  2. Po restartu obrazovka ukazuje adresu konzole a instalační token, stejně jako u obrazu VM.

3. Instalační skript

Na existujícím linuxovém serveru jako root:

curl -fsSL https://github.com/Max-Zit/rmmzit/releases/latest/download/install.sh | sudo sh

Skript nainstaluje PostgreSQL, stáhne nejnovější vydání, ověří jeho podpis, vytvoří databázi s náhodným heslem a spustí službu. Volby (za sh -s --): --version X, --db postgres://… pro existující databázi, --no-auto-updates, aby automatické bezpečnostní aktualizace systému zůstaly vypnuté. Opětovné spuštění aktualizuje RMMZit a zachová data.

4. Balíčky ručně

sudo apt install ./rmmzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./rmmzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Pak zapište adresu databáze do /etc/rmmzit/server.env (RMMZIT_DB=postgres://…) a spusťte službu příkazem systemctl enable --now rmmzit-server.

5. Docker

Server existuje také jako image kontejneru, ghcr.io/max-zit/rmmzit, sestavený ze stejného podepsaného balíčku serveru jako ostatní způsoby; běží s PostgreSQL přes Docker Compose. Stáhněte docker-compose.yml a .env.example do složky, zkopírujte .env.example do .env, nastavte heslo databáze (písmena a číslice) a časové pásmo a potom:

docker compose up -d
docker compose exec rmmzit rmmzit-server -setup-token

Otevřete https://<host>:8443 a zadejte instalační token. Port 8444 je koncový bod agentů; otevřete ho tam, odkud se agenti připojují. Značka image v .env určuje, co běží: latest pro oficiální vydání, testing pro kandidáty na vydání.

Aktualizujte příkazem docker compose pull && docker compose up -d. Než nová verze změní databázi, server zapíše zálohu do Nastavení → Záloha konzole. Pro návrat nastavte předchozí verzi jako značku image a obnovte tento soubor: docker compose stop rmmzit, docker compose run --rm rmmzit -restore /var/lib/rmmzit/backups/SOUBOR, docker compose up -d. V kontejneru patří síť a časové pásmo hostiteli Docker, ne konzoli.

První přihlášení

  • Instalační token je v /var/lib/rmmzit/setup-token.txt a v protokolu serveru (journalctl -u rmmzit-server). Platí jednou.
  • Každý účet potřebuje ověřovací aplikaci (TOTP) a dostane 10 záložních kódů. Uschovejte je bezpečně.
  • Konzole ve výchozím stavu přijímá spojení jen z privátních sítí. Pokud se zablokujete, spusťte na serveru rmmzit-server --reset-allowlist (appliance: nabídka nastavení, položka 5).

Kde co je

CestaCo
/etc/rmmzit/server.envkonfigurace: databáze, porty, zdroj aktualizací (čitelné jen pro root a službu)
/var/lib/rmmzitdatový adresář: certifikáty, tajný klíč, instalátory agentů (downloads), protokoly
/var/lib/rmmzit/logs/server.logprotokol serveru; také v journalctl -u rmmzit-server
/var/log/rmmzit-helperprotokol root pomocníka (aktualizace, časové pásmo, síť)

Zálohujte databázi spolu s /var/lib/rmmzit: tajný klíč odtud dešifruje uložená hesla a certifikáty identifikují server vůči jeho agentům.
