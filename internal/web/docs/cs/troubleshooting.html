Řešení potíží a časté dotazy

Nejčastější dotazy a co zkontrolovat nejdřív. Pro požadavek na podporu stáhněte diagnostiku v Nastavení → Diagnostika.

Nemohu se dostat do konzole

  • Vaše adresa možná není v povolených sítích: spojení se zavře před TLS, takže prohlížeč ukáže chybu spojení. Spusťte na serveru controlzit-server --reset-allowlist (appliance: nabídka nastavení, položka 5), abyste znovu povolili všechny privátní sítě.
  • Po změně portu otevřete konzoli na novém portu.
  • Zkontrolujte službu na serveru: systemctl status controlzit-server a journalctl -u controlzit-server.

Potíže s přihlášením

  • Kód je chybný — čas v telefonu musí být správný (automatický čas).
  • Ztracený telefon — přihlaste se záložním kódem; jiný správce může resetovat dvoufázové přihlášení.
  • Příliš mnoho neúspěšných pokusů — adresa je na čas zablokována; správce ji může odblokovat v Nastavení → Přihlášení a zabezpečení. Přihlášení ze samotného serveru se nikdy neblokují.
  • LDAP / jednotné přihlášení — použijte Test na stránce LDAP; zkontrolujte skupiny, které poskytovatel posílá. Protokol serveru obsahuje podrobnosti.

Agent se nepřipojuje

  • Dosáhne počítač na port agentů? Ve Windows: Test-NetConnection rmm.example.com -Port 8444.
  • Je veřejná adresa pro agenty správná? Kódy vytvořené při konzoli otevřené přes localhost posílají agenta na špatný server; nastavte adresu a vytvořte nový kód.
  • Je kód stále platný a nevyčerpaný?
  • Protokoly agenta: Windows C:\ProgramData\ControlZit Agent\agent.log, Linux /var/lib/controlzit-agent/agent.log a journalctl -u controlzit-agent; u připojeného zařízení je otevřete z konzole v Soubory. Ve Windows ikona vedle hodin ukazuje stav spojení.

Vzdálená plocha nic neukazuje

  • Linux s Waylandem nelze zobrazit: přihlaste se do relace X11 (Xorg) nebo použijte terminál.
  • Linux bez plochy: použijte terminál.
  • Kopírování souborů přes schránku vyžaduje přihlášeného uživatele na počítači s Windows.

Aktualizace Windows se neinstalují

  • Zkontrolujte automatickou instalaci v Nastavení → Aktualizace Windows: dny, hodinu a režim. Zařízení musí být v tu hodinu online.
  • Karta Aktualizace zařízení ukazuje poslední hledání a případnou chybu.

E-maily s upozorněními nepřicházejí

Použijte Odeslat testovací e-mail v Nastavení → Monitorování a upozornění; zpráva ukáže odpověď serveru. Heslo se posílá jen přes STARTTLS nebo TLS.

Časté dotazy

Potřebuje ControlZit cloudovou službu?

Ne. Vše běží na vašem serveru; nic se neposílá MaxZitu. Server jen kontroluje GitHub kvůli novým vydáním.

Jak ControlZit zálohovat?

Zálohujte databázi PostgreSQL (pg_dump) a složku /var/lib/controlzit. Bez tajného klíče a certifikátů odtud nelze uložená hesla dešifrovat a agenti by novému serveru nedůvěřovali.

Mohu server přesunout na nový stroj?

Ano: nainstalujte ControlZit na nový stroj, obnovte databázi a /var/lib/controlzit a ponechte stejnou adresu (nebo změňte veřejnou adresu pro agenty a nasměrujte starý název na nový stroj).

Existuje agent pro macOS?

Zatím ne. Podporovány jsou Windows a Linux (x86-64, ARM64).
