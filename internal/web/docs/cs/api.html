API

REST API umožňuje skriptům a dalším nástrojům číst zařízení, upozornění a úlohy a spouštět práci na zařízeních, se stejnými právy jako v konzoli.

Tokeny

Token vytvoříte v Můj účet → Tokeny API: název, roli, která není vyšší než vaše (jen čtení, technik nebo správce), a dobu platnosti. Token se zobrazí jen jednou; uchovávejte ho jako heslo. Jedná vaším jménem, s vašimi zákazníky. Posílejte ho v každém požadavku jako Authorization: Bearer czt_… na adresu konzole (port 8443), která přijímá spojení jen z povolených sítí. Soubory cookie relace prohlížeče na API nefungují. Odstraněním tokenu na stránce účtu jeho přístup okamžitě skončí.

Úlohy

Úloha čeká, až bude zařízení online, a běží po dřívějších úlohách zařízení, stejně jako akce v konzoli; zobrazí se v Aktivitě zařízení. Odpověď je 202 s úlohou; sledujte ji pomocí GET /api/v1/tasks/{id}, dokud její stav není done, failed, cancelled nebo expired. Druhy a jejich pole:

{"kind": "script", "shell": "powershell", "script": "Get-Service Spooler", "timeout": 120}
{"kind": "patch.scan"}
{"kind": "patch.install", "updates": [], "reboot": false}
{"kind": "winget", "action": "install", "id": "7zip.7zip"}
{"kind": "choco", "action": "upgrade", "id": "firefox"}
{"kind": "power", "action": "restart", "delay": 300, "message": "Restart for updates"}
{"kind": "agent.update"}
{"kind": "bitlocker.keys"}

Příklady

Skript PowerShell na zařízení 9 a potom jeho výsledek:

curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"kind":"script","shell":"powershell","script":"Get-Date","timeout":60}' \
  https://rmm.example.com:8443/api/v1/devices/9/tasks
curl -s -H "Authorization: Bearer $TOKEN" https://rmm.example.com:8443/api/v1/tasks/42

$h = @{ Authorization = "Bearer $env:CZ_TOKEN" }
Invoke-RestMethod -Headers $h https://rmm.example.com:8443/api/v1/alerts

Chyby

Chyby přicházejí jako JSON {"error": "…"} se stavem HTTP: 400 pro chybný požadavek, 401 pro chybějící, nesprávný nebo prošlý token, 403, když role tokenu volání nedovoluje, 404 pro něco, co neexistuje nebo co token nesmí vidět, 409, když úloha už skončila, 429 po příliš mnoha neúspěšných přihlášeních z adresy. Každá změna přes API se zapíše do protokolu aktivit s názvem tokenu.
