Instalace agentů

Agent je malá služba na každém spravovaném počítači. Připojuje se odchozím spojením k portu agentů serveru, posílá inventář a měření a provádí podepsané příkazy konzole.

Než začnete

  • Agenti musí dosáhnout na server na portu agentů (výchozí TCP 8444). Pro počítače mimo vaši síť otevřete tento port na firewallu a nastavte veřejnou adresu pro agenty v Nastavení → Síť a přístup (například https://rmm.example.com:8444). Port konzole zůstává zavřený.
  • Pokud jste konzoli otevřeli přímo na serveru (localhost) a veřejná adresa pro agenty není nastavena, stránka pobočky upozorní: agenti by se pokoušeli připojit na loopback adresu serveru.

Registrační kódy

Agenti se připojí k pobočce zákazníka pomocí registračního kódu. Otevřete pobočku v Zákazníci a klikněte na Vytvořit registrační kód. Zvolíte, jak dlouho platí (1–365 dní) a kolik počítačů jej smí použít. Kód (RZ1-…) obsahuje adresu serveru a otisk jeho certifikátu, takže instalátor nepotřebuje nic dalšího. Zobrazí se jen jednou; zrušte jej, když už není potřeba.

Windows

Stáhněte MSI na stránce pobočky (Stáhnout agenta (MSI, 64bitový)) a buď na něj poklepejte a vložte kód, nebo jej nainstalujte tiše, například pomocí zásad skupiny, Intune nebo skriptu:

msiexec /i rmmzit-agent-x64.msi /qn ENROLLCODE="RZ1-…"

Agent běží jako služba Windows RMMZit Agent. Malá ikona vedle hodin ukazuje, zda je připojen (zelená), a otevírá okno se serverem a informací, kdo počítač spravuje.

Ikona, její okno a otázka na restart používají jazyk zobrazení Windows uživatele (jeden ze 14 jazyků konzole, jinak angličtinu).

Bez MSI (PowerShell jako správce):

.\rmmzit-agent.exe enroll --code "RZ1-…"
.\rmmzit-agent.exe install

Linux

Stáhněte agenta pro Linux na stránce pobočky (x86-64, nebo ARM64 pro Raspberry Pi a ARM servery), zkopírujte jej na počítač a spusťte jako root:

chmod +x rmmzit-agent-linux-amd64
sudo ./rmmzit-agent-linux-amd64 install --code "RZ1-…"

Zkopíruje se do /usr/local/bin/rmmzit-agent, zaregistruje se a spustí službu systemd rmmzit-agent.

Aktualizace agentů

Server obsahuje instalátory agenta své vlastní verze. V Nastavení → Aktualizace agentů vidíte, kteří agenti jsou zastaralí, aktualizujete je všechny najednou, nebo necháte zastaralé agenty aktualizovat se samy při připojení. Jednotlivého agenta aktualizujete na stránce zařízení. Agent stáhne instalátor přes vlastní šifrované spojení a nainstaluje jej, jen pokud odpovídá SHA-256 v podepsaném příkazu k aktualizaci. Můžete tam také nahrát jiný instalátor (MSI nebo agenta pro Linux).

Windows Update na spravovaných počítačích

Agent zásadou vypne automatickou instalaci Windows Update, aby aktualizace přicházely jen z RMMZit, ručně nebo podle vašeho plánu (viz Aktualizace Windows). Předchozí nastavení se uloží a vrátí se po odebrání agenta.

Odebrání agenta

Smažte zařízení na jeho stránce (Odebrat zařízení). Je-li online, agent se během několika sekund odinstaluje a Windows Update dostane zpět vlastní nastavení. Offline počítač se už nemůže připojit; agenta tam odinstalujte ručně (Windows: Aplikace → RMMZit Agent → Odinstalovat; Linux: sudo rmmzit-agent uninstall).

Mnoho počítačů: zásady skupiny a Intune

Vytvořte registrační kód s dostatkem použití pro všechny počítače; stránka pobočky pak zobrazí, vyplněné tímto kódem:

  • Zásady skupiny: spouštěcí skript PowerShell. Umístěte MSI do sdílené složky, kterou mohou číst účty počítačů (Domain Computers), zadejte jeho cestu, zkopírujte skript a přidejte jej pod Konfigurace počítače → Zásady → Nastavení systému Windows → Skripty → Spuštění → Skripty PowerShell. Počítače s agentem (služba RMMZitAgent) jej přeskočí; protokol instalace je %windir%\Temp\rmmzit-agent-install.log.
  • Microsoft Intune: přidejte agenta jako aplikaci Windows (Win32): zabalte MSI nástrojem IntuneWinAppUtil od Microsoftu a použijte příkazy instalace a odinstalace, chování instalace Systém a pravidlo detekce (soubor C:\Program Files\RMMZit Agent\rmmzit-agent.exe) ze stránky pobočky. Nepřidávejte jej jako obchodní (LOB) MSI: agent se aktualizuje sám a Intune by znovu nainstaloval starou verzi.
