Začínáme

ControlZit je nástroj pro vzdálené monitorování a správu (RMM), který běží na vašem vlastním serveru. Z jedné webové konzole sledujete a spravujete počítače s Windows a Linuxem svých zákazníků: inventář, monitorování a upozornění, vzdálenou plochu, terminál, soubory, skripty, aktualizace Windows, software a zprávy.

Jak to funguje

  • Server běží na linuxovém stroji (obvykle malé VM) s PostgreSQL. Má dva porty: konzoli (webové rozhraní a API, TCP 8443) a koncový bod agentů (TCP 8444).
  • Agenti běží jako služba na každém spravovaném počítači. Připojují se odchozím spojením k portu agentů; počítače nepotřebují žádné otevřené porty. Agent důvěřuje serveru podle otisku jeho certifikátu, který si připne při registraci.
  • Každý příkaz agentovi server podepíše a agent jej ověří a každá akce se zapíše do auditního protokolu chráněného proti úpravám.

Konzole ovládá každý spravovaný počítač. Ať je dostupná jen z vašich vlastních sítí (výchozí stav) a otevřete jen port agentů tam, kde jej agenti potřebují. Viz Bezpečnost.

První kroky

  1. Nainstalujte server — importujte hotový obraz VM, spusťte ISO appliance nebo spusťte instalační skript na linuxovém serveru. Viz Instalace serveru.
  2. Vytvořte prvního správce pomocí instalačního tokenu, který server zobrazí, a nastavte dvoufázové přihlášení s ověřovací aplikací.
  3. Zkontrolujte adresu pro agenty v Nastavení → Síť a přístup: agenti musí dosáhnout na server přes veřejnou adresu pro agenty nebo název konzole.
  4. Přidejte zákazníka a pobočku v Zákazníci a na pobočce vytvořte registrační kód.
  5. Nainstalujte agenta na počítače té pobočky pomocí kódu. Viz Instalace agentů.
  6. Nastavte upozornění a automatické aktualizace Windows v zásadě zákazníka Default v Zásady a e-maily upozornění v Nastavení → Monitorování a upozornění.
  7. Přidejte techniky v Uživatelé nebo připojte Active Directory / LDAP či jednotné přihlášení. Viz Uživatelé, role a přihlášení.

Požadavky

  • Server: 2 vCPU, 2–4 GB RAM, disk 16 GB; Debian 12+, Ubuntu 22.04+, AlmaLinux nebo Rocky Linux 9+ (nebo hotová appliance).
  • Agenti pro Windows: Windows 10 / 11, Windows Server 2016 a novější, 64bitové.
  • Agenti pro Linux: distribuce se systemd, x86-64 nebo ARM64 (Raspberry Pi a ARM servery). Aktualizace přes apt nebo dnf.
  • Prohlížeč: aktuální Chrome, Edge, Firefox nebo Safari.
