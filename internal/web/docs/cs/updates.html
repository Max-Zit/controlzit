Aktualizace Windows a software

ControlZit ukazuje, které aktualizace na každém počítači chybí, a instaluje je ručně nebo podle vašeho plánu. Programy se instalují a aktualizují pomocí winget.

Přehled

Aktualizace ukazují zařízení s chybějícími aktualizacemi (bezpečnostní počítány zvlášť), zařízení čekající na restart, poslední instalaci a poslední hledání. Agenti hledají chybějící aktualizace několik minut po spuštění a pak dvakrát denně; Hledat nyní hned spustí hledání.

Na zařízení

Karta Aktualizace zařízení ukazuje chybějící aktualizace s kategorií a závažností a nedávno nainstalované. Vyberte aktualizace a klikněte na Instalovat vybrané; stránka ukáže výsledek po dokončení. Je-li potřeba restart, zařízení to ukáže a restart spustíte z jeho stránky.

Automatická instalace

V Nastavení → Aktualizace Windows zvolte, co server instaluje sám:

  • Vypnuto — aktualizace se instalují jen z konzole.
  • Bezpečnostní a kritické aktualizace, definice Defenderu.
  • Všechny aktualizace kromě aktualizací funkcí — nové verze Windows se nikdy neinstalují automaticky.

Zvolte dny a hodinu (čas serveru). Zařízení, která jsou v tu hodinu online, nainstalují jednou za ten den; offline zařízení čekají na další naplánovaný den. Volitelně se počítač sám restartuje, když to aktualizace vyžaduje, 5 minut po upozornění přihlášeného uživatele.

Aby aktualizace nepřicházely v náhodnou dobu, agent zásadou vypne automatickou instalaci Windows Update. Po odebrání agenta se vrátí dřívější nastavení.

Linux

Na Linuxu agent čte dostupné aktualizace balíčků přes apt (Debian, Ubuntu; bezpečnostní aktualizace ze zdrojů -security) nebo dnf (rodina RHEL; bezpečnostní aktualizace z informací o aktualizacích) a instaluje vybrané balíčky. Automatická instalace platí i pro zařízení s Linuxem; tam jsou „bezpečnostní aktualizace“ balíčky z bezpečnostních zdrojů.

Programy (winget)

Karta Programy zařízení s Windows ukazuje nainstalované programy, které winget zná, a dostupné aktualizace. Aktualizovat vše je aktualizuje; jednotlivé programy lze aktualizovat nebo odinstalovat. Nainstalovat program hledá v komunitním repozitáři winget (například 7-Zip nebo Chrome) a nainstaluje jej tiše pro všechny uživatele. Zařízení potřebuje winget (Instalační služba aplikace), který je součástí aktuálních Windows 10 a 11.
