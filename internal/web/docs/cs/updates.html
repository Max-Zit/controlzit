Aktualizace Windows a software

ControlZit ukazuje, které aktualizace na každém počítači chybí, a instaluje je ručně nebo podle vašeho plánu. Programy se instalují a aktualizují pomocí winget.

Přehled

Aktualizace ukazují zařízení s chybějícími aktualizacemi (bezpečnostní počítány zvlášť), zařízení čekající na restart, poslední instalaci a poslední hledání. Agenti hledají chybějící aktualizace několik minut po spuštění a pak dvakrát denně; Hledat nyní hned spustí hledání.

Na zařízení

Karta Aktualizace zařízení ukazuje chybějící aktualizace s kategorií a závažností a nedávno nainstalované. Vyberte aktualizace a klikněte na Instalovat vybrané; stránka ukáže výsledek po dokončení. Je-li potřeba restart, zařízení to ukáže a restart spustíte z jeho stránky.

Definice Defenderu (Security Intelligence Update) vycházejí několikrát denně, každá s novým ID aktualizace. Když jednu instalujete, agent nejprve znovu vyhledá a nainstaluje verzi definic, kterou Windows Update nabízí v tu chvíli.

Automatická instalace

V Nastavení → Aktualizace Windows zvolte, co server instaluje sám:

  • Vypnuto — aktualizace se instalují jen z konzole.
  • Bezpečnostní a kritické aktualizace, definice Defenderu.
  • Všechny aktualizace kromě aktualizací funkcí — nové verze Windows se nikdy neinstalují automaticky.

Zvolte dny a hodinu (čas serveru). Zařízení, která jsou v tu hodinu online, nainstalují jednou za ten den; offline zařízení čekají na další naplánovaný den. Volitelně se počítač sám restartuje, když to aktualizace vyžaduje, 5 minut po upozornění přihlášeného uživatele.

Aby aktualizace nepřicházely v náhodnou dobu, agent zásadou vypne automatickou instalaci Windows Update. Po odebrání agenta se vrátí dřívější nastavení.

Linux

Na Linuxu agent čte dostupné aktualizace balíčků přes apt (Debian, Ubuntu; bezpečnostní aktualizace ze zdrojů -security) nebo dnf (rodina RHEL; bezpečnostní aktualizace z informací o aktualizacích) a instaluje vybrané balíčky. Automatická instalace platí i pro zařízení s Linuxem; tam jsou „bezpečnostní aktualizace“ balíčky z bezpečnostních zdrojů.

Programy (winget)

Karta Programy zařízení s Windows má tři části. Dostupné aktualizace ukazuje programy, které winget umí aktualizovat; Aktualizovat vše je aktualizuje, nebo aktualizujte jednotlivé programy. Nainstalované ukazuje každý program ze seznamu nainstalovaných programů Windows, pro počítač i pro přihlášené uživatele, s filtrem podle názvu nebo vydavatele. Odinstalovat odebere program potichu: balíčky Windows Installer (MSI) přes msiexec /x, odinstalátory Inno Setup a NSIS s jejich tichým přepínačem, nebo vlastním tichým příkazem programu. Výsledek se hlásí až ve chvíli, kdy program opravdu zmizí; programy bez tichého odinstalátoru jsou označené a je třeba je odebrat na počítači nebo skriptem. Nainstalovat program hledá v komunitním repozitáři winget (například 7-Zip nebo Chrome) a instaluje potichu pro všechny uživatele. Instalace a aktualizace potřebují winget (App Installer), který je součástí aktuálních Windows 10 a 11.

Chocolatey lze přidat jako druhý veřejný zdroj v Software → Veřejné zdroje. Nainstalovat program pak nabízí volbu zdroje (winget nebo Chocolatey) a Dostupné aktualizace ukazuje i programy nainstalované přes Chocolatey, které mají novější verzi. Klient Chocolatey se na zařízení nainstaluje přes winget, když je poprvé potřeba. Balíčky Chocolatey spravuje jeho komunita a obvykle stahují program z webu výrobce.

Knihovna softwaru

V Software správci nahrávají vlastní instalátory: balíček Instalační služby systému Windows (.msi) nebo instalační program (.exe), do 2 GB, s názvem, verzí, argumenty pro tichou instalaci a výstupními kódy, které znamenají úspěch (výchozí 0, 1641 a 3010; poslední dva znamenají, že instalaci dokončí restart). U MSI agent spustí msiexec /i s protokolem a výchozí argumenty jsou /qn /norestart; EXE potřebuje vlastní tichý přepínač, například /S (NSIS), /VERYSILENT /NORESTART (Inno Setup) nebo /quiet.

Nainstalovat na zařízení vybere zákazníky, lokality nebo jednotlivá zařízení s Windows a spustí úlohu jako skript z knihovny: zařízení online instalují hned, offline po připojení do 24 hodin. Agent stáhne instalátor z agentského portu serveru a ověří ho podle SHA-256 z podepsaného příkazu, než ho spustí jako SYSTEM. Stránka úlohy ukazuje výsledek každého zařízení; protokol balíčku Instalační služby systému Windows se uloží s výsledkem. Technici instalují balíčky na zařízení svých zákazníků, i přes Nainstalovat program na kartě Programy zařízení.
