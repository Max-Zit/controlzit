Nastavení a aktualizace serveru

Správci najdou nastavení serveru v Nastavení: síť a porty, certifikát, časové pásmo, aktualizace serveru a agentů a diagnostiku pro podporu.

Síť a přístup

V Nastavení → Síť a přístup:

  • Konzole — adresa a port naslouchání (výchozí :8443) a povolené sítě: jedna IP adresa nebo síť na řádek (CIDR). Spojení z jiných adres se zavřou před TLS; samotný server (127.0.0.1) je vždy povolen. Uložení odmítne seznam, který by zablokoval vaši adresu.
  • Koncový bod agentů — adresa a port naslouchání (výchozí :8444, jiný než konzole), sítě, ze kterých smějí agenti přicházet (prázdné = všechny), a veřejná adresa pro agenty, která se vkládá do instalátorů a registračních kódů.
  • Nové porty platí po Restartovat nyní (restartuje službu RMMZit; agenti se připojí sami).

Pokud se zablokujete, spusťte na serveru rmmzit-server --reset-allowlist (appliance: nabídka nastavení, položka 5).

Síť serveru (appliance)

Na appliance RMMZit se zde nastavuje i síť samotného serveru: DHCP nebo pevná adresa s velikostí sítě (např. 192.168.1.20/24), brána, jeden až tři servery DNS a název serveru. Pokud brána s novým nastavením neodpoví, předchozí se po 30 sekundách samo vrátí. U jiných instalací síť spravuje operační systém.

Časové pásmo

Plány (aktualizace, skripty, zprávy) a časy v konzoli používají časové pásmo serveru. Vyberte jej ze seznamu a klikněte na Nastavit; konzole se restartuje a za několik sekund je zpět. Bez root pomocníka (viz níže) jej nastavte na serveru: timedatectl set-timezone Europe/Prague.

Certifikát (HTTPS)

V Nastavení → Certifikát zvolte certifikát, který prohlížeče vidí při otevření konzole. Agenti používají vlastní port a certifikát, takže je změna nikdy neodpojí.

  • Vlastní certifikát konzole (podepsaný sám sebou) — funguje hned; prohlížeče před ním varují.
  • Let's Encrypt — bezplatný certifikát, automaticky obnovovaný 30 dní před vypršením. Zadejte veřejný název DNS konzole a e-mailovou adresu a zvolte ověření:
    • port 80 — název ukazuje na tento server a port 80 je dostupný z internetu; server odpovídá na portu 80 a přesměruje prohlížeče na HTTPS;
    • DNS Cloudflare — pro servery nedostupné z internetu; vyžaduje token API Cloudflare s Zone:DNS:Edit pro zónu.
  • Nahrát certifikát od vaší certifikační autority nebo firemní CA: certifikát (PEM, s mezilehlými certifikáty) a soukromý klíč. Klíč se ukládá jen na tomto serveru.

Aktualizace serveru

Nastavení → Aktualizace RMMZit ukazuje běžící verzi a nejnovější vydání. Nainstalovat aktualizuje server: instalují se jen vydání podepsaná klíčem vydání RMMZit; před instalací server zálohuje databázi a program, a pokud se nová verze nespustí, sám se vrátí ke staré. Konzole je minutu či dvě nedostupná. Volitelně se nové verze instalují automaticky ve zvolené hodině.

Kanál aktualizací: Oficiální verze (výchozí) nebo Testování, který nabízí kandidáty na vydání dříve, než se stanou oficiálními, pro testovací konzoli. Produkční konzole nechte na oficiálních verzích.

Aktualizace, časové pásmo a síť potřebují root pomocníka, který je součástí balíčků pro Linux a appliance. Bez něj (např. samostatný program) aktualizujte pomocí install.sh nebo balíčku vydání.

Diagnostika

Nastavení → Diagnostika ukazuje, kam RMMZit zapisuje protokoly, nejnovější řádky protokolu serveru (filtr podle úrovně nebo textu), protokol root pomocníka a verze. Stáhnout diagnostiku (ZIP) vytvoří soubor pro podporu s protokoly, verzemi a souhrnem nastavení, zařízeními, upozorněními a auditním protokolem. Hesla, tokeny, registrační kódy a klíče se odstraňují ze všeho zobrazeného i ze souboru; skripty a jejich výstup nejsou zahrnuty.

Vlastní pole

V Nastavení → Vlastní pole správci přidávají vlastní pole pro zařízení a zákazníky — text, číslo nebo datum — například inventární číslo, konec záruky nebo smlouvu. Technici je vyplňují na stránkách zařízení a zákazníků; API vrací pole s každým zařízením a nastavuje je přes PUT /api/v1/devices/{id}/fields.

Záloha konzole

Nastavení → Záloha konzole zálohuje konzoli každý den ve zvolenou hodinu, nebo hned tlačítkem Zálohovat nyní. Záloha obsahuje databázi, tajný klíč uložených hesel, certifikáty a klíče, kterým agenti důvěřují, a knihovnu softwaru. Nejnovější zálohy (kolik zvolíte) zůstávají ve složce backups datového adresáře a lze je stáhnout ze stránky.

S heslem jsou soubory šifrované (AES-256-GCM); heslo uchovávejte jinde, protože bez něj zálohu nelze obnovit. Kopie každé zálohy může jít do složky SFTP na jiném serveru (heslo nebo soukromý klíč). První test spojení ukáže klíč hostitele serveru, kterému máte důvěřovat; kopie jdou jen na server s tímto klíčem. Když záloha nebo její kopie selže, příjemci e-mailů s upozorněními dostanou e-mail.

Obnovení se spouští při zastaveném serveru: na appliance v nabídce nastavení (Restore a backup), s balíčky pro Linux:

sudo systemctl stop rmmzit-server
sudo -u rmmzit sh -c 'set -a; . /etc/rmmzit/server.env; rmmzit-server -data-dir /var/lib/rmmzit -restore /path/rmmzit-backup-….czb'
sudo systemctl start rmmzit-server

Heslo šifrované zálohy se čte z RMMZIT_BACKUP_PASSPHRASE nebo ze souboru zadaného přes -restore-passphrase-file. Databáze se obnoví v jednom kroku (když selže, nic se nezmění); novější RMMZit obnovenou databázi při spuštění aktualizuje. Nový server obnovený ze zálohy si ponechá všechny agenty, protože důvěřují stejnému certifikátu.
