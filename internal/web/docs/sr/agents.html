Instalacija agenata

Agent je mali servis na svakom računaru kojim upravljate. Povezuje se ka portu za agente na serveru, šalje inventar i merenja i izvršava potpisane komande konzole.

Pre početka

  • Agenti moraju da dođu do servera na portu za agente (podrazumevano TCP 8444). Za računare van vaše mreže otvorite taj port na zaštitnom zidu i podesite javnu adresu za agente u Podešavanja → Mreža i pristup (na primer https://rmm.example.com:8444). Port konzole ostaje zatvoren.
  • Ako ste konzolu otvorili na samom serveru (localhost), a javna adresa za agente nije podešena, stranica lokacije vas upozorava: agenti bi pokušali da se povežu na lokalnu adresu servera.

Kodovi za prijavu

Agenti se priključuju lokaciji klijenta pomoću koda za prijavu. Otvorite lokaciju u Klijenti i kliknite Napravi kod za prijavu. Birate koliko dugo važi (1–365 dana) i koliko ga računara sme iskoristiti. Kod (CZ1-…) sadrži adresu servera i otisak sertifikata servera, pa instalaciji ne treba ništa drugo. Prikazuje se samo jednom; opozovite ga kad više nije potreban.

Windows

Preuzmite MSI na stranici lokacije (Preuzmi agenta (MSI, 64-bit)) i ili ga pokrenite dvoklikom i nalepite kod, ili ga instalirajte tiho, na primer preko Group Policy-ja, Intune-a ili skripte:

msiexec /i controlzit-agent-x64.msi /qn ENROLLCODE="CZ1-…"

Agent radi kao Windows servis ControlZit Agent. Mala ikonica pored sata pokazuje da li je povezan (zelena) i otvara prozor sa serverom i time ko upravlja računarom.

Ikonica, njen prozor i pitanje za restart koriste jezik prikaza Windowsa korisnika (jedan od 14 jezika konzole, inače engleski).

Bez MSI-ja (PowerShell kao administrator):

.\controlzit-agent.exe enroll --code "CZ1-…"
.\controlzit-agent.exe install

Linux

Preuzmite Linux agenta na stranici lokacije (x86-64, ili ARM64 za Raspberry Pi i ARM servere), kopirajte ga na mašinu i pokrenite kao root:

chmod +x controlzit-agent-linux-amd64
sudo ./controlzit-agent-linux-amd64 install --code "CZ1-…"

Kopira se u /usr/local/bin/controlzit-agent, prijavi se i pokrene systemd servis controlzit-agent.

Ažuriranje agenata

Server nosi instalacije agenata svoje verzije. U Podešavanja → Ažuriranje agenata vidite koji su agenti zastareli, ažurirate ih sve odjednom ili pustite da se zastareli agenti sami ažuriraju kad se povežu. Pojedinačni agent se ažurira na stranici uređaja. Agent preuzima instalaciju preko svoje šifrovane veze i instalira je samo ako se poklapa sa SHA-256 iz potpisane komande. Tu možete otpremiti i drugu instalaciju (MSI ili Linux agenta).

Windows Update na računarima

Agent pravilom isključuje automatsku instalaciju Windows Update-a, tako da ažuriranja stižu samo iz ControlZit-a, ručno ili po vašem rasporedu (vidi Windows ažuriranja). Prethodna podešavanja se čuvaju i vraćaju kad se agent ukloni.

Uklanjanje agenta

Obrišite uređaj na njegovoj stranici (Ukloni uređaj). Ako je na mreži, agent se sam deinstalira za nekoliko sekundi i Windows Update dobija nazad svoja podešavanja. Računar van mreže više ne može da se poveže; tamo deinstalirajte agenta ručno (Windows: Aplikacije → ControlZit Agent → Deinstaliraj; Linux: sudo controlzit-agent uninstall).

Mnogo računara: Group Policy i Intune

Napravite kod za upis sa dovoljno korišćenja za sve računare; stranica lokacije zatim prikazuje, popunjeno tim kodom:

  • Group Policy: PowerShell startup skriptu. Stavite MSI na deljeni folder koji računarski nalozi (Domain Computers) smeju da čitaju, upišite njegovu putanju, kopirajte skriptu i dodajte je pod Computer Configuration → Policies → Windows Settings → Scripts → Startup → PowerShell Scripts. Računari koji imaju agenta (servis ControlZitAgent) je preskaču; log instalacije je %windir%\Temp\controlzit-agent-install.log.
  • Microsoft Intune: dodajte agenta kao Windows aplikaciju (Win32): spakujte MSI Microsoft-ovim alatom IntuneWinAppUtil i koristite komande za instalaciju i deinstalaciju, način instalacije System i pravilo detekcije (fajl C:\Program Files\ControlZit Agent\controlzit-agent.exe) sa stranice lokacije. Ne dodajte ga kao line-of-business MSI: agent se sam ažurira, a Intune bi ponovo instalirao staru verziju.
