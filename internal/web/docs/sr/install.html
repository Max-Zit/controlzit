Instalacija servera

Izaberite jedan od četiri načina. Gotova slika virtuelne mašine je najbrža; skripta za instalaciju odgovara postojećem Linux serveru.

NačinNajbolje zaPotrebno
1. Slika VM (OVA, qcow2, VHDX)uvezi, pokreni, prijavi se, za nekoliko minutaVMware, Proxmox / KVM ili Hyper-V
2. Instalacioni ISOnova VM ili fizički server, bez pitanjapristup internetu tokom instalacije
3. Skripta za instalacijupostojeći Debian, Ubuntu, AlmaLinux ili Rocky Linux serverroot i pristup internetu
4. Paketi ručnosopstveni PostgreSQL, upravljanje konfiguracijom, serveri bez internetadeb ili rpm paket izdanja

Svi fajlovi su na stranici izdanja. Serveru dajte 2 vCPU, 2–4 GB RAM i disk od 16 GB ili veći.

1. Slika virtuelne mašine

  1. Uvezite sliku:
    • VMware ESXi / Workstation, VirtualBox: uvezite controlzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: napravite VM bez diska (2 vCPU, 2–4 GB RAM, VirtIO mreža), kopirajte controlzit-appliance.qcow2 na čvor i pokrenite qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm; zakačite disk kao SCSI i postavite ga za disk za pokretanje.
    • Hyper-V: raspakujte controlzit-appliance-vhdx.zip i napravite VM prve generacije sa tim VHDX-om kao diskom.
  2. Pokrenite VM. Disk se sam proširi na veličinu virtuelnog diska. Ekran VM-a pokazuje adresu konzole i token za podešavanje.
  3. Otvorite https://<adresa>:8443. Pregledač jednom upozori na samopotpisani sertifikat (kasnije ga zamenite u Podešavanja → Sertifikat). Unesite token i napravite prvog administratora.

Uređaj dobija adresu preko DHCP-a. Za fiksnu adresu, ime servera ili vremensku zonu prijavite se na samom ekranu VM-a kao czadmin (prva lozinka controlzit, mora se promeniti): otvara se meni za podešavanje. Vremenska zona i mreža mogu se kasnije menjati i u konzoli.

2. Instalacioni ISO

  1. Pokrenite VM ili server sa controlzit-appliance.iso. Posle 5 sekundi instalacija kreće sama: briše prvi disk, instalira Debian, PostgreSQL i ControlZit i traži pristup internetu (10–20 minuta).
  2. Posle restarta ekran pokazuje adresu konzole i token za podešavanje, kao kod slike VM.

3. Skripta za instalaciju

Na postojećem Linux serveru, kao root:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

Skripta instalira PostgreSQL, preuzima najnovije izdanje, proverava njegov potpis, pravi bazu sa nasumičnom lozinkom i pokreće servis. Opcije (posle sh -s --): --version X, --db postgres://… za postojeću bazu, --no-auto-updates da automatska bezbednosna ažuriranja operativnog sistema ostanu isključena. Ponovno pokretanje ažurira ControlZit i čuva podatke.

4. Paketi ručno

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Zatim upišite adresu baze u /etc/controlzit/server.env (CONTROLZIT_DB=postgres://…) i pokrenite servis sa systemctl enable --now controlzit-server.

Prva prijava

  • Token za podešavanje je u /var/lib/controlzit/setup-token.txt i u dnevniku servera (journalctl -u controlzit-server). Važi jednom.
  • Svaki nalog traži aplikaciju za autentifikaciju (TOTP) i dobija 10 rezervnih kodova. Čuvajte ih na sigurnom.
  • Konzola podrazumevano prihvata veze samo iz privatnih mreža. Ako se zaključate, pokrenite controlzit-server --reset-allowlist na serveru (na uređaju: meni za podešavanje, stavka 5).

Gde je šta

PutanjaŠta
/etc/controlzit/server.envkonfiguracija: baza, portovi, izvor ažuriranja (čitaju je samo root i servis)
/var/lib/controlzitdirektorijum podataka: sertifikati, tajni ključ, instalacije agenata (downloads), dnevnici
/var/lib/controlzit/logs/server.logdnevnik servera; i u journalctl -u controlzit-server
/var/log/controlzit-helperdnevnik root pomoćnika (ažuriranja, vremenska zona, mreža)

Bazu pravite rezervnu kopiju zajedno sa /var/lib/controlzit: tajni ključ odatle dešifruje sačuvane lozinke, a sertifikati predstavljaju server njegovim agentima.
