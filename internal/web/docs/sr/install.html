Instalacija servera

Izaberite jedan od pet načina. Gotova slika virtuelne mašine je najbrža; skripta za instalaciju odgovara postojećem Linux serveru, a Docker postojećem Docker hostu.

NačinNajbolje zaPotrebno
1. Slika VM (OVA, qcow2, VHDX)uvezi, pokreni, prijavi se, za nekoliko minutaVMware, Proxmox / KVM ili Hyper-V
2. Instalacioni ISOnova VM ili fizički server, bez pitanjapristup internetu tokom instalacije
3. Skripta za instalacijupostojeći Debian, Ubuntu, AlmaLinux ili Rocky Linux serverroot i pristup internetu
4. Paketi ručnosopstveni PostgreSQL, upravljanje konfiguracijom, serveri bez internetadeb ili rpm paket izdanja
5. Docker (container image)postojeći Docker host, NAS ili kućna laboratorijaDocker sa Compose dodatkom; pristup internetu za preuzimanje image-a

Svi fajlovi su na stranici izdanja. Serveru dajte 2 vCPU, 2–4 GB RAM i disk od 16 GB ili veći.

1. Slika virtuelne mašine

  1. Uvezite sliku:
    • VMware ESXi / Workstation, VirtualBox: uvezite rmmzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: napravite VM bez diska (2 vCPU, 2–4 GB RAM, VirtIO mreža), kopirajte rmmzit-appliance.qcow2 na čvor i pokrenite qm importdisk <vmid> rmmzit-appliance.qcow2 local-lvm; zakačite disk kao SCSI i postavite ga za disk za pokretanje.
    • Hyper-V: raspakujte rmmzit-appliance-vhdx.zip i napravite VM prve generacije sa tim VHDX-om kao diskom.
  2. Pokrenite VM. Disk se sam proširi na veličinu virtuelnog diska. Ekran VM-a pokazuje adresu konzole i token za podešavanje.
  3. Otvorite https://<adresa>:8443. Pregledač jednom upozori na samopotpisani sertifikat (kasnije ga zamenite u Podešavanja → Sertifikat). Unesite token i napravite prvog administratora.

Uređaj dobija adresu preko DHCP-a. Za fiksnu adresu, ime servera ili vremensku zonu prijavite se na samom ekranu VM-a kao rzadmin (prva lozinka rmmzit, mora se promeniti): otvara se meni za podešavanje. Vremenska zona i mreža mogu se kasnije menjati i u konzoli.

2. Instalacioni ISO

  1. Pokrenite VM ili server sa rmmzit-appliance.iso. Posle 5 sekundi instalacija kreće sama: briše prvi disk, instalira Debian, PostgreSQL i RMMZit i traži pristup internetu (10–20 minuta).
  2. Posle restarta ekran pokazuje adresu konzole i token za podešavanje, kao kod slike VM.

3. Skripta za instalaciju

Na postojećem Linux serveru, kao root:

curl -fsSL https://github.com/Max-Zit/rmmzit/releases/latest/download/install.sh | sudo sh

Skripta instalira PostgreSQL, preuzima najnovije izdanje, proverava njegov potpis, pravi bazu sa nasumičnom lozinkom i pokreće servis. Opcije (posle sh -s --): --version X, --db postgres://… za postojeću bazu, --no-auto-updates da automatska bezbednosna ažuriranja operativnog sistema ostanu isključena. Ponovno pokretanje ažurira RMMZit i čuva podatke.

4. Paketi ručno

sudo apt install ./rmmzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./rmmzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Zatim upišite adresu baze u /etc/rmmzit/server.env (RMMZIT_DB=postgres://…) i pokrenite servis sa systemctl enable --now rmmzit-server.

5. Docker

Server postoji i kao container image, ghcr.io/max-zit/rmmzit, napravljen od istog potpisanog paketa servera kao i ostali načini; radi sa PostgreSQL-om preko Docker Compose-a. Preuzmite docker-compose.yml i .env.example u jedan folder, kopirajte .env.example u .env, postavite lozinku baze (slova i cifre) i vremensku zonu, zatim:

docker compose up -d
docker compose exec rmmzit rmmzit-server -setup-token

Otvorite https://<host>:8443 i unesite setup token. Port 8444 je za agente; otvorite ga tamo odakle se agenti povezuju. Oznaka image-a u .env određuje šta radi: latest za zvanična izdanja, testing za kandidate.

Ažurirajte sa docker compose pull && docker compose up -d. Pre nego što nova verzija promeni bazu, server upisuje rezervnu kopiju u Podešavanja → Rezervna kopija konzole. Za povratak postavite prethodnu verziju kao oznaku image-a i vratite tu kopiju: docker compose stop rmmzit, docker compose run --rm rmmzit -restore /var/lib/rmmzit/backups/FAJL, docker compose up -d. U kontejneru mrežu i vremensku zonu podešava Docker host, a ne konzola.

Prva prijava

  • Token za podešavanje je u /var/lib/rmmzit/setup-token.txt i u dnevniku servera (journalctl -u rmmzit-server). Važi jednom.
  • Svaki nalog traži aplikaciju za autentifikaciju (TOTP) i dobija 10 rezervnih kodova. Čuvajte ih na sigurnom.
  • Konzola podrazumevano prihvata veze samo iz privatnih mreža. Ako se zaključate, pokrenite rmmzit-server --reset-allowlist na serveru (na uređaju: meni za podešavanje, stavka 5).

Gde je šta

PutanjaŠta
/etc/rmmzit/server.envkonfiguracija: baza, portovi, izvor ažuriranja (čitaju je samo root i servis)
/var/lib/rmmzitdirektorijum podataka: sertifikati, tajni ključ, instalacije agenata (downloads), dnevnici
/var/lib/rmmzit/logs/server.logdnevnik servera; i u journalctl -u rmmzit-server
/var/log/rmmzit-helperdnevnik root pomoćnika (ažuriranja, vremenska zona, mreža)

Bazu pravite rezervnu kopiju zajedno sa /var/lib/rmmzit: tajni ključ odatle dešifruje sačuvane lozinke, a sertifikati predstavljaju server njegovim agentima.
