API

REST API omogućava skriptama i drugim alatima da čitaju uređaje, alarme i zadatke i da pokreću poslove na uređajima, sa istim pravima kao u konzoli.

Tokeni

Token se pravi u Moj nalog → API tokeni: naziv, uloga koja nije veća od vaše (samo čitanje, tehničar ili administrator) i koliko dugo važi. Token se prikazuje jednom; čuvajte ga kao lozinku. Radi kao vi, sa vašim klijentima. Šaljite ga u svakom zahtevu kao Authorization: Bearer czt_… na adresu konzole (port 8443), koja prima veze samo iz dozvoljenih mreža. Kolačići sesije iz pregledača ne rade na API-ju. Brisanje tokena na stranici naloga odmah prekida njegov pristup.

Zadaci

Zadatak čeka dok uređaj ne bude na mreži i izvršava se posle ranijih zadataka uređaja, isto kao akcije u konzoli; vidi se u Aktivnostima uređaja. Odgovor je 202 sa zadatkom; pratite ga sa GET /api/v1/tasks/{id} dok mu status ne bude done, failed, cancelled ili expired. Vrste i njihova polja:

{"kind": "script", "shell": "powershell", "script": "Get-Service Spooler", "timeout": 120}
{"kind": "patch.scan"}
{"kind": "patch.install", "updates": [], "reboot": false}
{"kind": "winget", "action": "install", "id": "7zip.7zip"}
{"kind": "choco", "action": "upgrade", "id": "firefox"}
{"kind": "power", "action": "restart", "delay": 300, "message": "Restart for updates"}
{"kind": "agent.update"}
{"kind": "bitlocker.keys"}

Primeri

PowerShell skripta na uređaju 9, pa njen rezultat:

curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"kind":"script","shell":"powershell","script":"Get-Date","timeout":60}' \
  https://rmm.example.com:8443/api/v1/devices/9/tasks
curl -s -H "Authorization: Bearer $TOKEN" https://rmm.example.com:8443/api/v1/tasks/42

$h = @{ Authorization = "Bearer $env:CZ_TOKEN" }
Invoke-RestMethod -Headers $h https://rmm.example.com:8443/api/v1/alerts

Greške

Greške stižu kao JSON {"error": "…"} sa HTTP statusom: 400 za neispravan zahtev, 401 za token koji nedostaje, nije tačan ili je istekao, 403 kada uloga tokena ne dozvoljava poziv, 404 za nešto što ne postoji ili što token ne sme da vidi, 409 kada je zadatak već završen, 429 posle previše neuspelih prijava sa te adrese. Svaka promena kroz API beleži se u dnevnik aktivnosti sa nazivom tokena.
