Prvi koraci

ControlZit je alat za udaljeni nadzor i upravljanje (RMM) koji radi na vašem serveru. Iz jedne veb konzole pratite i održavate Windows i Linux računare svojih klijenata: inventar, nadzor i upozorenja, udaljenu radnu površinu, terminal, fajlove, skripte, Windows ažuriranja, programe i izveštaje.

Kako radi

  • Server radi na Linux mašini (obično maloj virtuelnoj mašini) sa PostgreSQL-om. Ima dva porta: konzolu (veb interfejs i API, TCP 8443) i tačku za agente (TCP 8444).
  • Agenti rade kao servis na svakom računaru kojim upravljate. Povezuju se ka serveru na port za agente; računarima ne treba nijedan otvoren port. Agent veruje serveru po otisku njegovog sertifikata, koji zapamti pri prijavi.
  • Svaku komandu agentu server potpisuje, a agent proverava, i svaka radnja se upisuje u dnevnik izmena koji se ne može neprimetno menjati.

Konzola upravlja svakim računarom. Neka bude dostupna samo iz vaših mreža (podrazumevano), a port za agente otvorite samo gde je agentima potreban. Vidi Bezbednost.

Prvi koraci

  1. Instalirajte server — uvezite gotovu sliku virtuelne mašine, pokrenite instalacioni ISO ili skriptu za instalaciju na Linux serveru. Vidi Instalacija servera.
  2. Napravite prvog administratora pomoću tokena za podešavanje koji pokazuje server i podesite prijavu u dva koraka sa aplikacijom za autentifikaciju.
  3. Proverite adresu za agente u Podešavanja → Mreža i pristup: agenti moraju da dođu do servera preko javne adrese za agente ili imena konzole.
  4. Dodajte klijenta i lokaciju u Klijenti, pa na lokaciji napravite kod za prijavu.
  5. Instalirajte agenta na računare te lokacije pomoću koda. Vidi Instalacija agenata.
  6. Podesite upozorenja i automatska Windows ažuriranja u polisi klijenta Default u Polise, a mejlove za alarme u Podešavanja → Nadzor i upozorenja.
  7. Dodajte tehničare u Korisnici ili povežite Active Directory / LDAP ili jedinstvenu prijavu. Vidi Korisnici, uloge i prijava.

Zahtevi

  • Server: 2 vCPU, 2–4 GB RAM, disk od 16 GB; Debian 12+, Ubuntu 22.04+, AlmaLinux ili Rocky Linux 9+ (ili gotov uređaj).
  • Windows agenti: Windows 10 / 11, Windows Server 2016 i noviji, 64-bitni.
  • Linux agenti: distribucije sa systemd-om, x86-64 ili ARM64 (Raspberry Pi i ARM serveri). Ažuriranja preko apt-a ili dnf-a.
  • Pregledač: aktuelni Chrome, Edge, Firefox ili Safari.
