Instalar el servidor

Elija una de cuatro formas. La imagen de VM lista para usar es la más rápida; el script de instalación sirve para un servidor Linux existente.

1. Imagen de VM (OVA, qcow2, VHDX)importar, arrancar e iniciar sesión en pocos minutosVMware, Proxmox / KVM o Hyper-V

Todos los archivos están en la página de versiones. Dé al servidor 2 vCPU, 2–4 GB de RAM y un disco de 16 GB o más.

1. Imagen de VM

  1. Importe la imagen:
    • VMware ESXi / Workstation, VirtualBox: despliegue controlzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: cree una VM sin disco (2 vCPU, 2–4 GB de RAM, red VirtIO), copie controlzit-appliance.qcow2 al nodo y ejecute qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm; conecte el disco como SCSI y conviértalo en el disco de arranque.
    • Hyper-V: descomprima controlzit-appliance-vhdx.zip y cree una VM de generación 1 con el VHDX como disco.
  2. Arranque la VM. El disco crece solo hasta el tamaño del disco virtual. La pantalla de la VM muestra la dirección de la consola y el token de configuración.
  3. Abra https://<dirección>:8443. El navegador avisa una vez del certificado autofirmado (sustitúyalo después en Configuración → Certificado). Introduzca el token y cree el primer administrador.

El appliance obtiene su dirección por DHCP. Para una dirección fija, el nombre del servidor o la zona horaria, inicie sesión en la pantalla de la VM como czadmin (primera contraseña controlzit, que debe cambiarse): se abre un menú de configuración. La zona horaria y la red también pueden cambiarse después en la consola.

2. ISO del appliance

  1. Arranque una VM o un servidor desde controlzit-appliance.iso. Tras 5 segundos la instalación empieza sola: borra el primer disco, instala Debian, PostgreSQL y ControlZit y necesita acceso a Internet (10–20 minutos).
  2. Tras reiniciar, la pantalla muestra la dirección de la consola y el token de configuración, como con la imagen de VM.

3. Script de instalación

En un servidor Linux existente, como root:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

El script instala PostgreSQL, descarga la versión más reciente, comprueba su firma, crea una base de datos con una contraseña aleatoria e inicia el servicio. Opciones (después de sh -s --): --version X, --db postgres://… para una base existente, --no-auto-updates para dejar desactivadas las actualizaciones de seguridad automáticas del sistema operativo. Ejecutarlo de nuevo actualiza ControlZit y conserva los datos.

4. Paquetes a mano

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Después escriba la dirección de la base de datos en /etc/controlzit/server.env (CONTROLZIT_DB=postgres://…) e inicie el servicio con systemctl enable --now controlzit-server.

Primer inicio de sesión

  • El token de configuración está en /var/lib/controlzit/setup-token.txt y en el registro del servidor (journalctl -u controlzit-server). Sirve una sola vez.
  • Cada cuenta necesita una aplicación de autenticación (TOTP) y recibe 10 códigos de recuperación. Guárdelos en un lugar seguro.
  • De forma predeterminada la consola solo acepta conexiones de redes privadas. Si se queda sin acceso, ejecute controlzit-server --reset-allowlist en el servidor (appliance: menú de configuración, opción 5).

Dónde está cada cosa

RutaQué
/etc/controlzit/server.envconfiguración: base de datos, puertos, origen de actualizaciones (solo la leen root y el servicio)
/var/lib/controlzitdirectorio de datos: certificados, clave secreta, instaladores de agentes (downloads), registros
/var/lib/controlzit/logs/server.logregistro del servidor; también en journalctl -u controlzit-server
/var/log/controlzit-helperregistro del asistente root (actualizaciones, zona horaria, red)

Haga copia de la base de datos junto con /var/lib/controlzit: la clave secreta de ahí descifra las contraseñas guardadas y los certificados identifican al servidor ante sus agentes.
