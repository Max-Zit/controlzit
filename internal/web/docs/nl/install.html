De server installeren

Kies een van vijf manieren. Het kant-en-klare VM-image is het snelst; het installatiescript past bij een bestaande Linux-server, Docker bij een bestaande Docker-host.

ManierHet best voorNodig

Alle bestanden staan op de releasepagina. Geef de server 2 vCPU, 2–4 GB RAM en een schijf van minstens 16 GB.

1. VM-image

  1. Importeer het image:
    • VMware ESXi / Workstation, VirtualBox: implementeer rmmzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: maak een VM zonder schijf (2 vCPU, 2–4 GB RAM, VirtIO-netwerk), kopieer rmmzit-appliance.qcow2 naar de node en voer qm importdisk <vmid> rmmzit-appliance.qcow2 local-lvm uit; koppel de schijf als SCSI en maak hem de opstartschijf.
    • Hyper-V: pak rmmzit-appliance-vhdx.zip uit en maak een VM van generatie 1 met de VHDX als schijf.
  2. Start de VM. De schijf groeit vanzelf tot de grootte van de virtuele schijf. Het scherm van de VM toont het adres van de console en het installatietoken.
  3. Open https://<adres>:8443. De browser waarschuwt eenmaal voor het zelfondertekende certificaat (vervang het later onder Instellingen → Certificaat). Voer het token in en maak de eerste beheerder aan.

De appliance krijgt zijn adres via DHCP. Voor een vast adres, de servernaam of de tijdzone meldt u zich op het scherm van de VM aan als rzadmin (eerste wachtwoord rmmzit, moet worden gewijzigd): er opent een installatiemenu. Tijdzone en netwerk kunnen later ook in de console worden gewijzigd.

2. Appliance-ISO

  1. Start een VM of server vanaf rmmzit-appliance.iso. Na 5 seconden begint de installatie vanzelf: ze wist de eerste schijf, installeert Debian, PostgreSQL en RMMZit en heeft internettoegang nodig (10–20 minuten).
  2. Na de herstart toont het scherm het consoleadres en het installatietoken, zoals bij het VM-image.

3. Installatiescript

Op een bestaande Linux-server, als root:

curl -fsSL https://github.com/Max-Zit/rmmzit/releases/latest/download/install.sh | sudo sh

Het script installeert PostgreSQL, downloadt de nieuwste release, controleert de handtekening, maakt een database met een willekeurig wachtwoord en start de service. Opties (na sh -s --): --version X, --db postgres://… voor een bestaande database, --no-auto-updates om de automatische beveiligingsupdates van het besturingssysteem uit te laten. Opnieuw uitvoeren werkt RMMZit bij en behoudt de gegevens.

4. Pakketten met de hand

sudo apt install ./rmmzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./rmmzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Zet daarna het databaseadres in /etc/rmmzit/server.env (RMMZIT_DB=postgres://…) en start de service met systemctl enable --now rmmzit-server.

5. Docker

De server bestaat ook als container-image, ghcr.io/max-zit/rmmzit, gebouwd uit hetzelfde ondertekende serverpakket als de andere manieren; hij draait met PostgreSQL via Docker Compose. Download docker-compose.yml en .env.example naar een map, kopieer .env.example naar .env, stel een databasewachtwoord (letters en cijfers) en de tijdzone in, en daarna:

docker compose up -d
docker compose exec rmmzit cat /var/lib/rmmzit/setup-token.txt

Open https://<host>:8443 en voer het installatietoken in. Poort 8444 is het eindpunt voor agents; open hem waar agents vandaan verbinden. De tag van de image in .env bepaalt wat er draait: latest voor officiële versies, testing voor releasekandidaten.

Werk bij met docker compose pull && docker compose up -d. Voordat een nieuwe versie de database wijzigt, schrijft de server een back-up naar Instellingen → Back-up van de console. Om terug te gaan, stelt u de vorige versie in als tag van de image en zet u dat bestand terug: docker compose stop rmmzit, docker compose run --rm rmmzit -restore /var/lib/rmmzit/backups/BESTAND, docker compose up -d. In een container horen het netwerk en de tijdzone bij de Docker-host, niet bij de console.

Eerste aanmelding

  • Het installatietoken staat in /var/lib/rmmzit/setup-token.txt en in het serverlogboek (journalctl -u rmmzit-server). Het werkt één keer.
  • Elk account heeft een authenticator-app (TOTP) nodig en krijgt 10 herstelcodes. Bewaar ze veilig.
  • De console accepteert standaard alleen verbindingen uit privénetwerken. Als u uzelf buitensluit, voer dan rmmzit-server --reset-allowlist uit op de server (appliance: installatiemenu, item 5).

Waar alles staat

PadWat
/etc/rmmzit/server.envconfiguratie: database, poorten, updatebron (alleen leesbaar voor root en de service)
/var/lib/rmmzitgegevensmap: certificaten, geheime sleutel, agent-installatieprogramma's (downloads), logboeken
/var/lib/rmmzit/logs/server.logserverlogboek; ook in journalctl -u rmmzit-server
/var/log/rmmzit-helperlogboek van de root-helper (updates, tijdzone, netwerk)

Maak een back-up van de database samen met /var/lib/rmmzit: de geheime sleutel daarin ontsleutelt de opgeslagen wachtwoorden en de certificaten identificeren de server bij zijn agents.
