De server installeren

Kies een van vier manieren. Het kant-en-klare VM-image is het snelst; het installatiescript past bij een bestaande Linux-server.

ManierHet best voorNodig
1. VM-image (OVA, qcow2, VHDX)importeren, starten, aanmelden, in een paar minutenVMware, Proxmox / KVM of Hyper-V
2. Appliance-ISOeen nieuwe VM of fysieke server, zonder tussenkomstinternettoegang tijdens de installatie
3. Installatiescripteen bestaande Debian-, Ubuntu-, AlmaLinux- of Rocky Linux-serverroot en internettoegang
4. Pakketten met de handeigen PostgreSQL, configuratiebeheer, offline servershet deb- of rpm-pakket van een release

Alle bestanden staan op de releasepagina. Geef de server 2 vCPU, 2–4 GB RAM en een schijf van minstens 16 GB.

1. VM-image

  1. Importeer het image:
    • VMware ESXi / Workstation, VirtualBox: implementeer controlzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: maak een VM zonder schijf (2 vCPU, 2–4 GB RAM, VirtIO-netwerk), kopieer controlzit-appliance.qcow2 naar de node en voer qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm uit; koppel de schijf als SCSI en maak hem de opstartschijf.
    • Hyper-V: pak controlzit-appliance-vhdx.zip uit en maak een VM van generatie 1 met de VHDX als schijf.
  2. Start de VM. De schijf groeit vanzelf tot de grootte van de virtuele schijf. Het scherm van de VM toont het adres van de console en het installatietoken.
  3. Open https://<adres>:8443. De browser waarschuwt eenmaal voor het zelfondertekende certificaat (vervang het later onder Instellingen → Certificaat). Voer het token in en maak de eerste beheerder aan.

De appliance krijgt zijn adres via DHCP. Voor een vast adres, de servernaam of de tijdzone meldt u zich op het scherm van de VM aan als czadmin (eerste wachtwoord controlzit, moet worden gewijzigd): er opent een installatiemenu. Tijdzone en netwerk kunnen later ook in de console worden gewijzigd.

2. Appliance-ISO

  1. Start een VM of server vanaf controlzit-appliance.iso. Na 5 seconden begint de installatie vanzelf: ze wist de eerste schijf, installeert Debian, PostgreSQL en ControlZit en heeft internettoegang nodig (10–20 minuten).
  2. Na de herstart toont het scherm het consoleadres en het installatietoken, zoals bij het VM-image.

3. Installatiescript

Op een bestaande Linux-server, als root:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

Het script installeert PostgreSQL, downloadt de nieuwste release, controleert de handtekening, maakt een database met een willekeurig wachtwoord en start de service. Opties (na sh -s --): --version X, --db postgres://… voor een bestaande database, --no-auto-updates om de automatische beveiligingsupdates van het besturingssysteem uit te laten. Opnieuw uitvoeren werkt ControlZit bij en behoudt de gegevens.

4. Pakketten met de hand

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Zet daarna het databaseadres in /etc/controlzit/server.env (CONTROLZIT_DB=postgres://…) en start de service met systemctl enable --now controlzit-server.

Eerste aanmelding

  • Het installatietoken staat in /var/lib/controlzit/setup-token.txt en in het serverlogboek (journalctl -u controlzit-server). Het werkt één keer.
  • Elk account heeft een authenticator-app (TOTP) nodig en krijgt 10 herstelcodes. Bewaar ze veilig.
  • De console accepteert standaard alleen verbindingen uit privénetwerken. Als u uzelf buitensluit, voer dan controlzit-server --reset-allowlist uit op de server (appliance: installatiemenu, item 5).

Waar alles staat

PadWat
/etc/controlzit/server.envconfiguratie: database, poorten, updatebron (alleen leesbaar voor root en de service)
/var/lib/controlzitgegevensmap: certificaten, geheime sleutel, agent-installatieprogramma's (downloads), logboeken
/var/lib/controlzit/logs/server.logserverlogboek; ook in journalctl -u controlzit-server
/var/log/controlzit-helperlogboek van de root-helper (updates, tijdzone, netwerk)

Maak een back-up van de database samen met /var/lib/controlzit: de geheime sleutel daarin ontsleutelt de opgeslagen wachtwoorden en de certificaten identificeren de server bij zijn agents.
