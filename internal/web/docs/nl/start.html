Aan de slag

ControlZit is een zelf gehoste tool voor bewaking en beheer op afstand (RMM). Vanuit één webconsole op uw eigen server bewaakt en beheert u de Windows- en Linux-computers van uw klanten: inventaris, bewaking en waarschuwingen, extern bureaublad, terminal, bestanden, scripts, Windows-updates, software en rapporten.

Hoe het werkt

  • De server draait op een Linux-machine (meestal een kleine VM) met PostgreSQL. Hij heeft twee poorten: de console (webinterface en API, TCP 8443) en het agent-eindpunt (TCP 8444).
  • Agents draaien als service op elke beheerde computer. Ze maken een uitgaande verbinding met de agentpoort; de computers hebben geen open poorten nodig. Een agent vertrouwt de server via de vingerafdruk van zijn certificaat, die hij bij registratie vastzet.
  • Elke opdracht aan een agent wordt door de server ondertekend en door de agent gecontroleerd, en elke actie wordt vastgelegd in het fraudebestendige auditlogboek.

De console beheert elke computer. Maak hem alleen bereikbaar vanuit uw eigen netwerken (standaard) en open alleen de agentpoort waar agents die nodig hebben. Zie Beveiliging.

Eerste stappen

  1. Installeer de server — importeer het kant-en-klare VM-image, start de appliance-ISO of voer het installatiescript uit op een Linux-server. Zie De server installeren.
  2. Maak de eerste beheerder aan met het installatietoken dat de server toont, en stel aanmelden in twee stappen in met een authenticator-app.
  3. Controleer het agentadres onder Instellingen → Netwerk en toegang: agents moeten de server bereiken via het openbare agentadres of de hostnaam van de console.
  4. Voeg een klant en een locatie toe onder Klanten en maak op de locatie een registratiecode aan.
  5. Installeer de agent met de code op de computers van die locatie. Zie Agents installeren.
  6. Stel waarschuwingen en automatische Windows-updates in in het beleid Default van de klant onder Beleid, en de waarschuwingsmails onder Instellingen → Bewaking en waarschuwingen.
  7. Voeg uw technici toe onder Gebruikers, of koppel Active Directory / LDAP of eenmalige aanmelding. Zie Gebruikers, rollen en aanmelden.

Vereisten

  • Server: 2 vCPU, 2–4 GB RAM, 16 GB schijf; Debian 12+, Ubuntu 22.04+, AlmaLinux of Rocky Linux 9+ (of de kant-en-klare appliance).
  • Windows-agents: Windows 10 / 11, Windows Server 2016 en nieuwer, 64-bit.
  • Linux-agents: distributies met systemd, x86-64 of ARM64 (Raspberry Pi en ARM-servers). Updates via apt of dnf.
  • Browser: een actuele Chrome, Edge, Firefox of Safari.
