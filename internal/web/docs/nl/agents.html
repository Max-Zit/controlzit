Agents installeren

De agent is een kleine service op elke beheerde computer. Hij maakt een uitgaande verbinding met de agentpoort van de server, meldt inventaris en meetwaarden en voert de ondertekende opdrachten van de console uit.

Voordat u begint

  • Agents moeten de server bereiken op de agentpoort (standaard TCP 8444). Voor computers buiten uw netwerk opent u deze poort in de firewall en stelt u het openbare agentadres in onder Instellingen → Netwerk en toegang (bijvoorbeeld https://rmm.example.com:8444). De consolepoort blijft dicht.
  • Als u de console op de server zelf hebt geopend (localhost) en er geen openbaar agentadres is ingesteld, waarschuwt de locatiepagina: agents zouden proberen verbinding te maken met het loopback-adres van de server.

Registratiecodes

Agents voegen zich bij een locatie van een klant met een registratiecode. Open de locatie onder Klanten en klik op Registratiecode aanmaken. U kiest hoe lang hij geldig is (1–365 dagen) en hoeveel computers hem mogen gebruiken. De code (RZ1-…) bevat het serveradres en de vingerafdruk van het servercertificaat, dus het installatieprogramma heeft niets anders nodig. Hij wordt maar één keer getoond; trek hem in als u hem niet meer nodig hebt.

Windows

Download de MSI op de locatiepagina (Agent downloaden (MSI, 64-bit)) en dubbelklik erop en plak de code, of installeer hem stil, bijvoorbeeld met Groepsbeleid, Intune of een script:

msiexec /i rmmzit-agent-x64.msi /qn ENROLLCODE="RZ1-…"

De agent draait als Windows-service RMMZit Agent. Een klein pictogram naast de klok toont of hij verbonden is (groen) en opent een venster met de server en wie de computer beheert.

Het pictogram, het venster en de herstartvraag gebruiken de weergavetaal van de Windows van de gebruiker (een van de 14 talen van de console, anders Engels).

Zonder de MSI (PowerShell als beheerder):

.\rmmzit-agent.exe enroll --code "RZ1-…"
.\rmmzit-agent.exe install

Linux

Download de Linux-agent op de locatiepagina (x86-64, of ARM64 voor Raspberry Pi en ARM-servers), kopieer hem naar de machine en voer hem uit als root:

chmod +x rmmzit-agent-linux-amd64
sudo ./rmmzit-agent-linux-amd64 install --code "RZ1-…"

Hij kopieert zichzelf naar /usr/local/bin/rmmzit-agent, registreert zich en start de systemd-service rmmzit-agent.

Agent-updates

De server bevat de agent-installatieprogramma's van zijn eigen versie. Onder Instellingen → Agent-updates ziet u welke agents verouderd zijn, werkt u ze allemaal tegelijk bij of laat u verouderde agents zichzelf bijwerken als ze verbinden. Eén agent werkt u bij op de apparaatpagina. De agent downloadt het installatieprogramma via zijn eigen versleutelde verbinding en installeert het alleen als het overeenkomt met de SHA-256 in de ondertekende updateopdracht. U kunt daar ook een ander installatieprogramma uploaden (een MSI of een Linux-agent).

Windows Update op beheerde computers

De agent schakelt via beleid de automatische installatie van Windows Update uit, zodat updates alleen via RMMZit komen, met de hand of volgens uw schema (zie Windows-updates). De vorige instellingen worden bewaard en komen terug als de agent wordt verwijderd.

Een agent verwijderen

Verwijder het apparaat op de pagina (Apparaat verwijderen). Is het online, dan verwijdert de agent zichzelf binnen enkele seconden en krijgt Windows Update zijn eigen instellingen terug. Een offline computer kan geen verbinding meer maken; verwijder daar de agent met de hand (Windows: Apps → RMMZit Agent → Verwijderen; Linux: sudo rmmzit-agent uninstall).

Veel computers: groepsbeleid en Intune

Maak een registratiecode met genoeg gebruiken voor alle computers; de locatiepagina toont dan, ingevuld met die code:

  • Groepsbeleid: een PowerShell-opstartscript. Zet de MSI op een share die de computeraccounts (Domain Computers) mogen lezen, vul het pad in, kopieer het script en voeg het toe onder Computerconfiguratie → Beleid → Windows-instellingen → Scripts → Opstarten → PowerShell-scripts. Computers met de agent (service RMMZitAgent) slaan het over; het installatielogboek is %windir%\Temp\rmmzit-agent-install.log.
  • Microsoft Intune: voeg de agent toe als Windows-app (Win32): verpak de MSI met IntuneWinAppUtil van Microsoft en gebruik de installatie- en verwijderopdrachten, het installatiegedrag Systeem en de detectieregel (bestand C:\Program Files\RMMZit Agent\rmmzit-agent.exe) van de locatiepagina. Voeg hem niet toe als line-of-business-MSI: de agent werkt zichzelf bij, en Intune zou de oude versie opnieuw installeren.
