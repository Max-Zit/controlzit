Scripts en geplande taken

Voer PowerShell, cmd, bash of sh uit op één apparaat, op veel apparaten tegelijk of volgens schema. Scripts draaien als SYSTEM (Windows) of root (Linux), zonder venster.

Op één apparaat

Open op een apparaatpagina Scripts, kies de shell, schrijf het script (of laad er een uit de bibliotheek) en stel een tijdslimiet in (5–1500 seconden). De pagina toont de afsluitcode en de uitvoer (de eerste 1 MB) als het script binnen enkele seconden klaar is; een langer script loopt door onder Activiteit, waar het ook gestopt kan worden. Eerdere uitvoeringen blijven in de lijst; Bewerken en opnieuw uitvoeren opent een uitvoering als nieuw script.

Scriptbibliotheek

Sla scripts die u vaak gebruikt op onder Scripts → Scriptbibliotheek, met een naam en beschrijving. Vandaar voert u een script uit op geselecteerde apparaten, op alle apparaten van enkele klanten of op alle apparaten.

Taken

Een bibliotheekscript op meerdere apparaten uitvoeren maakt een taak. De taakpagina toont elk apparaat met zijn status (wachtend, bezig, geslaagd, mislukt, verlopen) en uitvoer. Afsluitcode 0 telt als geslaagd. Offline apparaten voeren het script uit wanneer ze verbinden, binnen 24 uur; daarna tellen ze als verlopen.

Schema's

Een script uit de bibliotheek kan volgens schema draaien: op gekozen weekdagen op een tijd (servertijd), op afzonderlijke apparaten, op alle apparaten van enkele klanten of op alle apparaten (ook nieuwe). Een schema kan worden gepauzeerd en hervat. Apparaten die op dat moment offline zijn, voeren het script uit wanneer ze verbinden, binnen 24 uur.

Wat wordt vastgelegd

Het script en het begin van de uitvoer worden met uw naam in het auditlogboek gezet. Alleen-lezengebruikers kunnen geen scripts uitvoeren.

Scripts hebben volledige rechten op de computers. Houd de bibliotheek netjes, geef technici alleen de klanten die ze nodig hebben en test een script op één apparaat voordat u het op veel apparaten uitvoert.
