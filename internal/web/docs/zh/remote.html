远程桌面、终端和文件

在浏览器中帮助用户和修复计算机：您这边无需软件，对方无需开放端口。一切都通过代理的加密连接进行，并写入审计日志。

远程桌面

打开一台设备并点击远程桌面（或在单独窗口中打开）。您可以看到屏幕，并用鼠标和键盘进行控制。

  • 键盘：点击屏幕即可输入；按键以远程计算机自身的键盘布局发送。发送 Ctrl+Alt+Del 和发送文本（输入一段文本，例如长密码）位于工具栏中。全屏时，Ctrl+W 或 Windows 键等快捷键也会发送到远程计算机；按住 Esc 可退出全屏。
  • 质量：根据连接选择快速、均衡或清晰。
  • 显示器：选择一台显示器或全部显示器。
  • 登录屏幕和 UAC 屏幕会显示并可操作，因此您可以登录并确认管理员提示。

剪贴板和文件

在 Windows 计算机上，复制的文本可通过 Ctrl+C 和 Ctrl+V 双向传递。在您的资源管理器中复制的文件可通过 Ctrl+V 粘贴到远程计算机上。在远程计算机上复制的文件会以下载方式提供（下载复制的文件），因为浏览器无法将文件放入您的剪贴板。剪贴板交换可在设置 → 远程桌面中关闭。

远程屏幕上的提示

默认情况下，在您连接期间，计算机前的人会在屏幕顶部看到一个显示您姓名的横条。您在画面中看不到这个横条。可以在设置 → 远程桌面中关闭；无论如何，每个会话都会写入审计日志。

Linux

远程桌面适用于使用 X11（Xorg）的 Linux 桌面。Wayland 不允许后台服务查看或控制屏幕：请在那里使用 X11 会话登录，或使用终端。没有图形桌面时，请使用终端。

终端（Linux、Windows）

终端会在浏览器中打开设备的 root Shell。点击其中即可输入；选中文本即复制，用 Ctrl+Shift+V 或发送文本粘贴。会话的开始和结束会写入审计日志。在 Windows 上请使用脚本。

在 Windows 上（0.12 及以上版本的代理，Windows 10 1809 / Server 2019 及更新版本），终端是以 SYSTEM 身份在伪控制台上运行的 Windows PowerShell。离开页面会结束该 shell 及其启动的所有程序。

文件

文件无需连接屏幕即可浏览计算机的驱动器。上传文件（最大 4 GB）、下载文件、将文件夹或所选内容下载为 ZIP、创建文件夹、重命名和删除。代理以 SYSTEM（Windows）或 root（Linux）身份执行每个文件操作；每个操作都会以您的名义写入审计日志。

进程和服务

进程列出正在运行的程序及其内存、线程和会话，并可结束进程。服务列出服务（Windows 服务或 systemd 单元），并可启动、停止或重启它们。ControlZit 代理会保护自身：无法从控制台停止或结束。

注册表编辑器（Windows）

Windows 设备的 Registry 选项卡用于浏览注册表：按路径打开键（例如 HKLM\SOFTWARE\Vendor），或从根键 HKLM、HKU、HKCR 和 HKCC 逐级点开。可以添加、修改和删除值（REG_SZ、REG_EXPAND_SZ、REG_DWORD、REG_QWORD、REG_MULTI_SZ；数字使用十进制或 0x 十六进制）；二进制值以十六进制显示。可以创建键，也可以连同其全部内容删除键；根键、紧邻其下的键以及系统自身的分支受保护。每次更改都会连同被替换的值写入审计日志。各用户的注册表位于 HKU 下（按其 SID）；HKCU 将是 SYSTEM 自己的。需要 0.12 及以上版本的代理。

计划任务（Windows）

Scheduled tasks 选项卡列出任务计划程序中的任务，包括状态、上次运行及结果、下次运行、帐户和命令。Windows 自带的任务（位于 \Microsoft\ 下）默认隐藏，除非选择包括它们。任务可以运行、结束、启用、禁用和删除；每个操作都会记录审计。需要 0.12 及以上版本的代理。
