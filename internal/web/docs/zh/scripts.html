脚本与计划作业

在一台设备、多台设备或按计划运行 PowerShell、cmd、bash 或 sh。脚本以 SYSTEM（Windows）或 root（Linux）身份无窗口运行。

在一台设备上

在设备页面打开脚本，选择 Shell，编写脚本（或从脚本库加载），并设置时间限制（5–1500 秒）。页面会等待结果，显示退出代码和输出（前 1 MB）。之前的运行会保留在列表中；编辑并重新运行会将某次运行作为新脚本打开。

脚本库

将常用的脚本连同名称和描述保存到脚本 → 脚本库中。从那里可以在所选设备、某些客户的所有设备或所有设备上运行脚本。

作业

在多台设备上运行脚本库中的脚本会创建一个作业。作业页面显示每台设备的状态（等待中、运行中、成功、失败、已过期）及其输出。退出代码 0 视为成功。离线设备会在连接时（24 小时内）运行脚本；超过此时间则视为已过期。

计划

脚本库中的脚本可以按计划运行：在所选的星期几的某个时间（服务器时间），在单个设备、某些客户的所有设备或所有设备（包括新设备）上运行。计划可以暂停和恢复。当时离线的设备会在连接时（24 小时内）运行脚本。

记录内容

脚本及其输出的开头会以您的名义写入审计日志。只读用户无法运行脚本。

脚本在计算机上拥有完全权限。请保持脚本库整洁，只给技术员分配他们需要的客户，并在多台设备上运行脚本之前先在一台设备上测试。
