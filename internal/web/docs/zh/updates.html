Windows 更新与软件

ControlZit 显示每台计算机缺少哪些更新，并可手动或按您的计划安装。程序通过 winget 安装和更新。

概览

更新列出缺少更新的设备（安全更新单独统计）、等待重启的设备、上次安装和上次搜索。代理在启动几分钟后搜索缺少的更新，之后每天搜索两次；立即搜索会立刻开始搜索。

在一台设备上

设备的更新选项卡列出缺少的更新及其类别和严重性，以及最近安装的更新。选择更新并点击安装所选；完成后页面会显示结果。如果需要重启，设备会显示提示，您可以从其页面重启。

Defender 定义（Security Intelligence Update）每天发布多次，每次都有新的更新 ID。安装时，代理会先重新搜索，然后安装 Windows Update 当时提供的定义版本。

自动安装

在设置 → Windows 更新中选择服务器自动安装的内容：

  • 关闭——仅从控制台安装更新。
  • 安全和关键更新、Defender 定义。
  • 除功能升级外的所有更新——Windows 新版本永远不会自动安装。

选择日期和小时（服务器时间）。在该小时内在线的设备当天安装一次；离线设备等待下一个计划日。可选：当更新需要重启时，计算机会在提示已登录用户 5 分钟后自动重启。

为避免更新在随机时间到来，代理会通过策略关闭 Windows 更新的自动安装。移除代理后，之前的设置会恢复。

Linux

在 Linux 上，代理通过 apt（Debian、Ubuntu；安全更新来自 -security 源）或 dnf（RHEL 系列；安全更新依据更新信息）读取可用的软件包更新，并安装所选软件包。自动安装同样适用于 Linux 设备；在那里，“安全更新”指来自安全源的软件包。

程序（winget）

Windows 设备的程序选项卡分为三部分。可用更新列出 winget 可以更新的程序；全部更新会更新它们，也可以单独更新程序。已安装列出 Windows 已安装程序列表中的每个程序，包括计算机级和已登录用户的程序，并可按名称或发布者筛选。卸载以静默方式删除程序：Windows Installer（MSI）包使用 msiexec /x，Inno Setup 和 NSIS 卸载程序使用其静默参数，或使用程序自带的静默命令。只有在程序确实被删除后才会报告结果；没有静默卸载程序的程序会被标记，需要在计算机上或通过脚本删除。安装程序在 winget 社区存储库中搜索（例如 7-Zip 或 Chrome），并为所有用户静默安装。安装和更新需要 winget（App Installer），当前的 Windows 10 和 11 已自带。
