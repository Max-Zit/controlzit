安装代理

代理是每台受管计算机上的一个小型服务。它以出站方式连接到服务器的代理端口，报告清单和指标，并执行控制台发出的已签名命令。

开始之前

  • 代理必须能通过代理端口（默认 TCP 8444）访问服务器。对于您网络之外的计算机，请在防火墙上开放此端口，并在设置 → 网络与访问中设置代理公网地址（例如 https://rmm.example.com:8444）。控制台端口保持关闭。
  • 如果您是在服务器本身（localhost）上打开的控制台，且没有设置代理公网地址，站点页面会发出警告：代理会尝试连接服务器的回环地址。

注册码

代理通过注册码加入客户的某个站点。在客户中打开站点，然后点击创建注册码。您可以选择有效期（1–365 天）以及可以使用它的计算机数量。代码（RZ1-…）包含服务器地址及其证书指纹，因此安装程序不需要其他任何信息。它只显示一次；不再需要时请撤销。

Windows

在站点页面下载 MSI（下载代理（MSI，64 位）），双击并粘贴代码，或者通过组策略、Intune 或脚本静默安装：

msiexec /i rmmzit-agent-x64.msi /qn ENROLLCODE="RZ1-…"

代理作为 Windows 服务 RMMZit Agent 运行。时钟旁的小图标显示它是否已连接（绿色），并可打开一个窗口，显示服务器以及由谁管理这台计算机。

图标、其窗口和重启询问使用用户 Windows 的显示语言（控制台的 14 种语言之一，否则为英语）。

不使用 MSI（以管理员身份运行 PowerShell）：

.\rmmzit-agent.exe enroll --code "RZ1-…"
.\rmmzit-agent.exe install

Linux

在站点页面下载 Linux 代理（x86-64，或用于 Raspberry Pi 和 ARM 服务器的 ARM64），复制到计算机并以 root 身份运行：

chmod +x rmmzit-agent-linux-amd64
sudo ./rmmzit-agent-linux-amd64 install --code "RZ1-…"

它会将自身复制到 /usr/local/bin/rmmzit-agent，完成注册并启动 systemd 服务 rmmzit-agent。

代理更新

服务器自带与其版本相同的代理安装程序。在设置 → 代理更新中，您可以查看哪些代理已过时、一次性全部更新，或让过时的代理在连接时自动更新。单个代理可在其设备页面上更新。代理通过自己的加密连接下载安装程序，并且只有在与已签名更新命令中的 SHA-256 一致时才会安装。您也可以在那里上传其他安装程序（MSI 或 Linux 代理）。

受管计算机上的 Windows 更新

代理通过策略关闭 Windows 更新的自动安装，使更新只来自 RMMZit，可以手动安装或按您的计划安装（请参阅Windows 更新）。之前的设置会被保存，并在移除代理时恢复。

移除代理

在设备页面上删除设备（移除设备）。如果设备在线，代理会在几秒内自行卸载，Windows 更新会恢复其自身的设置。离线计算机将无法再连接；请在其上手动卸载代理（Windows：应用 → RMMZit Agent → 卸载；Linux：sudo rmmzit-agent uninstall）。

大量计算机：组策略和 Intune

创建一个使用次数足够所有计算机的注册码；站点页面随后会显示以下内容（已填入该注册码）：

  • 组策略：一个 PowerShell 启动脚本。将 MSI 放到计算机帐户（Domain Computers）可读取的共享中，输入其路径，复制脚本并将其添加到 计算机配置 → 策略 → Windows 设置 → 脚本 → 启动 → PowerShell 脚本。已安装代理（服务 RMMZitAgent）的计算机会跳过；安装日志为 %windir%\Temp\rmmzit-agent-install.log。
  • Microsoft Intune：将代理添加为 Windows 应用（Win32）：用 Microsoft 的 IntuneWinAppUtil 打包 MSI，并使用站点页面上的安装和卸载命令、安装行为系统以及检测规则（文件 C:\Program Files\RMMZit Agent\rmmzit-agent.exe）。不要作为业务线（LOB）MSI 添加：代理会自行更新，Intune 随后会重新安装旧版本。
