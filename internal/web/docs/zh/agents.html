安装代理

代理是每台受管计算机上的一个小型服务。它以出站方式连接到服务器的代理端口，报告清单和指标，并执行控制台发出的已签名命令。

开始之前

  • 代理必须能通过代理端口（默认 TCP 8444）访问服务器。对于您网络之外的计算机，请在防火墙上开放此端口，并在设置 → 网络与访问中设置代理公网地址（例如 https://rmm.example.com:8444）。控制台端口保持关闭。
  • 如果您是在服务器本身（localhost）上打开的控制台，且没有设置代理公网地址，站点页面会发出警告：代理会尝试连接服务器的回环地址。

注册码

代理通过注册码加入客户的某个站点。在客户中打开站点，然后点击创建注册码。您可以选择有效期（1–365 天）以及可以使用它的计算机数量。代码（CZ1-…）包含服务器地址及其证书指纹，因此安装程序不需要其他任何信息。它只显示一次；不再需要时请撤销。

Windows

在站点页面下载 MSI（下载代理（MSI，64 位）），双击并粘贴代码，或者通过组策略、Intune 或脚本静默安装：

msiexec /i controlzit-agent-x64.msi /qn ENROLLCODE="CZ1-…"

代理作为 Windows 服务 ControlZit Agent 运行。时钟旁的小图标显示它是否已连接（绿色），并可打开一个窗口，显示服务器以及由谁管理这台计算机。

图标、其窗口和重启询问使用用户 Windows 的显示语言（控制台的 14 种语言之一，否则为英语）。

不使用 MSI（以管理员身份运行 PowerShell）：

.\controlzit-agent.exe enroll --code "CZ1-…"
.\controlzit-agent.exe install

Linux

在站点页面下载 Linux 代理（x86-64，或用于 Raspberry Pi 和 ARM 服务器的 ARM64），复制到计算机并以 root 身份运行：

chmod +x controlzit-agent-linux-amd64
sudo ./controlzit-agent-linux-amd64 install --code "CZ1-…"

它会将自身复制到 /usr/local/bin/controlzit-agent，完成注册并启动 systemd 服务 controlzit-agent。

代理更新

服务器自带与其版本相同的代理安装程序。在设置 → 代理更新中，您可以查看哪些代理已过时、一次性全部更新，或让过时的代理在连接时自动更新。单个代理可在其设备页面上更新。代理通过自己的加密连接下载安装程序，并且只有在与已签名更新命令中的 SHA-256 一致时才会安装。您也可以在那里上传其他安装程序（MSI 或 Linux 代理）。

受管计算机上的 Windows 更新

代理通过策略关闭 Windows 更新的自动安装，使更新只来自 ControlZit，可以手动安装或按您的计划安装（请参阅Windows 更新）。之前的设置会被保存，并在移除代理时恢复。

移除代理

在设备页面上删除设备（移除设备）。如果设备在线，代理会在几秒内自行卸载，Windows 更新会恢复其自身的设置。离线计算机将无法再连接；请在其上手动卸载代理（Windows：应用 → ControlZit Agent → 卸载；Linux：sudo controlzit-agent uninstall）。
