快速入门

ControlZit 是一款自托管的远程监控与管理（RMM）工具。您可以通过自己服务器上的一个 Web 控制台，监控和管理客户的 Windows 和 Linux 计算机：清单、监控与警报、远程桌面、终端、文件、脚本、Windows 更新、软件和报告。

ControlZit 能做什么

领域您将获得
清单每台设备的硬件、操作系统、磁盘、网络、安全状态（防病毒、防火墙、BitLocker）和已安装的软件。设备
监控与警报CPU、内存、磁盘空间、离线设备、已停止的服务、Defender 和防火墙；通过电子邮件、Slack、Microsoft Teams 或 Webhook 发送警报。监控
远程访问浏览器中的远程桌面（Windows、带 X11 的 Linux），支持剪贴板和文件复制；Linux 上的 root 终端、文件管理器、进程、服务、重启和关机。远程访问
脚本从脚本库在一台设备、多台设备或按计划运行 PowerShell、cmd、bash 或 sh。脚本
更新与软件缺少的 Windows 更新和 Linux 软件包，手动或按计划安装，通过 winget 安装程序。更新
报告每个客户一份报告（设备、更新、警报、技术员的工作），可打印，也可每周或每月通过邮件发送。报告

工作原理

  • 服务器运行在一台带 PostgreSQL 的 Linux 机器上（通常是一台小型虚拟机）。它有两个端口：控制台（Web 界面和 API，TCP 8443）和代理端点（TCP 8444）。
  • 代理作为服务运行在每台受管计算机上。它们以出站方式连接到代理端口；计算机无需开放任何端口。代理通过服务器证书的指纹信任服务器，该指纹在注册时固定。
  • 发给代理的每条命令都由服务器签名并由代理验证，每个操作都会写入防篡改的审计日志。

控制台控制每台受管计算机。请仅允许从您自己的网络访问它（默认设置），并且只在代理需要的地方开放代理端口。请参阅安全。

第一步

  1. 安装服务器——导入现成的虚拟机镜像、启动设备 ISO，或在 Linux 服务器上运行安装脚本。请参阅安装服务器。
  2. 创建第一个管理员：使用服务器显示的设置令牌，并用身份验证器应用设置双重验证登录。
  3. 检查代理地址：在设置 → 网络与访问中，代理必须能通过代理公网地址或控制台主机名访问服务器。
  4. 添加客户和站点：在客户中添加，然后在站点上创建注册码。
  5. 安装代理：使用该代码在该站点的计算机上安装。请参阅安装代理。
  6. 设置警报：在设置 → 监控与警报中设置，如有需要，也可设置Windows 更新的自动安装。
  7. 添加技术员：在用户中添加，或连接 Active Directory / LDAP 或单点登录。请参阅用户、角色与登录。

系统要求

  • 服务器：2 个 vCPU、2–4 GB 内存、16 GB 磁盘；Debian 12+、Ubuntu 22.04+、AlmaLinux 或 Rocky Linux 9+（或现成的设备）。
  • Windows 代理：Windows 10 / 11、Windows Server 2016 及更高版本，64 位。
  • Linux 代理：带 systemd 的发行版，x86-64 或 ARM64（Raspberry Pi 和 ARM 服务器）。通过 apt 或 dnf 更新。
  • 浏览器：最新版 Chrome、Edge、Firefox 或 Safari。
