客户、站点和设备

设备按客户和站点组织。技术员和只读用户可以被限制为只能访问部分客户，因此每份报告和每个列表只显示他们可以看到的内容。

客户和站点

  • 客户是您服务的公司（或您自己公司的部门）。在客户中添加。
  • 站点是他们的办公室或分支机构。每台设备属于一个站点；注册码按站点创建。
  • 只有当客户或站点中不再包含站点或设备时，才能将其删除。

设备列表

设备列出您可以看到的所有设备，以及它们的客户和站点、操作系统、已登录用户、是否在线和最后出现时间。可以按名称、用户、系统或客户搜索，或按客户和状态筛选。

筛选可按客户、状态（在线、离线）、操作系统、未解决的警报、可修复的漏洞、策略或自定义字段缩小列表。技术人员用设备前面的复选框选择设备（或一次全选），然后对所有设备启动操作：库中的脚本（作为作业）、搜索并安装安全更新、用 winget 更新程序、刷新清单或 5 分钟后重启。离线设备会在连接时收到操作；每台设备的活动会显示进度。

页眉中的搜索（Ctrl+K 或 /）可按名称、用户、系统、序列号、IP 或 MAC 地址查找设备，还可查找客户、已安装的程序（及安装了这些程序的设备）以及按 ID 查找漏洞。

设备页面

设备页面为您可以对它执行的所有操作提供了选项卡：

选项卡显示或执行的内容
概览未处理的警报、当前负载、内存和磁盘、未运行的自动服务、待处理的重启；下方是完整清单。
远程桌面、终端、文件远程访问，请参阅远程桌面、终端和文件。
进程、服务正在运行的进程（结束）和服务（启动、停止、重启）。
脚本运行脚本并查看之前的运行及其输出，请参阅脚本。
更新缺少的和最近安装的 Windows 更新或 Linux 软件包，请参阅更新。
程序通过 winget 安装、更新和卸载程序（Windows）。
事件Windows 事件日志（System、Application、Security、Setup），可按级别、时间段和文本筛选。
活动控制台在设备上正在执行的操作：可以停止或取消的运行中和等待中的任务，以及历史记录，请参阅活动。

活动

控制台在设备上的每个操作都是一个任务：脚本、库任务、搜索和安装 Windows 更新、安装和卸载程序（winget、Chocolatey、软件库）、代理更新、重启和关机，也包括服务器的自动操作。设备的活动选项卡显示正在运行和正在等待的任务，以及带有结果和启动者的历史记录；选项卡上的数字是运行中和等待中的任务数。任务名称链接到其详细信息，例如脚本的输出。

设备的任务依次运行。如果设备离线，任务会等待其连接，最多 24 小时。您可以随时离开页面：快速任务会立即显示结果，较长的任务会继续运行，活动选项卡会自动刷新。取消会移除等待中的任务；停止会结束运行中的任务：代理会停止为其运行的脚本或安装程序，包括它们启动的进程。Windows 仍可能完成当时正在安装的更新。

清单

代理在连接几秒后发送清单，之后定期发送：操作系统和版本号、域或工作组、型号和序列号、处理器、内存、磁盘及其可用空间和 BitLocker 状态、网络适配器及其地址和网关、Microsoft Defender 及其特征库、Windows 防火墙配置文件、待处理的重启以及已安装的软件（Windows 上的程序、Linux 上的软件包）。刷新清单会立即请求新的清单。

重启和关机

设备页面上的电源按钮可立即或延迟重启或关闭计算机，并可向已登录用户发送消息；计划的重启可以取消。已登录的用户会丢失未保存的工作。

移除设备

移除设备会将其从控制台中删除。在线的代理会自行卸载；请参阅移除代理。
