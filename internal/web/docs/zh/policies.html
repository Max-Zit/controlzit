策略

策略为其分配到的客户、站点或设备设置 Windows Update、必需软件、警报规则和自动化，使一个办公室或一个客户的所有计算机都以相同方式管理。

策略的组成部分

  • Windows Update — 自动安装哪些内容、在哪些日期和几点安装，以及更新需要时计算机是否重启。
  • 必需软件 — 此策略下每台 Windows 设备都必须安装的程序；缺少的由服务器安装。
  • 警报规则 — CPU、内存、磁盘、离线设备和待重启的阈值，Defender 和防火墙，以及必须运行的服务。
  • 自动化 — 在指定日期和时间于策略的设备上运行的库脚本。
  • BitLocker — 加密系统驱动器，恢复密钥保存在服务器上。
  • 网络检查 — 设备每分钟从自己的网络检查的地址（ping、TCP 端口、网址）。
  • 程序更新 — 在指定日期或维护时间窗口内更新 winget 或 Chocolatey 识别的已安装程序。
  • 维护时间窗口 — 设备可以繁忙的时间：安装、强制重启，以及可选的不产生新警报。

每个部分都可以在策略中开启或关闭。关闭的部分不由此策略设置：它来自不太具体的策略或内置默认值（不自动更新，标准警报规则）。

分配策略

在策略中创建策略。在策略页面上，分配给可将其分配给客户、站点或单台设备；设备的策略选项卡用于设置设备自己的策略。每个客户、站点或设备只有一个策略；分配另一个会替换它。

每个部分以设置了该部分的最具体分配为准：设备的策略，然后是站点的，然后是客户的，最后是内置默认值。示例：客户的策略设置 Windows Update 和必需软件，某站点的策略只设置更严格的警报规则——该站点的设备获得客户的更新和软件以及站点的警报规则。

策略属于某个客户或整个服务器，在创建时选择。技术人员可以创建和修改其客户的策略，并将其分配给这些客户及其站点和设备；管理员可以管理所有策略，并且只有管理员可以创建适用于整个服务器的策略和设置 BitLocker 部分。客户的策略永远不能分配到该客户之外。

每个新客户都会获得自己的策略 Default，分配给该客户，带有内置的 Windows Update 和警报设置；您可以修改它，或为站点和设备分配各自的策略。升级到 0.6.3 版时，每个没有策略的现有客户都获得了一个 Default 策略，其中包含服务器以前的 Windows Update 和警报设置，这些设置已不再位于“设置”中。

必需软件

每个必需程序都有一个来源（软件库、winget 或 Chocolatey）以及它在 Windows 已安装程序列表中的名称所包含的文字（例如 7-Zip）。服务器每隔几分钟将必需程序与每台在线 Windows 设备的清单进行比较；缺少的程序会作为任务安装，您可以在设备的活动中看到。安装后设备会发送新的清单。如果程序仍然缺少，服务器会在 6 小时后重试。设备发送第一份清单之前不会安装任何内容。

警报规则

策略的阈值适用于其设备。警报邮件和聊天渠道在监控与警报中为整个服务器设置。

自动化

自动化会在所选日期和时间（服务器时间）运行脚本库中的脚本，作为一个任务覆盖其自动化来自此策略的所有设备。离线设备会在 24 小时内连接时运行；结果显示在任务页面和每台设备的活动中。

BitLocker 和恢复密钥

服务器会保存其 Windows 设备的 BitLocker 恢复密钥：每天从每台启用了 BitLocker 的设备读取一次，设备 BitLocker 页面（可从设备概览的 BitLocker 行进入）上的立即读取恢复密钥可立即读取。密钥使用服务器的密钥加密保存。只有管理员在输入密码后才能显示密钥；每次显示密钥和每次输错密码都会记录到审核日志中。

启用了要求在系统驱动器上启用 BitLocker的策略会在系统驱动器未加密的 Windows 设备上启用它。代理会先检查 TPM 并添加恢复密钥；服务器保存密钥后才开始加密（TPM 保护器、XTS-AES 256、仅已用空间），加密在后台进行，不影响使用计算机。没有就绪 TPM 或 Windows 版本不含 BitLocker（家庭版）的设备会在“活动”中显示原因，服务器会在 6 小时后重试。管理员也可以在单台设备的 BitLocker 页面上为其启用。

程序更新

程序更新部分会更新有新版本的已安装程序：winget 识别的程序，以及可选的通过 Chocolatey 安装的程序。它在每个选定日期的选定小时运行一次，或在维护时间窗口内运行。不更新列表中的程序（软件包 ID 或名称的一部分）不受影响。设置更新环延迟后，新版本会在服务器首次发现后等待相应天数。每次运行都显示在设备的活动中。

维护时间窗口

维护时间窗口是每周的一段时间，例如周六 22:00 起 4 小时（服务器时间）。设为在维护时间窗口内的 Windows 更新和程序更新在此时运行，超过期限的重启会等待下一个时间窗口。选中维护时间窗口内不产生新警报后，时间窗口打开期间设备不会产生新警报；已打开的警报保持不变。

设备适用的设置

设备的策略选项卡显示每个部分由哪个策略设置（以及它分配给设备、其站点还是其客户）或使用内置默认值，每个必需程序的状态（已安装、缺失、何时开始安装），生效的 Windows Update 和警报设置以及自动化。
