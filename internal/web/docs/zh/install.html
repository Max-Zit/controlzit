安装服务器

从五种方式中选择一种。现成的虚拟机镜像最快；安装脚本适用于现有的 Linux 服务器，Docker 适用于现有的 Docker 主机。

方式最适合需要
1. 虚拟机镜像（OVA、qcow2、VHDX）几分钟内导入、启动并登录VMware、Proxmox / KVM 或 Hyper-V
2. 设备 ISO新虚拟机或物理服务器，无人值守安装期间可访问互联网
3. 安装脚本现有的 Debian、Ubuntu、AlmaLinux 或 Rocky Linux 服务器root 权限和互联网访问
4. 手动安装软件包自有 PostgreSQL、配置管理、离线服务器某个版本的 deb 或 rpm 软件包
5. Docker（容器镜像）现有的 Docker 主机、NAS 或家庭实验室带 Compose 插件的 Docker；拉取镜像需要互联网访问

所有文件都在版本页面上。请为服务器分配 2 个 vCPU、2–4 GB 内存和至少 16 GB 磁盘。

1. 虚拟机镜像

  1. 导入镜像：
    • VMware ESXi / Workstation、VirtualBox：部署 rmmzit-appliance.ova（Create / Register VM → Deploy a virtual machine from an OVF or OVA file）。
    • Proxmox VE：创建一台没有磁盘的虚拟机（2 个 vCPU、2–4 GB 内存、VirtIO 网络），将 rmmzit-appliance.qcow2 复制到节点并运行 qm importdisk <vmid> rmmzit-appliance.qcow2 local-lvm；将磁盘作为 SCSI 挂载并设为启动盘。
    • Hyper-V：解压 rmmzit-appliance-vhdx.zip，创建一台以该 VHDX 为磁盘的第 1 代虚拟机。
  2. 启动虚拟机。磁盘会自动扩展到虚拟磁盘的大小。虚拟机屏幕会显示控制台地址和设置令牌。
  3. 打开 https://<地址>:8443。浏览器会对自签名证书提示一次警告（之后可在设置 → 证书中替换）。输入令牌并创建第一个管理员。

设备通过 DHCP 获取地址。如需设置固定地址、服务器名称或时区，请在虚拟机屏幕上以 rzadmin 登录（初始密码为 rmmzit，必须更改）：将打开设置菜单。时区和网络之后也可以在控制台中更改。

2. 设备 ISO

  1. 从 rmmzit-appliance.iso 启动虚拟机或服务器。5 秒后安装会自动开始：它会清除第一块磁盘，安装 Debian、PostgreSQL 和 RMMZit，并需要访问互联网（10–20 分钟）。
  2. 重启后，屏幕会像虚拟机镜像一样显示控制台地址和设置令牌。

3. 安装脚本

在现有的 Linux 服务器上以 root 身份运行：

curl -fsSL https://github.com/Max-Zit/rmmzit/releases/latest/download/install.sh | sudo sh

该脚本会安装 PostgreSQL、下载最新版本、验证其签名、创建带随机密码的数据库并启动服务。选项（位于 sh -s -- 之后）：--version X；--db postgres://… 用于现有数据库；--no-auto-updates 使操作系统的自动安全更新保持关闭。再次运行会更新 RMMZit 并保留数据。

4. 手动安装软件包

sudo apt install ./rmmzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./rmmzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

然后将数据库地址写入 /etc/rmmzit/server.env（RMMZIT_DB=postgres://…），并使用 systemctl enable --now rmmzit-server 启动服务。

5. Docker

服务器也提供容器镜像 ghcr.io/max-zit/rmmzit，它由与其他方式相同的已签名服务器软件包构建，通过 Docker Compose 与 PostgreSQL 一起运行。将 docker-compose.yml 和 .env.example 下载到一个文件夹，把 .env.example 复制为 .env，设置数据库密码（字母和数字）和时区，然后：

docker compose up -d
docker compose exec rmmzit rmmzit-server -setup-token

打开 https://<主机>:8443 并输入设置令牌。端口 8444 是代理的连接端点；在代理连接的来源处开放它。.env 中的镜像标签决定运行的版本：latest 表示正式版本，testing 表示候选版本。

使用 docker compose pull && docker compose up -d 更新。在新版本更改数据库之前，服务器会将备份写入设置 → 控制台备份。如需回退，将上一个版本设为镜像标签并恢复该文件：docker compose stop rmmzit、docker compose run --rm rmmzit -restore /var/lib/rmmzit/backups/文件、docker compose up -d。在容器中，网络和时区由 Docker 主机管理，而不是控制台。

首次登录

  • 设置令牌位于 /var/lib/rmmzit/setup-token.txt 和服务器日志中（journalctl -u rmmzit-server）。只能使用一次。
  • 每个账户都需要身份验证器应用（TOTP），并获得 10 个恢复码。请妥善保管。
  • 默认情况下，控制台只接受来自私有网络的连接。如果把自己锁在外面，请在服务器上运行 rmmzit-server --reset-allowlist（设备：设置菜单第 5 项）。

文件位置

路径内容
/etc/rmmzit/server.env配置：数据库、端口、更新来源（仅 root 和服务可读）
/var/lib/rmmzit数据目录：证书、密钥、代理安装程序（downloads）、日志
/var/lib/rmmzit/logs/server.log服务器日志；也可在 journalctl -u rmmzit-server 中查看
/var/log/rmmzit-helperroot 助手的日志（更新、时区、网络）

请将数据库与 /var/lib/rmmzit 一起备份：其中的密钥用于解密已保存的密码，证书用于向代理证明服务器身份。
