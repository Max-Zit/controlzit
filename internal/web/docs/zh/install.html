安装服务器

从四种方式中选择一种。现成的虚拟机镜像最快；安装脚本适用于现有的 Linux 服务器。

方式最适合需要
1. 虚拟机镜像（OVA、qcow2、VHDX）几分钟内导入、启动并登录VMware、Proxmox / KVM 或 Hyper-V
2. 设备 ISO新虚拟机或物理服务器，无人值守安装期间可访问互联网
3. 安装脚本现有的 Debian、Ubuntu、AlmaLinux 或 Rocky Linux 服务器root 权限和互联网访问
4. 手动安装软件包自有 PostgreSQL、配置管理、离线服务器某个版本的 deb 或 rpm 软件包

所有文件都在版本页面上。请为服务器分配 2 个 vCPU、2–4 GB 内存和至少 16 GB 磁盘。

1. 虚拟机镜像

  1. 导入镜像：
    • VMware ESXi / Workstation、VirtualBox：部署 controlzit-appliance.ova（Create / Register VM → Deploy a virtual machine from an OVF or OVA file）。
    • Proxmox VE：创建一台没有磁盘的虚拟机（2 个 vCPU、2–4 GB 内存、VirtIO 网络），将 controlzit-appliance.qcow2 复制到节点并运行 qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm；将磁盘作为 SCSI 挂载并设为启动盘。
    • Hyper-V：解压 controlzit-appliance-vhdx.zip，创建一台以该 VHDX 为磁盘的第 1 代虚拟机。
  2. 启动虚拟机。磁盘会自动扩展到虚拟磁盘的大小。虚拟机屏幕会显示控制台地址和设置令牌。
  3. 打开 https://<地址>:8443。浏览器会对自签名证书提示一次警告（之后可在设置 → 证书中替换）。输入令牌并创建第一个管理员。

设备通过 DHCP 获取地址。如需设置固定地址、服务器名称或时区，请在虚拟机屏幕上以 czadmin 登录（初始密码为 controlzit，必须更改）：将打开设置菜单。时区和网络之后也可以在控制台中更改。

2. 设备 ISO

  1. 从 controlzit-appliance.iso 启动虚拟机或服务器。5 秒后安装会自动开始：它会清除第一块磁盘，安装 Debian、PostgreSQL 和 ControlZit，并需要访问互联网（10–20 分钟）。
  2. 重启后，屏幕会像虚拟机镜像一样显示控制台地址和设置令牌。

3. 安装脚本

在现有的 Linux 服务器上以 root 身份运行：

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

该脚本会安装 PostgreSQL、下载最新版本、验证其签名、创建带随机密码的数据库并启动服务。选项（位于 sh -s -- 之后）：--version X；--db postgres://… 用于现有数据库；--no-auto-updates 使操作系统的自动安全更新保持关闭。再次运行会更新 ControlZit 并保留数据。

4. 手动安装软件包

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

然后将数据库地址写入 /etc/controlzit/server.env（CONTROLZIT_DB=postgres://…），并使用 systemctl enable --now controlzit-server 启动服务。

首次登录

  • 设置令牌位于 /var/lib/controlzit/setup-token.txt 和服务器日志中（journalctl -u controlzit-server）。只能使用一次。
  • 每个账户都需要身份验证器应用（TOTP），并获得 10 个恢复码。请妥善保管。
  • 默认情况下，控制台只接受来自私有网络的连接。如果把自己锁在外面，请在服务器上运行 controlzit-server --reset-allowlist（设备：设置菜单第 5 项）。

文件位置

路径内容
/etc/controlzit/server.env配置：数据库、端口、更新来源（仅 root 和服务可读）
/var/lib/controlzit数据目录：证书、密钥、代理安装程序（downloads）、日志
/var/lib/controlzit/logs/server.log服务器日志；也可在 journalctl -u controlzit-server 中查看
/var/log/controlzit-helperroot 助手的日志（更新、时区、网络）

请将数据库与 /var/lib/controlzit 一起备份：其中的密钥用于解密已保存的密码，证书用于向代理证明服务器身份。
