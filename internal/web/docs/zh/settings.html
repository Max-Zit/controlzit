服务器设置与更新

管理员可以在设置中找到服务器的设置：网络和端口、证书、时区、服务器和代理的更新，以及用于技术支持的诊断。

网络与访问

在设置 → 网络与访问中：

  • 控制台——监听地址和端口（默认 :8443）以及允许的网络：每行一个 IP 地址或网络（CIDR）。来自其他地址的连接在 TLS 之前即被关闭；服务器本身（127.0.0.1）始终允许。保存时会拒绝会把您自己的地址锁在外面的列表。
  • 代理端点——监听地址和端口（默认 :8444，必须与控制台不同）、允许代理来源的网络（留空 = 全部），以及写入安装程序和注册码的代理公网地址。
  • 新端口在立即重启后生效（重启 RMMZit 服务；代理会自动重新连接）。

如果把自己锁在外面，请在服务器上运行 rmmzit-server --reset-allowlist（设备：设置菜单第 5 项）。

服务器网络（设备）

在 RMMZit 设备上，这里还可以设置服务器本身的网络：DHCP 或带网络大小的固定地址（例如 192.168.1.20/24）、网关、一到三个 DNS 服务器以及服务器名称。如果网关在新设置下没有响应，30 秒后会自动恢复之前的设置。在其他安装中，网络由操作系统管理。

时区

计划（更新、脚本、报告）以及控制台中的时间都使用服务器的时区。从列表中选择并点击设置；控制台会重启并在几秒后恢复。没有 root 助手（见下文）时，请在服务器上设置：timedatectl set-timezone Asia/Shanghai。

证书（HTTPS）

在设置 → 证书中选择浏览器打开控制台时看到的证书。代理使用自己的端口和证书，因此更改证书永远不会断开代理。

  • 控制台自己的证书（自签名）——立即可用；浏览器会发出警告。
  • Let's Encrypt——免费证书，在到期前 30 天自动续期。输入控制台的公共 DNS 名称和电子邮件地址，并选择验证方式：
    • 80 端口——该名称指向此服务器且 80 端口可从互联网访问；服务器在 80 端口应答并将浏览器重定向到 HTTPS；
    • Cloudflare DNS——适用于无法从互联网访问的服务器；需要具有该区域 Zone:DNS:Edit 权限的 Cloudflare API 令牌。
  • 上传证书：来自您的证书颁发机构或公司 CA 的证书（PEM，包含中间证书）和私钥。私钥只存储在此服务器上。

服务器更新

设置 → RMMZit 更新显示正在运行的版本和最新版本。安装会更新服务器：只安装使用 RMMZit 发布密钥签名的版本；安装前服务器会备份数据库和程序，如果新版本无法启动，会自动回退到旧版本。控制台会中断一两分钟。可选：在选定的小时自动安装新版本。

更新通道：正式版本（默认）或测试，测试通道会在候选版本成为正式版本之前将其提供给测试控制台。生产控制台请保持使用正式版本。

更新、时区和网络需要随 Linux 软件包和设备提供的 root 助手。没有它时（例如单独的程序），请使用 install.sh 或该版本的软件包进行更新。

代理更新

请参阅安装代理 → 代理更新。

诊断

设置 → 诊断显示 RMMZit 写入日志的位置、服务器日志的最新行（可按级别或文本筛选）、root 助手的日志以及版本。下载诊断信息（ZIP）会创建一个用于技术支持的文件，包含日志、版本和设置摘要、设备、警报和审计日志。所有显示内容和文件中都会去除密码、令牌、注册码和密钥；不包含脚本及其输出。

自定义字段

管理员在设置 → 自定义字段中为设备和客户添加自己的字段（文本、数字或日期），例如资产编号、保修截止日期或合同。技术人员在设备和客户页面上填写；API 在每台设备中返回这些字段，并通过 PUT /api/v1/devices/{id}/fields 设置。

控制台备份

设置 → 控制台备份 每天在选定的时间备份控制台，也可点击 立即备份 马上备份。备份包含数据库、已保存密码的密钥、代理信任的证书和密钥以及软件库。最新的备份（数量由您选择）保留在数据目录的 backups 文件夹中，可从页面下载。

设置密码短语后文件会被加密（AES-256-GCM）；请将密码短语另行保存，因为没有它就无法恢复备份。每个备份的副本可以发送到另一台服务器上的 SFTP 文件夹（密码或私钥）。首次测试连接时会显示需要信任的服务器主机密钥；副本只会发送到具有该密钥的服务器。备份或其复制失败时，告警邮件的收件人会收到邮件。

恢复需在服务器停止时进行：在设备上通过设置菜单（Restore a backup），使用 Linux 软件包时：

sudo systemctl stop rmmzit-server
sudo -u rmmzit sh -c 'set -a; . /etc/rmmzit/server.env; rmmzit-server -data-dir /var/lib/rmmzit -restore /path/rmmzit-backup-….czb'
sudo systemctl start rmmzit-server

加密备份的密码短语从 RMMZIT_BACKUP_PASSPHRASE 或 -restore-passphrase-file 指定的文件读取。数据库一步恢复（失败则不做任何更改）；较新版本的 RMMZit 会在启动时更新恢复的数据库。从备份恢复的新服务器会保留所有代理，因为它们信任同一证书。
