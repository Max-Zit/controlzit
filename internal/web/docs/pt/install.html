Instalar o servidor

Escolha uma de quatro formas. A imagem de VM pronta é a mais rápida; o script de instalação serve para um servidor Linux existente.

FormaIdeal paraRequer
1. Imagem de VM (OVA, qcow2, VHDX)importar, arrancar e entrar em poucos minutosVMware, Proxmox / KVM ou Hyper-V
2. ISO do applianceuma VM nova ou um servidor físico, sem intervençãoacesso à Internet durante a instalação

4. Pacotes manualmentePostgreSQL próprio, gestão de configuração, servidores offlineo pacote deb ou rpm de uma versão

Todos os ficheiros estão na página de versões. Dê ao servidor 2 vCPU, 2–4 GB de RAM e um disco de 16 GB ou mais.

1. Imagem de VM

  1. Importe a imagem:
    • VMware ESXi / Workstation, VirtualBox: implemente controlzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: crie uma VM sem disco (2 vCPU, 2–4 GB de RAM, rede VirtIO), copie controlzit-appliance.qcow2 para o nó e execute qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm; ligue o disco como SCSI e torne-o o disco de arranque.
    • Hyper-V: descompacte controlzit-appliance-vhdx.zip e crie uma VM de geração 1 com o VHDX como disco.
  2. Arranque a VM. O disco cresce sozinho até ao tamanho do disco virtual. O ecrã da VM mostra o endereço da consola e o token de configuração.
  3. Abra https://<endereço>:8443. O navegador avisa uma vez sobre o certificado autoassinado (substitua-o depois em Definições → Certificado). Introduza o token e crie o primeiro administrador.

O appliance obtém o endereço por DHCP. Para um endereço fixo, o nome do servidor ou o fuso horário, inicie sessão no ecrã da VM como czadmin (primeira palavra-passe controlzit, que tem de ser alterada): abre-se um menu de configuração. O fuso horário e a rede também podem ser alterados depois na consola.

2. ISO do appliance

  1. Arranque uma VM ou um servidor a partir de controlzit-appliance.iso. Após 5 segundos a instalação começa sozinha: apaga o primeiro disco, instala Debian, PostgreSQL e ControlZit e precisa de acesso à Internet (10–20 minutos).
  2. Após o reinício, o ecrã mostra o endereço da consola e o token de configuração, como na imagem de VM.

3. Script de instalação

Num servidor Linux existente, como root:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

O script instala o PostgreSQL, transfere a versão mais recente, verifica a sua assinatura, cria uma base de dados com uma palavra-passe aleatória e inicia o serviço. Opções (depois de sh -s --): --version X, --db postgres://… para uma base de dados existente, --no-auto-updates para deixar desligadas as atualizações de segurança automáticas do sistema operativo. Executá-lo de novo atualiza o ControlZit e mantém os dados.

4. Pacotes manualmente

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Depois escreva o endereço da base de dados em /etc/controlzit/server.env (CONTROLZIT_DB=postgres://…) e inicie o serviço com systemctl enable --now controlzit-server.

Primeiro início de sessão

  • O token de configuração está em /var/lib/controlzit/setup-token.txt e no registo do servidor (journalctl -u controlzit-server). Serve uma vez.
  • Cada conta precisa de uma aplicação de autenticação (TOTP) e recebe 10 códigos de recuperação. Guarde-os em segurança.
  • Por predefinição a consola só aceita ligações de redes privadas. Se ficar sem acesso, execute controlzit-server --reset-allowlist no servidor (appliance: menu de configuração, opção 5).

Onde está cada coisa

CaminhoO quê
/etc/controlzit/server.envconfiguração: base de dados, portas, origem das atualizações (legível apenas por root e pelo serviço)
/var/lib/controlzitdiretório de dados: certificados, chave secreta, instaladores dos agentes (downloads), registos
/var/lib/controlzit/logs/server.logregisto do servidor; também em journalctl -u controlzit-server
/var/log/controlzit-helperregisto do auxiliar root (atualizações, fuso horário, rede)

Faça cópia da base de dados juntamente com /var/lib/controlzit: a chave secreta aí guardada desencripta as palavras-passe guardadas e os certificados identificam o servidor perante os seus agentes.
