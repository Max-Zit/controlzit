Primeiros passos

O RMMZit é uma ferramenta de monitorização e gestão remota (RMM) alojada por si. A partir de uma consola web no seu próprio servidor, acompanha e gere os computadores Windows e Linux dos seus clientes: inventário, monitorização e alertas, ambiente de trabalho remoto, terminal, ficheiros, scripts, atualizações do Windows, software e relatórios.

Como funciona

  • O servidor corre numa máquina Linux (normalmente uma pequena VM) com PostgreSQL. Tem duas portas: a consola (interface web e API, TCP 8443) e o ponto de ligação dos agentes (TCP 8444).
  • Os agentes correm como serviço em cada computador gerido. Ligam-se de saída à porta dos agentes; os computadores não precisam de portas abertas. Um agente confia no servidor pela impressão digital do seu certificado, que fixa no registo.
  • Cada comando para um agente é assinado pelo servidor e verificado pelo agente, e cada ação é registada no registo de auditoria à prova de adulteração.

A consola controla cada computador gerido. Torne-a acessível apenas a partir das suas próprias redes (predefinição) e abra apenas a porta dos agentes onde estes precisam dela. Veja Segurança.

Primeiros passos

  1. Instale o servidor — importe a imagem de VM pronta, arranque a ISO do appliance ou execute o script de instalação num servidor Linux. Veja Instalar o servidor.
  2. Crie o primeiro administrador com o token de configuração mostrado pelo servidor e configure o início de sessão em dois passos com uma aplicação de autenticação.
  3. Verifique o endereço dos agentes em Definições → Rede e acesso: os agentes têm de chegar ao servidor pelo endereço público dos agentes ou pelo nome da consola.
  4. Adicione um cliente e um local em Clientes e crie um código de registo no local.
  5. Instale o agente nos computadores desse local com o código. Veja Instalar agentes.
  6. Configure os alertas e as atualizações automáticas do Windows na política Default do cliente em Políticas, e os e-mails de alerta em Configurações → Monitoramento e alertas.
  7. Adicione os seus técnicos em Utilizadores, ou ligue o Active Directory / LDAP ou o início de sessão único. Veja Utilizadores, funções e início de sessão.

Requisitos

  • Servidor: 2 vCPU, 2–4 GB de RAM, disco de 16 GB; Debian 12+, Ubuntu 22.04+, AlmaLinux ou Rocky Linux 9+ (ou o appliance pronto).
  • Agentes Windows: Windows 10 / 11, Windows Server 2016 e mais recentes, 64 bits.
  • Agentes Linux: distribuições com systemd, x86-64 ou ARM64 (Raspberry Pi e servidores ARM). Atualizações via apt ou dnf.
  • Navegador: Chrome, Edge, Firefox ou Safari atuais.
