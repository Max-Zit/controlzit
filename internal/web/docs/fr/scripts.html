Scripts et tâches planifiées

Exécutez PowerShell, cmd, bash ou sh sur un appareil, sur plusieurs appareils à la fois ou selon une planification. Les scripts s'exécutent en tant que SYSTEM (Windows) ou root (Linux), sans fenêtre.

Sur un appareil

Sur la page d'un appareil, ouvrez Scripts, choisissez le shell, écrivez le script (ou chargez-en un depuis la bibliothèque) et fixez un délai maximal (5–1500 secondes). La page affiche le code de sortie et la sortie (le premier Mo) quand le script se termine en quelques secondes ; un script plus long continue dans Activité, où il peut aussi être arrêté. Les exécutions précédentes restent dans la liste ; Modifier et relancer ouvre une exécution comme nouveau script.

Bibliothèque de scripts

Enregistrez les scripts que vous utilisez souvent dans Scripts → Bibliothèque de scripts, avec un nom et une description. De là, exécutez un script sur des appareils choisis, sur tous les appareils de certains clients ou sur tous les appareils.

Tâches

Exécuter un script de la bibliothèque sur plusieurs appareils crée une tâche. La page de la tâche montre chaque appareil avec son état (en attente, en cours, réussi, échoué, expiré) et sa sortie. Le code de sortie 0 compte comme un succès. Les appareils hors ligne exécutent le script à leur connexion, dans les 24 heures ; ensuite ils sont considérés comme expirés.

Planifications

Un script de la bibliothèque peut s'exécuter selon une planification : certains jours de la semaine à une heure donnée (heure du serveur), sur des appareils précis, sur tous les appareils de certains clients ou sur tous les appareils (y compris les nouveaux). Une planification peut être suspendue et reprise. Les appareils hors ligne à ce moment exécutent le script à leur connexion, dans les 24 heures.

Ce qui est journalisé

Le script et le début de sa sortie sont inscrits au journal d'audit avec votre nom. Les utilisateurs en lecture seule ne peuvent pas exécuter de scripts.

Les scripts ont tous les droits sur les ordinateurs. Gardez la bibliothèque en ordre, donnez aux techniciens uniquement les clients dont ils ont besoin et testez un script sur un appareil avant de l'exécuter sur plusieurs.
