Premiers pas

ControlZit est un outil de supervision et de gestion à distance (RMM) auto-hébergé. Depuis une console web sur votre propre serveur, vous surveillez et gérez les ordinateurs Windows et Linux de vos clients : inventaire, surveillance et alertes, bureau à distance, terminal, fichiers, scripts, mises à jour Windows, logiciels et rapports.

Fonctionnement

  • Le serveur tourne sur une machine Linux (souvent une petite VM) avec PostgreSQL. Il a deux ports : la console (interface web et API, TCP 8443) et le point d'accès des agents (TCP 8444).
  • Les agents tournent comme service sur chaque ordinateur géré. Ils se connectent en sortie au port des agents ; les ordinateurs n'ont besoin d'aucun port ouvert. Un agent fait confiance au serveur grâce à l'empreinte de son certificat, qu'il épingle à l'inscription.
  • Chaque commande vers un agent est signée par le serveur et vérifiée par l'agent, et chaque action est inscrite dans le journal d'audit infalsifiable.

La console contrôle chaque ordinateur géré. Ne la rendez accessible que depuis vos propres réseaux (par défaut) et n'ouvrez que le port des agents là où ils en ont besoin. Voir Sécurité.

Premières étapes

  1. Installer le serveur — importez l'image VM prête à l'emploi, démarrez l'ISO de l'appliance ou lancez le script d'installation sur un serveur Linux. Voir Installer le serveur.
  2. Créer le premier administrateur avec le jeton de configuration affiché par le serveur, puis configurer la connexion à deux facteurs avec une application d'authentification.
  3. Vérifier l'adresse des agents dans Paramètres → Réseau et accès : les agents doivent joindre le serveur par l'adresse publique des agents ou le nom d'hôte de la console.
  4. Ajouter un client et un site dans Clients, puis créer un code d'inscription sur le site.
  5. Installer l'agent sur les ordinateurs de ce site avec le code. Voir Installer les agents.
  6. Configurez les alertes et les mises à jour Windows automatiques dans la stratégie Default du client sous Stratégies, et les e-mails d'alerte dans Paramètres → Surveillance et alertes.
  7. Ajouter vos techniciens dans Utilisateurs, ou connecter Active Directory / LDAP ou l'authentification unique. Voir Utilisateurs, rôles et connexion.

Configuration requise

  • Serveur : 2 vCPU, 2–4 Go de RAM, disque de 16 Go ; Debian 12+, Ubuntu 22.04+, AlmaLinux ou Rocky Linux 9+ (ou l'appliance prête à l'emploi).
  • Agents Windows : Windows 10 / 11, Windows Server 2016 et plus récent, 64 bits.
  • Agents Linux : distributions avec systemd, x86-64 ou ARM64 (Raspberry Pi et serveurs ARM). Mises à jour via apt ou dnf.
  • Navigateur : Chrome, Edge, Firefox ou Safari récent.
