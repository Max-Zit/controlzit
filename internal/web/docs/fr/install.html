Installer le serveur

Choisissez l'une des quatre méthodes. L'image VM prête à l'emploi est la plus rapide ; le script d'installation convient à un serveur Linux existant.

MéthodeIdéale pourNécessite

Tous les fichiers sont sur la page des versions. Donnez au serveur 2 vCPU, 2–4 Go de RAM et un disque d'au moins 16 Go.

1. Image VM

  1. Importez l'image :
    • VMware ESXi / Workstation, VirtualBox : déployez controlzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE : créez une VM sans disque (2 vCPU, 2–4 Go de RAM, réseau VirtIO), copiez controlzit-appliance.qcow2 sur le nœud et lancez qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm ; attachez le disque en SCSI et faites-en le disque de démarrage.
    • Hyper-V : décompressez controlzit-appliance-vhdx.zip et créez une VM de génération 1 avec le VHDX comme disque.
  2. Démarrez la VM. Le disque s'agrandit tout seul à la taille du disque virtuel. L'écran de la VM affiche l'adresse de la console et le jeton de configuration.
  3. Ouvrez https://<adresse>:8443. Le navigateur avertit une fois au sujet du certificat auto-signé (remplacez-le plus tard dans Paramètres → Certificat). Saisissez le jeton et créez le premier administrateur.

L'appliance obtient son adresse par DHCP. Pour une adresse fixe, le nom du serveur ou le fuseau horaire, connectez-vous sur l'écran de la VM en tant que czadmin (premier mot de passe controlzit, à changer) : un menu de configuration s'ouvre. Le fuseau horaire et le réseau peuvent aussi être modifiés plus tard dans la console.

2. ISO de l'appliance

  1. Démarrez une VM ou un serveur sur controlzit-appliance.iso. Après 5 secondes l'installation démarre seule : elle efface le premier disque, installe Debian, PostgreSQL et ControlZit et nécessite un accès Internet (10–20 minutes).
  2. Après le redémarrage, l'écran affiche l'adresse de la console et le jeton de configuration, comme avec l'image VM.

3. Script d'installation

Sur un serveur Linux existant, en root :

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

Le script installe PostgreSQL, télécharge la dernière version, vérifie sa signature, crée une base de données avec un mot de passe aléatoire et démarre le service. Options (après sh -s --) : --version X, --db postgres://… pour une base existante, --no-auto-updates pour laisser désactivées les mises à jour de sécurité automatiques du système. Le relancer met ControlZit à jour en conservant les données.

4. Paquets à la main

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Indiquez ensuite l'adresse de la base dans /etc/controlzit/server.env (CONTROLZIT_DB=postgres://…) et démarrez le service avec systemctl enable --now controlzit-server.

Première connexion

  • Le jeton de configuration se trouve dans /var/lib/controlzit/setup-token.txt et dans le journal du serveur (journalctl -u controlzit-server). Il ne sert qu'une fois.
  • Chaque compte nécessite une application d'authentification (TOTP) et reçoit 10 codes de récupération. Conservez-les en lieu sûr.
  • Par défaut la console n'accepte que les connexions des réseaux privés. Si vous vous bloquez, lancez controlzit-server --reset-allowlist sur le serveur (appliance : menu de configuration, élément 5).

Où se trouvent les éléments

CheminContenu
/etc/controlzit/server.envconfiguration : base de données, ports, source des mises à jour (lisible seulement par root et le service)
/var/lib/controlzitrépertoire de données : certificats, clé secrète, installateurs des agents (downloads), journaux
/var/lib/controlzit/logs/server.logjournal du serveur ; aussi dans journalctl -u controlzit-server
/var/log/controlzit-helperjournal de l'assistant root (mises à jour, fuseau horaire, réseau)

Sauvegardez la base de données avec /var/lib/controlzit : la clé secrète qui s'y trouve déchiffre les mots de passe enregistrés et les certificats identifient le serveur auprès de ses agents.
