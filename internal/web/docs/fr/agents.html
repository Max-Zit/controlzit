Installer les agents

L'agent est un petit service sur chaque ordinateur géré. Il se connecte en sortie au port des agents du serveur, envoie l'inventaire et les mesures et exécute les commandes signées de la console.

Avant de commencer

  • Les agents doivent joindre le serveur sur le port des agents (TCP 8444 par défaut). Pour les ordinateurs hors de votre réseau, ouvrez ce port sur le pare-feu et définissez l'adresse publique des agents dans Paramètres → Réseau et accès (par exemple https://rmm.example.com:8444). Le port de la console reste fermé.
  • Si vous avez ouvert la console sur le serveur lui-même (localhost) sans adresse publique des agents, la page du site vous avertit : les agents essaieraient de se connecter à l'adresse de bouclage du serveur.

Codes d'inscription

Les agents rejoignent un site d'un client avec un code d'inscription. Ouvrez le site dans Clients et cliquez sur Créer un code d'inscription. Vous choisissez sa durée de validité (1–365 jours) et le nombre d'ordinateurs qui peuvent l'utiliser. Le code (CZ1-…) contient l'adresse du serveur et l'empreinte de son certificat, l'installateur n'a donc besoin de rien d'autre. Il n'est affiché qu'une fois ; révoquez-le quand il n'est plus utile.

Windows

Téléchargez le MSI sur la page du site (Télécharger l'agent (MSI, 64 bits)) et double-cliquez dessus puis collez le code, ou installez-le en silence, par exemple par stratégie de groupe, Intune ou script :

msiexec /i controlzit-agent-x64.msi /qn ENROLLCODE="CZ1-…"

L'agent tourne comme service Windows ControlZit Agent. Une petite icône près de l'horloge indique s'il est connecté (vert) et ouvre une fenêtre avec le serveur et qui gère l'ordinateur.

L'icône, sa fenêtre et la question de redémarrage utilisent la langue d'affichage du Windows de l'utilisateur (l'une des 14 langues de la console, sinon l'anglais).

Sans le MSI (PowerShell en administrateur) :

.\controlzit-agent.exe enroll --code "CZ1-…"
.\controlzit-agent.exe install

Linux

Téléchargez l'agent Linux sur la page du site (x86-64, ou ARM64 pour Raspberry Pi et serveurs ARM), copiez-le sur la machine et exécutez-le en root :

chmod +x controlzit-agent-linux-amd64
sudo ./controlzit-agent-linux-amd64 install --code "CZ1-…"

Il se copie dans /usr/local/bin/controlzit-agent, s'inscrit et démarre le service systemd controlzit-agent.

Mises à jour des agents

Le serveur fournit les installateurs d'agent de sa propre version. Dans Paramètres → Mises à jour des agents vous voyez les agents obsolètes, les mettez tous à jour d'un coup ou laissez les agents obsolètes se mettre à jour à leur connexion. Un agent seul se met à jour sur la page de son appareil. L'agent télécharge l'installateur par sa propre connexion chiffrée et ne l'installe que s'il correspond au SHA-256 de la commande de mise à jour signée. Vous pouvez aussi y téléverser un autre installateur (un MSI ou un agent Linux).

Windows Update sur les ordinateurs gérés

L'agent désactive par stratégie l'installation automatique de Windows Update, afin que les mises à jour ne viennent que de ControlZit, à la main ou selon votre planification (voir Mises à jour Windows). Les paramètres précédents sont conservés et reviennent quand l'agent est retiré.

Retirer un agent

Supprimez l'appareil sur sa page (Retirer l'appareil). S'il est en ligne, l'agent se désinstalle en quelques secondes et Windows Update récupère ses propres paramètres. Un ordinateur hors ligne ne peut plus se connecter ; désinstallez-y l'agent à la main (Windows : Applications → ControlZit Agent → Désinstaller ; Linux : sudo controlzit-agent uninstall).
