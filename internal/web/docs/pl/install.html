Instalacja serwera

Wybierz jeden z czterech sposobów. Gotowy obraz VM jest najszybszy; skrypt instalacyjny pasuje do istniejącego serwera z Linuksem.

SposóbNajlepszy doWymaga
1. Obraz VM (OVA, qcow2, VHDX)import, uruchomienie, logowanie w kilka minutVMware, Proxmox / KVM lub Hyper-V
2. ISO urządzenianowa VM lub serwer fizyczny, bez obsługidostęp do Internetu podczas instalacji
3. Skrypt instalacyjnyistniejący serwer Debian, Ubuntu, AlmaLinux lub Rocky Linuxroot i dostęp do Internetu
4. Pakiety ręczniewłasny PostgreSQL, zarządzanie konfiguracją, serwery offlinepakiet deb lub rpm wydania

Wszystkie pliki są na stronie wydań. Daj serwerowi 2 vCPU, 2–4 GB RAM i dysk co najmniej 16 GB.

1. Obraz VM

  1. Zaimportuj obraz:
    • VMware ESXi / Workstation, VirtualBox: wdróż controlzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: utwórz VM bez dysku (2 vCPU, 2–4 GB RAM, sieć VirtIO), skopiuj controlzit-appliance.qcow2 na węzeł i uruchom qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm; podłącz dysk jako SCSI i ustaw go jako dysk rozruchowy.
    • Hyper-V: rozpakuj controlzit-appliance-vhdx.zip i utwórz VM generacji 1 z VHDX jako dyskiem.
  2. Uruchom VM. Dysk sam powiększa się do rozmiaru dysku wirtualnego. Ekran VM pokazuje adres konsoli i token konfiguracji.
  3. Otwórz https://<adres>:8443. Przeglądarka raz ostrzeże o certyfikacie z podpisem własnym (zastąp go później w Ustawienia → Certyfikat). Wpisz token i utwórz pierwszego administratora.

Urządzenie pobiera adres przez DHCP. Aby ustawić stały adres, nazwę serwera lub strefę czasową, zaloguj się na ekranie VM jako czadmin (pierwsze hasło controlzit, które trzeba zmienić): otworzy się menu konfiguracji. Strefę czasową i sieć można też później zmienić w konsoli.

2. ISO urządzenia

  1. Uruchom VM lub serwer z controlzit-appliance.iso. Po 5 sekundach instalacja zaczyna się sama: kasuje pierwszy dysk, instaluje Debiana, PostgreSQL i ControlZit i wymaga dostępu do Internetu (10–20 minut).
  2. Po ponownym uruchomieniu ekran pokazuje adres konsoli i token konfiguracji, tak jak w obrazie VM.

3. Skrypt instalacyjny

Na istniejącym serwerze z Linuksem, jako root:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

Skrypt instaluje PostgreSQL, pobiera najnowsze wydanie, sprawdza jego podpis, tworzy bazę danych z losowym hasłem i uruchamia usługę. Opcje (po sh -s --): --version X, --db postgres://… dla istniejącej bazy, --no-auto-updates, aby automatyczne aktualizacje zabezpieczeń systemu pozostały wyłączone. Ponowne uruchomienie aktualizuje ControlZit i zachowuje dane.

4. Pakiety ręcznie

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Następnie wpisz adres bazy danych do /etc/controlzit/server.env (CONTROLZIT_DB=postgres://…) i uruchom usługę poleceniem systemctl enable --now controlzit-server.

Pierwsze logowanie

  • Token konfiguracji jest w /var/lib/controlzit/setup-token.txt i w dzienniku serwera (journalctl -u controlzit-server). Działa jeden raz.
  • Każde konto potrzebuje aplikacji uwierzytelniającej (TOTP) i dostaje 10 kodów odzyskiwania. Przechowuj je bezpiecznie.
  • Domyślnie konsola przyjmuje połączenia tylko z sieci prywatnych. Jeśli się zablokujesz, uruchom controlzit-server --reset-allowlist na serwerze (urządzenie: menu konfiguracji, pozycja 5).

Gdzie co jest

ŚcieżkaCo
/etc/controlzit/server.envkonfiguracja: baza danych, porty, źródło aktualizacji (czytelna tylko dla root i usługi)
/var/lib/controlzitkatalog danych: certyfikaty, klucz tajny, instalatory agentów (downloads), dzienniki
/var/lib/controlzit/logs/server.logdziennik serwera; także w journalctl -u controlzit-server
/var/log/controlzit-helperdziennik pomocnika root (aktualizacje, strefa czasowa, sieć)

Twórz kopię bazy danych razem z /var/lib/controlzit: klucz tajny odszyfrowuje zapisane hasła, a certyfikaty identyfikują serwer wobec jego agentów.
