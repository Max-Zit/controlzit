Instalacja agentów

Agent to mała usługa na każdym zarządzanym komputerze. Łączy się wychodząco z portem agentów serwera, przesyła inwentaryzację i pomiary oraz wykonuje podpisane polecenia konsoli.

Zanim zaczniesz

  • Agenci muszą docierać do serwera na porcie agentów (domyślnie TCP 8444). Dla komputerów spoza Twojej sieci otwórz ten port w zaporze i ustaw publiczny adres agentów w Ustawienia → Sieć i dostęp (na przykład https://rmm.example.com:8444). Port konsoli pozostaje zamknięty.
  • Jeśli otworzono konsolę na samym serwerze (localhost), a publiczny adres agentów nie jest ustawiony, strona lokalizacji ostrzega: agenci próbowaliby łączyć się z adresem pętli zwrotnej serwera.

Kody rejestracji

Agenci dołączają do lokalizacji klienta za pomocą kodu rejestracji. Otwórz lokalizację w Klienci i kliknij Utwórz kod rejestracji. Wybierasz, jak długo jest ważny (1–365 dni) i ile komputerów może go użyć. Kod (CZ1-…) zawiera adres serwera i odcisk jego certyfikatu, więc instalator nie potrzebuje niczego więcej. Jest pokazywany tylko raz; unieważnij go, gdy przestanie być potrzebny.

Windows

Pobierz MSI na stronie lokalizacji (Pobierz agenta (MSI, 64-bit)) i kliknij go dwukrotnie i wklej kod albo zainstaluj po cichu, na przykład przez zasady grupy, Intune lub skrypt:

msiexec /i controlzit-agent-x64.msi /qn ENROLLCODE="CZ1-…"

Agent działa jako usługa Windows ControlZit Agent. Mała ikona obok zegara pokazuje, czy jest połączony (zielona), i otwiera okno z serwerem i informacją, kto zarządza komputerem.

Bez MSI (PowerShell jako administrator):

.\controlzit-agent.exe enroll --code "CZ1-…"
.\controlzit-agent.exe install

Linux

Pobierz agenta dla Linuksa na stronie lokalizacji (x86-64 lub ARM64 dla Raspberry Pi i serwerów ARM), skopiuj go na maszynę i uruchom jako root:

chmod +x controlzit-agent-linux-amd64
sudo ./controlzit-agent-linux-amd64 install --code "CZ1-…"

Kopiuje się do /usr/local/bin/controlzit-agent, rejestruje i uruchamia usługę systemd controlzit-agent.

Aktualizacje agentów

Serwer zawiera instalatory agenta we własnej wersji. W Ustawienia → Aktualizacje agentów widzisz nieaktualnych agentów, aktualizujesz wszystkich naraz lub pozwalasz, by nieaktualni agenci aktualizowali się sami przy połączeniu. Pojedynczego agenta aktualizujesz na stronie urządzenia. Agent pobiera instalator przez własne szyfrowane połączenie i instaluje go tylko wtedy, gdy zgadza się z SHA-256 w podpisanym poleceniu aktualizacji. Możesz tam też przesłać inny instalator (MSI lub agenta dla Linuksa).

Windows Update na zarządzanych komputerach

Agent wyłącza zasadą automatyczną instalację Windows Update, aby aktualizacje przychodziły tylko z ControlZit, ręcznie lub według Twojego harmonogramu (zobacz Aktualizacje Windows). Poprzednie ustawienia są zapisywane i wracają po usunięciu agenta.

Usuwanie agenta

Usuń urządzenie na jego stronie (Usuń urządzenie). Jeśli jest online, agent odinstaluje się w kilka sekund, a Windows Update odzyska własne ustawienia. Komputer offline nie może się już połączyć; odinstaluj tam agenta ręcznie (Windows: Aplikacje → ControlZit Agent → Odinstaluj; Linux: sudo controlzit-agent uninstall).
