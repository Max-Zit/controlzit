Aktualizacje Windows i oprogramowanie

RMMZit pokazuje, których aktualizacji brakuje na każdym komputerze, i instaluje je ręcznie lub według Twojego harmonogramu. Programy instaluje się i aktualizuje przez winget.

Przegląd

Aktualizacje pokazuje urządzenia z brakującymi aktualizacjami (zabezpieczeń liczone osobno), urządzenia czekające na restart, ostatnią instalację i ostatnie wyszukiwanie. Agenci szukają brakujących aktualizacji kilka minut po starcie, a potem dwa razy dziennie; Szukaj teraz natychmiast rozpoczyna wyszukiwanie.

Na urządzeniu

Karta Aktualizacje urządzenia pokazuje brakujące aktualizacje z kategorią i ważnością oraz niedawno zainstalowane. Zaznacz aktualizacje i kliknij Zainstaluj wybrane; instalacja działa jako zadanie w Aktywności, która pokaże wynik po zakończeniu. Jeśli potrzebny jest restart, urządzenie to pokaże, a restart możesz uruchomić z jego strony.

Definicje Defendera (Security Intelligence Update) wychodzą kilka razy dziennie, każda z nowym identyfikatorem aktualizacji. Gdy instalujesz jedną z nich, agent najpierw wyszukuje ponownie i instaluje wersję definicji, którą Windows Update oferuje w tym momencie.

Automatyczna instalacja

Część Windows Update zasady (na przykład zasady klienta Default) określa, co serwer instaluje sam:

  • Wyłączone — aktualizacje są instalowane tylko z konsoli.
  • Aktualizacje zabezpieczeń i krytyczne, definicje Defendera.
  • Wszystkie aktualizacje oprócz aktualizacji funkcji — nowe wersje Windows nigdy nie są instalowane automatycznie.

Wybierz dni i godzinę (czas serwera) albo W oknie serwisowym. Urządzenia, które są wtedy online, instalują raz tego dnia; urządzenia offline czekają na następny zaplanowany dzień.

Pierścień aktualizacji: przy opóźnieniu na przykład 7 dni urządzenie instaluje aktualizację dopiero 7 dni po tym, jak serwer zobaczył ją po raz pierwszy. Daj komputerom testowym zasadę z 0 dniami, a pozostałym z 7 dniami, a problemy pojawią się najpierw na komputerach testowych. Definicje Defendera nigdy nie czekają.

Uruchom ponownie, gdy aktualizacja tego wymaga: nigdy automatycznie; automatycznie 5 minut po instalacji, z powiadomieniem; albo Zapytaj użytkownika: ikona RMMZit prosi zalogowanego użytkownika o ponowne uruchomienie, ponownie co 4 godziny, a po terminie (dniach, o które użytkownik może odłożyć) serwer uruchamia komputer ponownie z 10-minutowym ostrzeżeniem, w oknie serwisowym, jeśli urządzenie je ma. Karta Zasada urządzenia pokazuje oczekujące ponowne uruchomienie i jego termin.

Aby aktualizacje nie przychodziły w przypadkowych momentach, agent wyłącza zasadą automatyczną instalację Windows Update. Po usunięciu agenta wracają poprzednie ustawienia.

Linux

W Linuksie agent odczytuje dostępne aktualizacje pakietów przez apt (Debian, Ubuntu; aktualizacje zabezpieczeń z repozytoriów -security) lub dnf (rodzina RHEL; aktualizacje zabezpieczeń z informacji o aktualizacjach) i instaluje wybrane pakiety. Automatyczna instalacja dotyczy też urządzeń z Linuksem; tam „aktualizacje zabezpieczeń” to pakiety ze źródeł bezpieczeństwa.

Programy (winget)

Karta Programy urządzenia z Windows ma trzy części. Dostępne aktualizacje pokazuje programy, które winget może zaktualizować; Aktualizuj wszystko je aktualizuje, można też aktualizować pojedyncze programy. Zainstalowane pokazuje każdy program z listy zainstalowanych programów Windows, dla komputera i dla zalogowanych użytkowników, z filtrem według nazwy lub wydawcy. Odinstaluj usuwa program po cichu: pakiety Windows Installer (MSI) przez msiexec /x, deinstalatory Inno Setup i NSIS z ich cichym przełącznikiem albo własnym cichym poleceniem programu. Wynik jest zgłaszany dopiero, gdy program naprawdę zniknie; programy bez cichego deinstalatora są oznaczone i trzeba je usunąć na komputerze lub skryptem. Zainstaluj program przeszukuje repozytorium społeczności winget (na przykład 7-Zip lub Chrome) i instaluje po cichu dla wszystkich użytkowników. Instalowanie i aktualizowanie wymaga winget (App Installer), który jest w aktualnych Windows 10 i 11.

Chocolatey można dodać jako drugie publiczne źródło w Oprogramowanie → Źródła publiczne. Zainstaluj program oferuje wtedy wybór źródła (winget lub Chocolatey), a Dostępne aktualizacje pokazuje też programy zainstalowane przez Chocolatey, które mają nowszą wersję. Klient Chocolatey jest instalowany na urządzeniu przez winget przy pierwszej potrzebie. Pakiety Chocolatey są utrzymywane przez jego społeczność i zwykle pobierają program ze strony producenta.

Biblioteka oprogramowania

W Oprogramowanie administratorzy wysyłają własne instalatory: pakiet Instalatora Windows (.msi) lub program instalacyjny (.exe), do 2 GB, z nazwą, wersją, argumentami cichej instalacji i kodami wyjścia oznaczającymi sukces (domyślnie 0, 1641 i 3010; dwa ostatnie oznaczają, że instalację kończy ponowne uruchomienie). Dla MSI agent uruchamia msiexec /i z dziennikiem, a domyślne argumenty to /qn /norestart; EXE potrzebuje własnego przełącznika cichej instalacji, na przykład /S (NSIS), /VERYSILENT /NORESTART (Inno Setup) lub /quiet.

Zainstaluj na urządzeniach wybiera klientów, lokalizacje lub pojedyncze urządzenia z Windows i uruchamia zadanie, jak skrypt z biblioteki: urządzenia online instalują od razu, a offline po połączeniu w ciągu 24 godzin. Agent pobiera instalator z portu agentów serwera i sprawdza go z SHA-256 z podpisanego polecenia, zanim uruchomi go jako SYSTEM. Strona zadania pokazuje wynik każdego urządzenia; dziennik pakietu Instalatora Windows jest zapisywany razem z wynikiem. Technicy instalują pakiety na urządzeniach swoich klientów, także przez Zainstaluj program na karcie Programy urządzenia.

Luki

W Luki administrator włącza skanowanie zainstalowanych programów. Co 6 godzin serwer porównuje je z publicznymi bazami luk: NVD dla popularnych programów Windows (przeglądarki, czytniki PDF, archiwizatory, narzędzia zdalnego dostępu i programistyczne oraz inne) i OSV dla pakietów Debiana i Ubuntu. Wysyłane są tylko nazwy i wersje programów, nigdy dane urządzeń. Opcjonalny darmowy klucz API NVD przyspiesza pierwsze skanowanie.

Strona pokazuje programy i wersje, których dotyczą luki, z liczbą luk według wagi i urządzeniami; karta Luki urządzenia wymienia każdą z odnośnikiem do opisu. Aktualizacja programu je usuwa. Z opcją Alert, gdy program ma krytyczną lukę w regułach alertów zasady luki krytyczne (CVSS 9 lub więcej) otwierają alert. Sam Windows obejmują aktualizacje Windows, nie to skanowanie.

Luki pakietów Debiana i Ubuntu, dla których w wydaniu urządzenia nie ma jeszcze poprawki, są ukryte, dopóki ich nie pokażesz; każdy wynik pokazuje wersję, która ją usuwa.
