Pierwsze kroki

ControlZit to samodzielnie hostowane narzędzie do zdalnego monitorowania i zarządzania (RMM). Z jednej konsoli internetowej na własnym serwerze monitorujesz komputery z Windows i Linuksem swoich klientów i nimi zarządzasz: inwentaryzacja, monitorowanie i alerty, pulpit zdalny, terminal, pliki, skrypty, aktualizacje Windows, oprogramowanie i raporty.

Jak to działa

  • Serwer działa na maszynie z Linuksem (zwykle małej VM) z PostgreSQL. Ma dwa porty: konsolę (interfejs WWW i API, TCP 8443) i punkt końcowy agentów (TCP 8444).
  • Agenci działają jako usługa na każdym zarządzanym komputerze. Łączą się wychodząco z portem agentów; komputery nie potrzebują otwartych portów. Agent ufa serwerowi na podstawie odcisku jego certyfikatu, który przypina przy rejestracji.
  • Każde polecenie dla agenta jest podpisywane przez serwer i sprawdzane przez agenta, a każda akcja trafia do odpornego na manipulacje dziennika audytu.

Konsola steruje każdym zarządzanym komputerem. Udostępniaj ją tylko z własnych sieci (domyślnie) i otwieraj tylko port agentów tam, gdzie jest potrzebny. Zobacz Bezpieczeństwo.

Pierwsze kroki

  1. Zainstaluj serwer — zaimportuj gotowy obraz VM, uruchom ISO urządzenia lub wykonaj skrypt instalacyjny na serwerze z Linuksem. Zobacz Instalacja serwera.
  2. Utwórz pierwszego administratora przy użyciu tokenu konfiguracji wyświetlanego przez serwer i skonfiguruj logowanie dwuskładnikowe z aplikacją uwierzytelniającą.
  3. Sprawdź adres agentów w Ustawienia → Sieć i dostęp: agenci muszą docierać do serwera przez publiczny adres agentów lub nazwę hosta konsoli.
  4. Dodaj klienta i lokalizację w Klienci, a następnie utwórz w lokalizacji kod rejestracji.
  5. Zainstaluj agenta na komputerach tej lokalizacji przy użyciu kodu. Zobacz Instalacja agentów.
  6. Skonfiguruj alerty w Ustawienia → Monitorowanie i alerty oraz, jeśli chcesz, automatyczną instalację aktualizacji Windows.
  7. Dodaj techników w Użytkownicy lub podłącz Active Directory / LDAP albo logowanie jednokrotne. Zobacz Użytkownicy, role i logowanie.

Wymagania

  • Serwer: 2 vCPU, 2–4 GB RAM, dysk 16 GB; Debian 12+, Ubuntu 22.04+, AlmaLinux lub Rocky Linux 9+ (albo gotowe urządzenie).
  • Agenci Windows: Windows 10 / 11, Windows Server 2016 i nowsze, 64-bitowe.
  • Agenci Linux: dystrybucje z systemd, x86-64 lub ARM64 (Raspberry Pi i serwery ARM). Aktualizacje przez apt lub dnf.
  • Przeglądarka: aktualny Chrome, Edge, Firefox lub Safari.
