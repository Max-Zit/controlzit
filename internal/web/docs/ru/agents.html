Установка агентов

Агент — небольшая служба на каждом управляемом компьютере. Он подключается исходящим соединением к порту агентов сервера, передаёт инвентаризацию и метрики и выполняет подписанные команды консоли.

Перед началом

  • Агенты должны достигать сервера на порту агентов (по умолчанию TCP 8444). Для компьютеров вне вашей сети откройте этот порт в брандмауэре и задайте публичный адрес для агентов в разделе Настройки → Сеть и доступ (например, https://rmm.example.com:8444). Порт консоли остаётся закрытым.
  • Если вы открыли консоль на самом сервере (localhost) и публичный адрес для агентов не задан, страница площадки предупредит: агенты пытались бы подключиться к адресу обратной петли сервера.

Коды регистрации

Агенты присоединяются к площадке клиента по коду регистрации. Откройте площадку в разделе Клиенты и нажмите Создать код регистрации. Вы выбираете срок действия (1–365 дней) и сколько компьютеров могут его использовать. Код (RZ1-…) содержит адрес сервера и отпечаток его сертификата, поэтому установщику больше ничего не нужно. Он показывается только один раз; отзовите его, когда он больше не нужен.

Windows

Скачайте MSI на странице площадки (Скачать агент (MSI, 64-бит)) и либо дважды щёлкните его и вставьте код, либо установите в тихом режиме, например через групповую политику, Intune или скрипт:

msiexec /i rmmzit-agent-x64.msi /qn ENROLLCODE="RZ1-…"

Агент работает как служба Windows RMMZit Agent. Небольшой значок рядом с часами показывает, подключён ли он (зелёный), и открывает окно с сервером и тем, кто управляет компьютером.

Значок, его окно и вопрос о перезагрузке используют язык интерфейса Windows пользователя (один из 14 языков консоли, иначе английский).

Без MSI (PowerShell от имени администратора):

.\rmmzit-agent.exe enroll --code "RZ1-…"
.\rmmzit-agent.exe install

Linux

Скачайте агент для Linux на странице площадки (x86-64 или ARM64 для Raspberry Pi и ARM-серверов), скопируйте его на машину и запустите от root:

chmod +x rmmzit-agent-linux-amd64
sudo ./rmmzit-agent-linux-amd64 install --code "RZ1-…"

Он копирует себя в /usr/local/bin/rmmzit-agent, регистрируется и запускает службу systemd rmmzit-agent.

Обновления агентов

Сервер содержит установщики агента своей версии. В разделе Настройки → Обновления агентов вы видите устаревшие агенты, обновляете их все сразу или разрешаете устаревшим агентам обновляться самим при подключении. Отдельный агент обновляется на странице устройства. Агент скачивает установщик по своему зашифрованному соединению и устанавливает его, только если он совпадает с SHA-256 в подписанной команде обновления. Там же можно загрузить другой установщик (MSI или агент для Linux).

Windows Update на управляемых компьютерах

Агент политикой отключает автоматическую установку Windows Update, чтобы обновления приходили только из RMMZit — вручную или по вашему расписанию (см. Обновления Windows). Прежние настройки сохраняются и возвращаются при удалении агента.

Удаление агента

Удалите устройство на его странице (Удалить устройство). Если оно в сети, агент удалит себя за несколько секунд, а Windows Update вернёт свои настройки. Компьютер не в сети больше не сможет подключиться; удалите агент на нём вручную (Windows: Приложения → RMMZit Agent → Удалить; Linux: sudo rmmzit-agent uninstall).

Много компьютеров: групповая политика и Intune

Создайте код регистрации с достаточным числом использований для всех компьютеров; страница площадки тогда покажет, заполненные этим кодом:

  • Групповая политика: сценарий запуска PowerShell. Поместите MSI в общую папку, доступную для чтения учётным записям компьютеров (Domain Computers), введите путь, скопируйте сценарий и добавьте его в Конфигурация компьютера → Политики → Конфигурация Windows → Сценарии → Автозагрузка → Сценарии PowerShell. Компьютеры с агентом (служба RMMZitAgent) пропускают его; журнал установки — %windir%\Temp\rmmzit-agent-install.log.
  • Microsoft Intune: добавьте агента как приложение Windows (Win32): упакуйте MSI утилитой Microsoft IntuneWinAppUtil и используйте команды установки и удаления, режим установки Система и правило обнаружения (файл C:\Program Files\RMMZit Agent\rmmzit-agent.exe) со страницы площадки. Не добавляйте его как бизнес-приложение MSI: агент обновляется сам, и Intune снова установил бы старую версию.
