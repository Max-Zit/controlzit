Обновления Windows и программы

ControlZit показывает, каких обновлений не хватает на каждом компьютере, и устанавливает их вручную или по вашему расписанию. Программы устанавливаются и обновляются через winget.

Обзор

Обновления показывает устройства с недостающими обновлениями (обновления безопасности считаются отдельно), устройства, ожидающие перезагрузки, последнюю установку и последний поиск. Агенты ищут недостающие обновления через несколько минут после запуска, а затем дважды в день; Искать сейчас сразу запускает поиск.

На устройстве

Вкладка Обновления устройства показывает недостающие обновления с категорией и важностью, а также недавно установленные. Отметьте обновления и нажмите Установить выбранные; страница покажет результат по завершении. Если нужна перезагрузка, устройство это покажет, и её можно запустить со страницы устройства.

Автоматическая установка

В разделе Настройки → Обновления Windows выберите, что сервер устанавливает сам:

  • Выключено — обновления устанавливаются только из консоли.
  • Обновления безопасности и критические, определения Defender.
  • Все обновления, кроме обновлений функций — новые версии Windows никогда не устанавливаются автоматически.

Выберите дни и час (время сервера). Устройства в сети в этот час устанавливают обновления один раз в этот день; устройства не в сети ждут следующего запланированного дня. При желании компьютер сам перезагружается, когда этого требует обновление, через 5 минут после уведомления вошедшему пользователю.

Чтобы обновления не приходили в случайное время, агент политикой отключает автоматическую установку Windows Update. После удаления агента возвращаются прежние настройки.

Linux

В Linux агент читает доступные обновления пакетов через apt (Debian, Ubuntu; обновления безопасности из источников -security) или dnf (семейство RHEL; обновления безопасности по сведениям об обновлениях) и устанавливает выбранные пакеты. Автоматическая установка действует и для устройств с Linux; там «обновления безопасности» — это пакеты из источников безопасности.

Программы (winget)

Вкладка Программы устройства с Windows показывает установленные программы, известные winget, и доступные обновления. Обновить все обновляет их; отдельные программы можно обновить или удалить. Установить программу ищет в общественном репозитории winget (например, 7-Zip или Chrome) и устанавливает программу в тихом режиме для всех пользователей. На устройстве нужен winget (Установщик приложений), который входит в актуальные Windows 10 и 11.
