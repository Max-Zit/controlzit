Обновления Windows и программы

RMMZit показывает, каких обновлений не хватает на каждом компьютере, и устанавливает их вручную или по вашему расписанию. Программы устанавливаются и обновляются через winget.

Обзор

Обновления показывает устройства с недостающими обновлениями (обновления безопасности считаются отдельно), устройства, ожидающие перезагрузки, последнюю установку и последний поиск. Агенты ищут недостающие обновления через несколько минут после запуска, а затем дважды в день; Искать сейчас сразу запускает поиск.

На устройстве

Вкладка Обновления устройства показывает недостающие обновления с категорией и важностью, а также недавно установленные. Отметьте обновления и нажмите Установить выбранные; установка выполняется как задача в разделе Действия, где по завершении виден результат. Если нужна перезагрузка, устройство это покажет, и её можно запустить со страницы устройства.

Определения Defender (Security Intelligence Update) выходят несколько раз в день, каждое с новым идентификатором обновления. Когда вы устанавливаете одно из них, агент сначала выполняет поиск заново и устанавливает версию определений, которую Windows Update предлагает в этот момент.

Автоматическая установка

Часть Windows Update политики (например, политики клиента Default) определяет, что сервер устанавливает сам:

  • Выключено — обновления устанавливаются только из консоли.
  • Обновления безопасности и критические, определения Defender.
  • Все обновления, кроме обновлений функций — новые версии Windows никогда не устанавливаются автоматически.

Выберите дни и час (время сервера) или В окне обслуживания. Устройства, которые в это время в сети, устанавливают один раз в этот день; устройства не в сети ждут следующего запланированного дня.

Кольцо обновлений: с задержкой, например, 7 дней устройство устанавливает обновление только через 7 дней после того, как сервер впервые его увидел. Дайте тестовым компьютерам политику с 0 днями, а остальным — с 7 днями, и проблемы сначала проявятся на тестовых компьютерах. Определения Defender никогда не ждут.

Перезагрузка, когда её требует обновление: никогда автоматически; автоматически через 5 минут после установки с уведомлением; или Спросить пользователя: значок RMMZit просит вошедшего пользователя перезагрузить компьютер, повторно каждые 4 часа, а после срока (дней, на которые пользователь может отложить) сервер перезагружает компьютер с предупреждением за 10 минут, в окне обслуживания, если оно есть у устройства. Вкладка Политика устройства показывает ожидающую перезагрузку и её срок.

Чтобы обновления не приходили в случайное время, агент политикой отключает автоматическую установку Windows Update. После удаления агента возвращаются прежние настройки.

Linux

В Linux агент читает доступные обновления пакетов через apt (Debian, Ubuntu; обновления безопасности из источников -security) или dnf (семейство RHEL; обновления безопасности по сведениям об обновлениях) и устанавливает выбранные пакеты. Автоматическая установка действует и для устройств с Linux; там «обновления безопасности» — это пакеты из источников безопасности.

Программы (winget)

Вкладка Программы устройства Windows состоит из трёх частей. Доступные обновления показывает программы, которые может обновить winget; Обновить все обновляет их, можно обновлять и отдельные программы. Установленные показывает каждую программу из списка установленных программ Windows — для компьютера и для вошедших пользователей — с фильтром по названию или издателю. Удалить удаляет программу без вопросов: пакеты Windows Installer (MSI) через msiexec /x, деинсталляторы Inno Setup и NSIS с их ключом тихого режима или собственной тихой командой программы. Результат сообщается, только когда программа действительно удалена; программы без тихого деинсталлятора помечены, их нужно удалить на компьютере или скриптом. Установить программу ищет в репозитории сообщества winget (например, 7-Zip или Chrome) и устанавливает без вопросов для всех пользователей. Для установки и обновления нужен winget (App Installer), который входит в актуальные Windows 10 и 11.

Chocolatey можно добавить как второй общедоступный источник в разделе Программы → Общедоступные источники. Тогда в Установить программу появляется выбор источника (winget или Chocolatey), а Доступные обновления показывает и программы, установленные через Chocolatey, у которых есть более новая версия. Клиент Chocolatey устанавливается на устройство через winget, когда он впервые нужен. Пакеты Chocolatey поддерживает его сообщество, и обычно они скачивают программу с сайта производителя.

Библиотека программ

В разделе Программы администраторы загружают собственные установщики: пакет установщика Windows (.msi) или программу установки (.exe) размером до 2 ГБ — с названием, версией, аргументами тихой установки и кодами завершения, означающими успех (по умолчанию 0, 1641 и 3010; два последних означают, что установку завершит перезагрузка). Для MSI агент запускает msiexec /i с журналом, а аргументы по умолчанию — /qn /norestart; EXE нужен собственный ключ тихой установки, например /S (NSIS), /VERYSILENT /NORESTART (Inno Setup) или /quiet.

Установить на устройства выбирает клиентов, площадки или отдельные устройства Windows и запускает задание, как скрипт из библиотеки: устройства в сети устанавливают сразу, а не в сети — когда подключаются в течение 24 часов. Агент скачивает установщик с агентского порта сервера и сверяет его с SHA-256 из подписанной команды, прежде чем запустить от имени SYSTEM. Страница задания показывает результат каждого устройства; журнал пакета установщика Windows сохраняется вместе с результатом. Техники устанавливают пакеты на устройства своих клиентов, в том числе через Установить программу на вкладке «Программы» устройства.

Уязвимости

В разделе Уязвимости администратор включает проверку установленных программ. Каждые 6 часов сервер сравнивает их с открытыми базами уязвимостей: NVD для распространённых программ Windows (браузеры, просмотрщики PDF, архиваторы, средства удалённого доступа и разработки и другие) и OSV для пакетов Debian и Ubuntu. Отправляются только названия и версии программ, никогда данные устройств. Необязательный бесплатный ключ API NVD ускоряет первую проверку.

Страница показывает затронутые программы и версии с числом уязвимостей по критичности и устройствами; вкладка Уязвимости устройства перечисляет каждую со ссылкой на описание. Обновление программы устраняет их. С параметром Оповещать, когда у программы есть критическая уязвимость в правилах оповещений политики критические (CVSS 9 и выше) открывают оповещение. Саму Windows покрывают обновления Windows, а не эта проверка.

Уязвимости пакетов Debian и Ubuntu, для которых в выпуске устройства ещё нет исправления, скрыты, пока вы их не покажете; для каждой находки указана версия с исправлением.
