Начало работы

ControlZit — инструмент удалённого мониторинга и управления (RMM), который работает на вашем собственном сервере. Из одной веб-консоли вы наблюдаете за компьютерами клиентов с Windows и Linux и управляете ими: инвентаризация, мониторинг и оповещения, удалённый рабочий стол, терминал, файлы, скрипты, обновления Windows, программы и отчёты.

Как это работает

  • Сервер работает на машине с Linux (обычно небольшой VM) с PostgreSQL. У него два порта: консоль (веб-интерфейс и API, TCP 8443) и точка подключения агентов (TCP 8444).
  • Агенты работают как служба на каждом управляемом компьютере. Они подключаются к порту агентов исходящим соединением; компьютерам не нужны открытые порты. Агент доверяет серверу по отпечатку его сертификата, который закрепляет при регистрации.
  • Каждую команду агенту сервер подписывает, а агент проверяет, и каждое действие записывается в защищённый от изменений журнал аудита.

Консоль управляет каждым компьютером. Делайте её доступной только из своих сетей (по умолчанию) и открывайте только порт агентов там, где он нужен. См. Безопасность.

Первые шаги

  1. Установите сервер — импортируйте готовый образ VM, загрузите ISO устройства или запустите скрипт установки на сервере с Linux. См. Установка сервера.
  2. Создайте первого администратора с помощью токена настройки, который показывает сервер, и настройте двухфакторный вход с приложением-аутентификатором.
  3. Проверьте адрес для агентов в разделе Настройки → Сеть и доступ: агенты должны достигать сервера по публичному адресу для агентов или по имени консоли.
  4. Добавьте клиента и площадку в разделе Клиенты и создайте на площадке код регистрации.
  5. Установите агент на компьютеры площадки с этим кодом. См. Установка агентов.
  6. Настройте оповещения и автоматические обновления Windows в политике клиента Default в разделе Политики, а письма об оповещениях — в Настройки → Мониторинг и оповещения.
  7. Добавьте техников в разделе Пользователи или подключите Active Directory / LDAP либо единый вход. См. Пользователи, роли и вход.

Требования

  • Сервер: 2 vCPU, 2–4 ГБ ОЗУ, диск 16 ГБ; Debian 12+, Ubuntu 22.04+, AlmaLinux или Rocky Linux 9+ (или готовое устройство).
  • Агенты Windows: Windows 10 / 11, Windows Server 2016 и новее, 64-бит.
  • Агенты Linux: дистрибутивы с systemd, x86-64 или ARM64 (Raspberry Pi и ARM-серверы). Обновления через apt или dnf.
  • Браузер: актуальный Chrome, Edge, Firefox или Safari.
