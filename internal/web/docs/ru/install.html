Установка сервера

Выберите один из четырёх способов. Готовый образ VM — самый быстрый; скрипт установки подходит для существующего сервера с Linux.

СпособЛучше всего дляНужно
1. Образ VM (OVA, qcow2, VHDX)импортировать, запустить и войти за несколько минутVMware, Proxmox / KVM или Hyper-V
2. ISO устройствановая VM или физический сервер, без участиядоступ в интернет во время установки
3. Скрипт установкисуществующий сервер Debian, Ubuntu, AlmaLinux или Rocky Linuxroot и доступ в интернет

Все файлы есть на странице выпусков. Дайте серверу 2 vCPU, 2–4 ГБ ОЗУ и диск от 16 ГБ.

1. Образ VM

  1. Импортируйте образ:
    • VMware ESXi / Workstation, VirtualBox: разверните controlzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: создайте VM без диска (2 vCPU, 2–4 ГБ ОЗУ, сеть VirtIO), скопируйте controlzit-appliance.qcow2 на узел и выполните qm importdisk <vmid> controlzit-appliance.qcow2 local-lvm; подключите диск как SCSI и сделайте его загрузочным.
    • Hyper-V: распакуйте controlzit-appliance-vhdx.zip и создайте VM поколения 1 с этим VHDX в качестве диска.
  2. Запустите VM. Диск сам увеличится до размера виртуального диска. На экране VM показаны адрес консоли и токен настройки.
  3. Откройте https://<адрес>:8443. Браузер один раз предупредит о самоподписанном сертификате (позже замените его в разделе Настройки → Сертификат). Введите токен и создайте первого администратора.

Устройство получает адрес по DHCP. Чтобы задать постоянный адрес, имя сервера или часовой пояс, войдите на экране VM как czadmin (первый пароль controlzit, его нужно сменить): откроется меню настройки. Часовой пояс и сеть можно позже изменить и в консоли.

2. ISO устройства

  1. Загрузите VM или сервер с controlzit-appliance.iso. Через 5 секунд установка начнётся сама: она стирает первый диск, устанавливает Debian, PostgreSQL и ControlZit и требует доступа в интернет (10–20 минут).
  2. После перезагрузки на экране показаны адрес консоли и токен настройки, как в образе VM.

3. Скрипт установки

На существующем сервере с Linux от имени root:

curl -fsSL https://github.com/Max-Zit/controlzit/releases/latest/download/install.sh | sudo sh

Скрипт устанавливает PostgreSQL, скачивает последний выпуск, проверяет его подпись, создаёт базу данных со случайным паролем и запускает службу. Параметры (после sh -s --): --version X, --db postgres://… для существующей базы, --no-auto-updates, чтобы автоматические обновления безопасности ОС остались выключенными. Повторный запуск обновляет ControlZit и сохраняет данные.

4. Пакеты вручную

sudo apt install ./controlzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./controlzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Затем впишите адрес базы данных в /etc/controlzit/server.env (CONTROLZIT_DB=postgres://…) и запустите службу командой systemctl enable --now controlzit-server.

Первый вход

  • Токен настройки находится в /var/lib/controlzit/setup-token.txt и в журнале сервера (journalctl -u controlzit-server). Он действует один раз.
  • Каждой учётной записи нужно приложение-аутентификатор (TOTP); она получает 10 резервных кодов. Храните их в надёжном месте.
  • По умолчанию консоль принимает соединения только из частных сетей. Если вы заблокировали себе доступ, выполните на сервере controlzit-server --reset-allowlist (устройство: меню настройки, пункт 5).

Где что находится

ПутьЧто
/etc/controlzit/server.envконфигурация: база данных, порты, источник обновлений (читают только root и служба)
/var/lib/controlzitкаталог данных: сертификаты, секретный ключ, установщики агентов (downloads), журналы
/var/lib/controlzit/logs/server.logжурнал сервера; также в journalctl -u controlzit-server
/var/log/controlzit-helperжурнал помощника root (обновления, часовой пояс, сеть)

Делайте резервную копию базы данных вместе с /var/lib/controlzit: секретный ключ оттуда расшифровывает сохранённые пароли, а сертификаты удостоверяют сервер перед его агентами.
