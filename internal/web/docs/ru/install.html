Установка сервера

Выберите один из пяти способов. Готовый образ VM — самый быстрый; скрипт установки подходит для существующего сервера с Linux, Docker — для существующего хоста Docker.

Все файлы есть на странице выпусков. Дайте серверу 2 vCPU, 2–4 ГБ ОЗУ и диск от 16 ГБ.

1. Образ VM

  1. Импортируйте образ:
    • VMware ESXi / Workstation, VirtualBox: разверните rmmzit-appliance.ova (Create / Register VM → Deploy a virtual machine from an OVF or OVA file).
    • Proxmox VE: создайте VM без диска (2 vCPU, 2–4 ГБ ОЗУ, сеть VirtIO), скопируйте rmmzit-appliance.qcow2 на узел и выполните qm importdisk <vmid> rmmzit-appliance.qcow2 local-lvm; подключите диск как SCSI и сделайте его загрузочным.
    • Hyper-V: распакуйте rmmzit-appliance-vhdx.zip и создайте VM поколения 1 с этим VHDX в качестве диска.
  2. Запустите VM. Диск сам увеличится до размера виртуального диска. На экране VM показаны адрес консоли и токен настройки.
  3. Откройте https://<адрес>:8443. Браузер один раз предупредит о самоподписанном сертификате (позже замените его в разделе Настройки → Сертификат). Введите токен и создайте первого администратора.

Устройство получает адрес по DHCP. Чтобы задать постоянный адрес, имя сервера или часовой пояс, войдите на экране VM как rzadmin (первый пароль rmmzit, его нужно сменить): откроется меню настройки. Часовой пояс и сеть можно позже изменить и в консоли.

2. ISO устройства

  1. Загрузите VM или сервер с rmmzit-appliance.iso. Через 5 секунд установка начнётся сама: она стирает первый диск, устанавливает Debian, PostgreSQL и RMMZit и требует доступа в интернет (10–20 минут).
  2. После перезагрузки на экране показаны адрес консоли и токен настройки, как в образе VM.

3. Скрипт установки

На существующем сервере с Linux от имени root:

curl -fsSL https://github.com/Max-Zit/rmmzit/releases/latest/download/install.sh | sudo sh

Скрипт устанавливает PostgreSQL, скачивает последний выпуск, проверяет его подпись, создаёт базу данных со случайным паролем и запускает службу. Параметры (после sh -s --): --version X, --db postgres://… для существующей базы, --no-auto-updates, чтобы автоматические обновления безопасности ОС остались выключенными. Повторный запуск обновляет RMMZit и сохраняет данные.

4. Пакеты вручную

sudo apt install ./rmmzit-server_X_amd64.deb      # Debian, Ubuntu
sudo dnf install ./rmmzit-server-X-1.x86_64.rpm     # AlmaLinux, Rocky Linux

Затем впишите адрес базы данных в /etc/rmmzit/server.env (RMMZIT_DB=postgres://…) и запустите службу командой systemctl enable --now rmmzit-server.

5. Docker

Сервер есть и в виде образа контейнера, ghcr.io/max-zit/rmmzit, собранного из того же подписанного пакета сервера, что и другие способы; он работает с PostgreSQL через Docker Compose. Скачайте docker-compose.yml и .env.example в папку, скопируйте .env.example в .env, задайте пароль базы данных (буквы и цифры) и часовой пояс, затем:

docker compose up -d
docker compose exec rmmzit cat /var/lib/rmmzit/setup-token.txt

Откройте https://<хост>:8443 и введите токен настройки. Порт 8444 — точка подключения агентов; откройте его там, откуда подключаются агенты. Тег образа в .env определяет, что запущено: latest для официальных выпусков, testing для кандидатов.

Обновляйте командой docker compose pull && docker compose up -d. Перед тем как новая версия изменит базу данных, сервер записывает резервную копию в Настройки → Резервная копия консоли. Чтобы вернуться, укажите предыдущую версию как тег образа и восстановите этот файл: docker compose stop rmmzit, docker compose run --rm rmmzit -restore /var/lib/rmmzit/backups/ФАЙЛ, docker compose up -d. В контейнере сеть и часовой пояс относятся к хосту Docker, а не к консоли.

Первый вход

  • Токен настройки находится в /var/lib/rmmzit/setup-token.txt и в журнале сервера (journalctl -u rmmzit-server). Он действует один раз.
  • Каждой учётной записи нужно приложение-аутентификатор (TOTP); она получает 10 резервных кодов. Храните их в надёжном месте.
  • По умолчанию консоль принимает соединения только из частных сетей. Если вы заблокировали себе доступ, выполните на сервере rmmzit-server --reset-allowlist (устройство: меню настройки, пункт 5).

Где что находится

ПутьЧто
/etc/rmmzit/server.envконфигурация: база данных, порты, источник обновлений (читают только root и служба)
/var/lib/rmmzitкаталог данных: сертификаты, секретный ключ, установщики агентов (downloads), журналы
/var/lib/rmmzit/logs/server.logжурнал сервера; также в journalctl -u rmmzit-server
/var/log/rmmzit-helperжурнал помощника root (обновления, часовой пояс, сеть)

Делайте резервную копию базы данных вместе с /var/lib/rmmzit: секретный ключ оттуда расшифровывает сохранённые пароли, а сертификаты удостоверяют сервер перед его агентами.
